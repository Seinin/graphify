# 21cmFAST 代码地图（atlas）

> 本页把 21cmFAST 的整条计算流水线压成一页，并说清"想干什么就走哪条路"。
> 想按问题查对象 → [INDEX](INDEX.md)；想改这套文档本身 → [CONVENTIONS](CONVENTIONS.md)（维护契约，读者不必看）。

## 1. 一眼看完：从参数到亮温

```
① 输入              ② 一次性备料（不随红移重复）      ③ 逐红移推进（红移从高到低，每个红移都走一遍）
──────────          ─────────────────────────────    ─────────────────────────────────────────────────────
                                                       P06 源项网格 ─▶ P07 X 射线源箱 ─▶ P08 自旋温度盒 ─▶ P09 电离盒 ─▶ P10 亮温盒
P01 输入参数集 ─▶ P02 初始条件 ─┬─▶ P03 微扰场 ────────────┘         │                │             │            │
（模板 / 命令行）                └─▶ P04 晕目录 ─────────────────────┘                │             │            │
                                        （旁支 P05 微扰晕目录，主链不消费）           └─────────────┴────────────┘
                                                                                        （上一快照回喂下一快照）

④ 输出              P10 亮温盒 ─┬─▶ P11 演化快照（E1 联合演化盒，按量取用）
                              ├─▶ P12 光锥（E2，沿视线切片拼起来）
                              └─▶ P13 全局演化历史（E3，退化成零维、取盒均值）

⑤ 旁路（不推进主链）   P14 光度函数诊断 · P15 再电离光学深度 · P16 光子守恒校准曲线（回灌 ③）· P17 宇宙学查表（并入 P01）
```

**只有 P02–P10 在真正的计算链上；P11–P13 是三种"收尾形态"，P14–P17 是旁路。**
P04/P06/P07 是**条件性**的：只有启用离散晕抽样、自旋温度涨落、拉格朗日型源模型时才会走到。
