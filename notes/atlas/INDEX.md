## 2. 七个入口 / 十七种产物 速查

**入口**（对外可以怎么调）：

| 编号 | 名称 | 角色 | 一句话 |
| :--- | :--- | :--- | :--- |
| [E1](L0-pipeline.md#e1-联合演化盒) | 联合演化盒 | 流水线 | 一次运行沿红移拿到主链整套产物 |
| [E2](L0-pipeline.md#e2-光锥) | 光锥 | 流水线 | 同上，但把每个红移的盒沿视线切片拼起来 |
| [E3](L0-pipeline.md#e3-全局演化) | 全局演化 | 流水线（退化） | 压成单格，取均值得到红移历史曲线 |
| [E4](L0-pipeline.md#e4-单场直算) | 单场直算 | 底层 | 主链每种产物的唯一直接产出者；E1–E3 内部调它 |
| [E5](L0-pipeline.md#e5-参数装配与模板) | 参数装配与模板 | 前置 | 产出 P01，所有入口都从它开始 |
| [E6](L0-pipeline.md#e6-持久化与读取) | 持久化与读取 | 横切 | 不推进主链，只把产物落盘、重跑回读 |
| [E7](L0-pipeline.md#e7-离线与旁路) | 离线与旁路 | 旁路 | 诊断量 + 一处回灌（光子守恒校准） |
