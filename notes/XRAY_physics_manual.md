### 三条通道与 X-ray 的不可替代性

21cm 信号来自中性氢 HI 的 1420 MHz 超精细结构跃迁。在**宇宙黎明(EoH)与再电离(EoR)**时期(z ≈ 6–30),观测 21cm 信号是探测第一代恒星与星系的主要手段。但第一代天体(Halo)如何影响 21cm 信号?主要有三条通道:

| 通道                         | 物理机制                                | 作用目标               | 时间尺度                              |
| ---------------------------- | --------------------------------------- | ---------------------- | ------------------------------------- |
| **UV 电离**            | 恒星电离光子(HI→HII)                   | 电离分数 x_e           | 再电离主体                            |
| **X-ray 加热**(本手册) | 恒星残余物(黑洞、高能双星)产生的 X 射线 | 气体动力学温度 Tk      | 早于再电离,是 21cm 信号的"第一道印记" |
| **Lyα 耦合**(WF效应)  | 恒星紫外光子经 Lyman 系列散射           | 自旋温度 Ts 与 Tk 耦合 | 与 X-ray 同时期                       |

> **主线**:21cm 观测的对比度是 `Ts vs T_CMB`。在再电离之前,中性氢还很丰富,**X-ray 加热几乎决定了 21cm 信号的全局吸收谱型(dip)的位置与深度**。没有 X-ray,21cm 信号将长期处于完全吸收态,丢失大量信息。X-ray 是 EoH 阶段(再电离之前)21cm 信号的主要"开关"。

> **为什么康普顿散射和 CMB 耦合不是一回事**:CMB 光子在这里有两个不同的角色。① 作为 21cm 线光子与 HI 超精细跃迁共振(吸收/受激发射)→ 直接作用于 $T_s$,把它拉回 $T_\gamma$——这是"CMB 耦合";② 作为高频光子与自由电子散射(汤姆孙/康普顿)→ 交换能量作用于 $T_k$,把它拉向 $T_\gamma$——这是"康普顿散射"。前者动布居、后者动温度,不要混为一谈。
>
> **时间表如何读这张表**:顺着时间走,主导机制依次为 康普顿($z\gtrsim150$,$T_k=T_\gamma$)→ 绝热冷却 + 碰撞耦合($40\lesssim z\lesssim150$,$T_s\approx T_k<T_\gamma$,吸收)→ CMB 耦合独占($z_\star\lesssim z\lesssim40$,碰撞失效,$T_s=T_\gamma$,空窗)→ Lyα 耦合($z_\alpha\lesssim z\lesssim z_\star$,深吸收谷)→ Lyα + X-ray 加热($z_h\lesssim z\lesssim z_\alpha$,$T_k$ 逼近 $T_\gamma$,吸收转发射)→ 饱和发射($z_T$)。

> **谁直接动谁(因果分层)**:这张表读到这里,可以总结成两条铁的规则——
>
> - **耦合(CMB、碰撞、Lyα)直接修改的只有 $T_s$**:它们把 $T_s$ 拉向 $T_\gamma$ 或 $T_k$,但对 $T_k$、$T_\gamma$、$T_c$ 几乎不碰。理由:超精细能级能量差 $h\nu_{21}\approx6\times10^{-6}\,\mathrm{eV}$ 远小于 $k_BT_k$ 和 21cm 光子相对 CMB 浴的能量,翻转布居交换的能量对 $T_k$、$T_\gamma$ 都是沧海一粟。
> - **加热/冷却(康普顿、绝热、X-ray)直接修改的只有 $T_k$**:它们直接改气体动能温度,不直接碰 $T_s$。
>
> 但"不直接碰"不等于"不影响":**加热/冷却通过 $T_k$ 间接修改 $T_s$**——$T_k$ 一变,碰撞耦合和 Lyα 耦合就把 $T_s$ 拉向新的 $T_k$,于是 $T_s$ 跟着变。这正是 X-ray 能成为 21cm 信号"开关"的原因:它直接改的是 $T_k$,但通过耦合这条链传到 $T_s$,最终决定 $\delta T_{21}$。此外还有第二条旁路:电离直接改 $x_e$,而 $x_{\mathrm{col}}$ 的 H–e⁻、H–p⁺ 项正比于 $x_e$,所以电离(含 X-ray 电离)会顺带增强碰撞耦合,间接影响 $T_s$(见 P2 第三步)。
>
> 一句话总结:**耦合直接动 $T_s$;加热/冷却直接动 $T_k$;前者对 $T_k$ 无反馈,后者对 $T_s$ 有反馈(经 $T_k$ 间接传入)。**

典型参考模型(PL2012 §3.1 图 1)中 $z_\star \approx 30$、$z_\alpha \approx 25$、$z_h \approx 20$、$z_T \approx 17$、$z_r \approx 10$,具体值随源模型大幅移动。

**时间表中各个 $T$ 的含义**(按出现顺序):

| 符号                                                                                                                                                                       | 全称 | 含义 |
| :------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---- | ---- |
| $T_\gamma$ | CMB 光子温度 | 宇宙微波背景辐射温度,$T_\gamma = 2.725(1+z)\,\mathrm{K}$;21cm 对比度 $\delta T_{21}\propto(T_s-T_\gamma)$ 的参考基准,也驱动 Compton 耦合 |      |      |
| $T_k$ | 气体(重子)动力学温度 | 中性气体的动能温度,$T_k \propto (1+z)^2$ 绝热冷却;决定碰撞耦合速率,是 **X-ray 加热的对象**                                        |      |      |
| $T_s$ | 21cm 自旋温度 | 由 HI 超精细上/下能级布居比定义;时间表中每个阶段的本质就是"$T_s$ 被推向哪个 $T$"——$T_s < T_\gamma$ 吸收、$T_s > T_\gamma$ 发射         |      |      |
| $T_c$ | Lyα 色温 | Wouthuysen–Field 耦合把$T_s$ 拉向的等效温度;光子散射反冲平衡下 $T_c \approx T_k$(详见 P2)                                                       |      |      |

| 符号                                                                                | 含义                                |
| ----------------------------------------------------------------------------------- | ----------------------------------- |
| $z_\star$                                                                         | 第一代发光源点亮的红移,黑暗时代结束 |
| $z_\alpha$ | Lyα(WF)耦合饱和的红移($x_\alpha \gg 1$,Lyα 通量涨落不再影响信号) |                                     |
| $z_h$ | X-ray 加热使平均$T_k$ 达到 $T_\gamma$ 的红移,整体信号由吸收转发射     |                                     |

> 记住这条主线:碰撞耦合与 Lyα 耦合都把 $T_s$ 挂到 $T_k$ 上,而 CMB 光子把 $T_s$ 拉回 $T_\gamma$。时间表的演化顺序 = 主导耦合从碰撞($z\gtrsim40$)→ Lyα($z_\alpha$)→ 加热抬升 $T_k$($z_h$)→ 饱和($z_T$),最终 UV 电离抹掉中性氢($z_r$)。X-ray 的杠杆就是 $T_k$。

> **暗时代明明是 $T_s < T_\gamma$(吸收),为什么到了耦合空窗期 $T_s$ 反而"升高"到 $T_\gamma$?**
>
> 关键:**$T_s$ 不是气体的动能温度,而是超精细能级布居比定义出的"虚拟温度"**——它自己不含热量,只回答一个问题:此刻布居被哪个温度锚定。锚点由 P2 的加权平均公式(PL2012 式 8)决定:
>
> $$
> \frac{1}{T_s} = \frac{x_{\mathrm{col}}\,\frac{1}{T_k} + x_\alpha\,\frac{1}{T_c} + \frac{1}{T_\gamma}}{1 + x_{\mathrm{col}} + x_\alpha}
> $$
>
> - **暗时代**:气体密度 $n$ 高 → 碰撞去激发速率 $C_{10}\propto n$ → $x_{\mathrm{col}}\gg1$,权重几乎全压在 $T_k$ 上 → $T_s\approx T_k$。而 $T_k$ 绝热冷却比 $T_\gamma$ 快($T_k\propto(1+z)^2$ vs $T_\gamma\propto(1+z)$),所以 $T_s\ll T_\gamma$ → 深吸收。
> - **耦合空窗**:膨胀使 $n$ 持续下降 → $C_{10}\propto n$ 衰减 → $x_{\mathrm{col}}\to0$,公式里 $T_k$ 的权重消失,只剩 CMB 项 → $T_s\to T_\gamma$。
>
> 所以 $T_s$ 的"升高"**不是被加热,而是碰撞这只看手松开了 $T_s$**,让它回到 CMB 基准温度(此时 $T_\gamma$ 本身也在随红移下降,只是 $T_k$ 降得更快,差距更大)。这正是"空窗"二字的含义:没有任何耦合把 $T_s$ 挂到 $T_k$ 上,信号归零($\delta T_{21}\propto T_s-T_\gamma\to0$)。要等第一代源点亮,Lyα 耦合(以及后续 X-ray 加热抬高 $T_k$)才再次把 $T_s$ 锚到 $T_k$ 上。

**关键:X-ray 决定 $z_\alpha$ 与 $z_h$ 的先后,这是最大的模型不确定之一。** 常规图像是"先 Lyα 耦合、后 X-ray 加热"($z_\alpha > z_h$);但存在 **X-ray 预热(X-ray preheating)** 图像:若 X-ray 源效率极高,加热先于 Lyα 耦合($z_h > z_\alpha$),X-ray 把气体加热到碰撞耦合重新有效的温度,21cm 信号在更高红移就出现吸收——第一代微类星体(miniquasar)模拟即属此情形。在 21cmFAST 中,这对应 `L_X` 取高值,且 X-ray 产生的 Lyα(`dxlya_dt_box`,见 E3)与加热同步进入。

> **观测意义(核心)**:21cm 对 X-ray 最敏感的阶段是**加热期($z_\alpha \to z_h$)**:吸收谷的深度、宽度以及转发射的红移直接约束 `L_X` 与 `X_RAY_SPEC_INDEX`——这是本手册全部公式最终要回答的问题。

## P1:21cm 亮温公式——X-ray 作用的终点

### 亮温公式——从辐射转移到 δT21 的四步推导

本节将 21cm 差分亮温公式**从头推一遍**。每一步给出"是什么 → 为什么 → 得什么"。PL2012 §2.1 的脉络与此一致。

**第 1 步:辐射转移方程(一切亮温公式的起点)**

电磁波穿过介质时,强度 $I_\nu$(单位:$\mathrm{erg\,s^{-1}\,cm^{-2}\,Hz^{-1}\,sr^{-1}}$)沿路径 $s$ 的变化满足:

$$
\frac{dI_\nu}{ds} = j_\nu - \alpha_\nu I_\nu
$$

其中 $j_\nu$ 是发射系数(介质自己发多少光),$\alpha_\nu$ 是吸收系数(介质吃掉多少光)。

**第 2 步:把"21cm 线"装进吸收系数**

21cm 线是中性氢的超精细跃迁:上能级 $F=1$(统计权重 $g_1=3$)、下能级 $F=0$($g_0=1$),跃迁能量 $h\nu_{21}$,自发辐射系数 $A_{10} = 2.85\times10^{-15}\,\mathrm{s^{-1}}$(寿命约 1100 万年,是宇宙中寿命最长的原子跃迁之一)。

对**吸收系数**,爱因斯坦理论给出:

$$
\alpha_\nu = \frac{h\nu_{21}}{4\pi}\big(n_0 B_{01} - n_1 B_{10}\big)\,\phi(\nu)
$$

- $n_0$、$n_1$:上下能级粒子数密度
- $B_{01}$、$B_{10}$:受激吸收 / 受激发射爱因斯坦系数,满足 $B_{01} = (g_1/g_0)B_{10} = 3B_{10}$
- $\phi(\nu)$:线型函数(归一化 $\int\phi\,d\nu=1$)

> **物理**:吸收的净效果 = 向上的吸收($n_0B_{01}$)减去向下的受激发射($n_1B_{10}$),差值为正才有净吸收。这一"减去"至关重要:它把 $T_s$ 写进公式的通道。

**第 3 步:用 $T_s$ 和 $T_*$ 重写布居数,得到吸收系数**

自旋温度 $T_s$ 的定义来自**布居数比**:

$$
\frac{n_1}{n_0} = \frac{g_1}{g_0}\,e^{-T_*/T_s} = 3\,e^{-T_*/T_s}, \qquad T_* \equiv \frac{h\nu_{21}}{k_B} \approx 0.068\ \mathrm{K}
$$

把 $n_1 = 3n_0 e^{-T_*/T_s}$ 代入吸收系数,并利用"21cm 线光子能量远小于任何温度($T_*/T_s \ll 1$)"展开 $e^{-T_*/T_s} \approx 1 - T_*/T_s$:

$$
\begin{aligned}
n_0 B_{01} - n_1 B_{10} &= n_0\cdot 3B_{10} - 3n_0 e^{-T_*/T_s}B_{10} \\
&= 3n_0 B_{10}\big(1 - e^{-T_*/T_s}\big) \\
&\approx 3n_0 B_{10}\,\frac{T_*}{T_s}
\end{aligned}
$$

代入 $\alpha_\nu$,并用 $n_{\mathrm{HI}} = n_0 + n_1 \approx n_0(1+3e^{-T_*/T_s}) \approx 4n_0$(因为 $T_* \ll T_s$,几乎全在下能级)消去 $n_0$,以及爱因斯坦关系 $B_{10} = A_{10}c^2/(2h\nu_{21}^3)$:

$$
\alpha_\nu \approx \frac{3}{32\pi}\,\frac{h c^2 A_{10}}{k_B T_s \nu_{21}^2}\,n_{\mathrm{HI}}\,\phi(\nu)
$$

**关键结论**:吸收系数 $\alpha_\nu \propto n_{\mathrm{HI}}/T_s$。物理上,这来自"净吸收 ∝ 布居数差 ∝ $T_*/T_s$"。**$T_s$ 越大,净吸收越弱**——这正是"自旋温度高 → 21cm 信号弱(趋近背景)"的数学根源。

**第 4 步:积分光学深度,得到亮温**

光学深度是吸收系数沿视线积分:

$$
\tau_{21}(\nu) = \int \alpha_\nu\,ds
$$

把视线距离换成红移($ds = c\,dt = c\,dz/[(1+z)H(z)]$,此处只取均匀膨胀、忽略本征速度),并把中性氢数密度写成 $n_{\mathrm{HI}} = \bar n_{\mathrm{HI}}(1+\delta) = x_{\mathrm{HI}}\bar n_{\mathrm{H}}(1+\delta)$($\bar n_H$ 为共动氢核数密度),再对线型积分 $\int\phi\,d\nu = 1$,得到光学深度的量级估计(PL2012 式 2):

$$
\tau_{21} \approx 0.0092\,x_{\mathrm{HI}}\,(1+\delta)\left(\frac{1+z}{10}\right)^{3/2}\,\frac{T_\gamma}{T_s}
$$

(数值系数来自 $\frac{3h c^3 A_{10}}{32\pi k_B\nu_{21}^2}\frac{\bar n_{\mathrm{H}}(0)}{H_0}\sqrt{\frac{\Omega_m h^2}{0.15}}$,默认宇宙学下 ≈ 0.0092。)

**最后一步:差分亮温**

"背景+云"几何(云在 CMB 背景前,云后是 CMB)的辐射转移解为:

$$
T_b^{\mathrm{obs}} = T_s\big(1-e^{-\tau_{21}}\big) + T_\gamma\,e^{-\tau_{21}}
$$

(强度 $I_\nu$ 在瑞利–金斯极限下等价于亮温 $T \propto I_\nu/\nu^2$,故可直接对亮温作线性组合。)观测到的**差分亮温** = 云的亮温 − 背景亮温:

$$
\delta T_{21} = T_b^{\mathrm{obs}} - T_\gamma = \big(T_s - T_\gamma\big)\big(1-e^{-\tau_{21}}\big) \approx \big(T_s - T_\gamma\big)\,\tau_{21} \qquad (\tau_{21}\ll 1)
$$

把第 4 步的 $\tau_{21}$ 代进去,整理系数($T_\gamma = 2.725(1+z)$),就得到大家熟悉的公式(PL2012 式 7;21cmFAST 用默认宇宙学把前两个括号归一为常数 27 mK):

$$
\boxed{\;\delta T_{21} \approx 27\, x_{\mathrm{HI}}\, (1+\delta)\left(\frac{1+z}{10}\right)^{1/2} \frac{T_s - T_{\mathrm{CMB}}}{T_s}\ \mathrm{mK}\;}
$$

- $x_{\mathrm{HI}}$:中性氢分数(受电离影响)
- $T_s$:自旋温度(受 X-ray 加热、Lyα 耦合、碰撞耦合影响)
- $T_{\mathrm{CMB}}$:宇宙微波背景温度

**完整版公式(PL2012 式 7)**:上面是 21cmFAST 使用的含归一化系数的形式;文献完整形式显式写出宇宙学参数与视线速度效应:

$$
\delta T_{21} \approx 27\, x_{\mathrm{HI}}\,(1+\delta_b)\left(\frac{\Omega_b h^2}{0.023}\right)\left(\frac{0.15}{\Omega_m h^2}\right)\left(\frac{1+z}{10}\right)^{1/2}\frac{T_s - T_{\mathrm{CMB}}}{T_s}\,\frac{\partial_r v_r}{(1+z)H(z)}\;\mathrm{mK}
$$

- 前两个括号是重子/物质密度参数归一;对 21cmFAST 默认宇宙学($\Omega_b h^2 \approx 0.0223$、$\Omega_m h^2 \approx 0.142$)乘积 ≈ 1.03,故系数收敛为上面的 27 mK
- 最后一项 $\partial_r v_r / [(1+z)H(z)]$ 是视线方向速度梯度造成的红移空间畸变;再电离前气体随哈勃流,此项 ≈ 1,21cmFAST 未显式引入本征速度项

> **三件事**:
>
> 1. $\delta T_{21} \ne 0$ 的唯一原因是 $T_s \ne T_\gamma$(吸收/发射);
> 2. $T_s$ 通过布居数比 $n_1/n_0 = 3e^{-T_*/T_s}$ 进入光学深度,**"1/T_s"式依赖**是后面一切耦合公式采用"1/T 相加"的根本原因;
> 3. X-ray 改变不了 $T_\gamma$,只能抬高 $T_k$(→ $T_s$)。所以**控制 $T_s$ 就控制了一切**——这正是 P2 的主题。

**两种背景源(PL2012 §2.1)**:21cmFAST 面向的情形 (i) 以 CMB 为均匀背景(弥漫全天差分亮温 δT21);情形 (ii) 以射电亮源(如射电噪类星体)为背景,沿途中性氢呈**21cm 森林(21cm forest)**吸收谱,可作高红移小尺度结构探针。X-ray 物理对两者相同(都经 $T_s$),本手册只展开 (i)。

## P2:自旋温度 Ts 与动力学温度 Tk

> **记号(核心)**:P2/P3 的 $\varepsilon_X$ 指**能量沉积率(X-ray 加热率)**,而 P4/P5 的 $\varepsilon_X$ 指**源发射率场**(单位 per s per cm³)——二者由 P4 的传播(光学深度)衔接。

### Ts 的耦合结构——从统计平衡一步步推出加权公式

**第一步:Ts 是什么。**

上能级($F=1$,三重态,统计权重 3)与下能级($F=0$,单态,权重 1)的粒子数比满足玻尔兹曼分布:

$$
n_1 / n_0 = (g_1/g_0)\, e^{-T_*/T_s} = 3\, e^{-T_*/T_s}, \qquad T_* = \frac{h\nu_{21}}{k_B} \approx 0.068\ \mathrm{K}
$$

因为 $T_* / T_s \ll 1$($T_s$ 在几 K 到几百 K),展开 $e^{-T_*/T_s} \approx 1 - T_*/T_s$——**能级布居数差与 $1/T_s$ 成正比**。这正是所有耦合都以 $1/T$ 相加、而不是以 $T$ 相加的根本原因:每个物理过程都在"争夺"布居数比,而布居数比在 $1/T$ 空间是线性的,线性叠加才成立。

**第二步:列出布居数方程(统计平衡 = 详细平衡)。**

设单位时间内每个原子的**上→下**与**下→上**跃迁速率如下(引入 $n_1, n_0$ 表示粒子数密度,注意跃迁速率与粒子数密度的乘积是单位体积跃迁率):

| 过程              | 上→下(去激发)速率                                               | 下→上(激发)速率                            |
| ----------------- | ---------------------------------------------------------------- | ------------------------------------------- |
| 自发辐射          | $A_{10}$                                                       | —                                          |
| CMB 受激吸收/发射 | $A_{10}\bar n_\gamma$(受激发射)、$B_{10}\bar J_\gamma$(吸收) | 见右                                        |
| 碰撞              | $C_{10}$                                                       | $C_{01} = 3 e^{-T_*/T_k}C_{10}$(细致平衡) |
| Lyα 散射         | $P_{10}$                                                       | $P_{01}$(由色温 $T_c$ 决定)             |

其中 $\bar n_\gamma$ 是 CMB 在 21cm 频率处的光子占据数($\bar n_\gamma \approx k_B T_\gamma / h\nu_{21} \gg 1$,瑞利–金斯极限),$\bar J_\gamma$ 是 CMB 平均强度。**统计平衡**要求上下能级布居数不变:

$$
n_1\big(A_{10} + C_{10} + P_{10}\big) = n_0\big(B_{10}\bar J_\gamma + C_{01} + P_{01}\big)
$$

把 $n_1/n_0 = 3e^{-T_*/T_s}$ 代入统计平衡方程,并显式写出 CMB 受激发射项,逐步化简——这就是 **PL2012 式 8 的完整推导**(直接展开如下)。

**化简用到的三组关系**:

1. **爱因斯坦关系 + 瑞利–金斯极限**:统计权重使 $B_{01} = 3B_{10}$(由 $g_0B_{01} = g_1B_{10}$),且 $B_{10}\bar J_\gamma = A_{10}\bar n_\gamma$。CMB 在 21cm 频率的占据数

   $$
   \bar n_\gamma = \frac{c^2\bar J_\gamma}{2h\nu_{21}^3} = \frac{k_B T_\gamma}{h\nu_{21}} = \frac{T_\gamma}{T_*} \gg 1
   $$

   因此受激吸收率 $B_{01}\bar J_\gamma = 3A_{10}\bar n_\gamma$、受激发射率 $B_{10}\bar J_\gamma = A_{10}\bar n_\gamma$ 都统一写成 $A_{10}\bar n_\gamma$ 的倍数。
2. **细致平衡**:碰撞与 Lyα 的激发速率 = 去激发速率 × 玻尔兹曼因子:

   $$
   C_{01} = \frac{g_1}{g_0}\,e^{-T_*/T_k}C_{10} = 3\,e^{-T_*/T_k}C_{10}, \qquad P_{01} = 3\,e^{-T_*/T_c}P_{10}
   $$
3. **低温展开**:$T_* \ll T_s, T_k, T_c$ 时 $e^{-T_*/T} \approx 1 - T_*/T$(这正是"$1/T$ 线性叠加"能成立的代数前提)。

把上面"第二步"表格逐项代入,并把 CMB 受激发射 $A_{10}\bar n_\gamma$ 放到上→下侧,统计平衡方程成为:

$$
n_1\big(A_{10} + A_{10}\bar n_\gamma + C_{10} + P_{10}\big) = n_0\big(3A_{10}\bar n_\gamma + 3e^{-T_*/T_k}C_{10} + 3e^{-T_*/T_c}P_{10}\big)
$$

代入 $n_1/n_0 = 3e^{-T_*/T_s}$,两边同除以 $3$:

$$
e^{-T_*/T_s}\big(A_{10}(1+\bar n_\gamma) + C_{10} + P_{10}\big) = A_{10}\bar n_\gamma + e^{-T_*/T_k}C_{10} + e^{-T_*/T_c}P_{10}
$$

三处 $e^{-T_*/T} \approx 1 - T_*/T$ 同时展开,重排各项并合并 $A_{10}(1+\bar n_\gamma) - A_{10}\bar n_\gamma = A_{10}$:

$$
A_{10} - \frac{T_*}{T_s}\big[A_{10}(1+\bar n_\gamma) + C_{10} + P_{10}\big] + \frac{T_*}{T_k}C_{10} + \frac{T_*}{T_c}P_{10} = 0
$$

把 $1/T_s$ 项移到左边、其余移到右边,整体除以 $T_*\,A_{10}\,\bar n_\gamma$;此时瑞利–金斯极限 $\bar n_\gamma \gg 1$ 使 $1+\bar n_\gamma \approx \bar n_\gamma$:

$$
\frac{1}{T_s}\Big[1 + \frac{C_{10}}{A_{10}\bar n_\gamma} + \frac{P_{10}}{A_{10}\bar n_\gamma}\Big]
= \frac{1}{\bar n_\gamma}\frac{1}{T_*} + \frac{1}{T_k}\frac{C_{10}}{A_{10}\bar n_\gamma} + \frac{1}{T_c}\frac{P_{10}}{A_{10}\bar n_\gamma}
$$

最后一步用 $\bar n_\gamma = T_\gamma/T_*$(即 $1/\bar n_\gamma T_* = 1/T_\gamma$)把 CMB 项还原成 $1/T_\gamma$,并定义两个速率比 $x_{\mathrm{col}} \equiv C_{10}/(A_{10}\bar n_\gamma)$、$x_\alpha \equiv P_{10}/(A_{10}\bar n_\gamma)$,整理即得 **PL2012 式 8**:

$$
\frac{1}{T_s} = \frac{x_{\mathrm{col}}\,\dfrac{1}{T_k} + x_\alpha\,\dfrac{1}{T_c} + \dfrac{1}{T_{\mathrm{CMB}}}}{1 + x_{\mathrm{col}} + x_\alpha}
$$

其中两个速率比 $x_{\mathrm{col}} \equiv C_{10}/(A_{10}\bar n_\gamma)$(碰撞耦合系数)、$x_\alpha \equiv P_{10}/(A_{10}\bar n_\gamma)$(WF 耦合系数)即上一步推导最后引入的记号;它们的物理意义与量级见下文"第三步"。

> **这条公式的物理解读**:自旋温度 $T_s$ 不是某个单一过程决定的,而是**三个"温度源"按速率加权的调和平均**。权重就是各过程的"速率比"。哪个过程速率大,就把 $T_s$ 拉到它的温度:CMB 想拉向 $T_\gamma$,碰撞想拉向 $T_k$,Lyα 想拉向 $T_c \approx T_k$。**X-ray 的整个作用,就是通过抬高 $T_k$ 增大"碰撞/ Lyα"两路权重,从而把 $T_s$ 从 $T_\gamma$ 拽向 $T_k$。**

**第三步:三个系数的物理。**

- $x_{\mathrm{col}}$(代码 `xc_fast`):碰撞去激发速率 $C_{10}$ 与 CMB 光子作用速率之比,$C_{10} = n\,\kappa_{10}(T_k)$ 正比于气体密度。21cmFAST 拆成三项——中性氢碰撞 ∝ $(1-x_e)\,n_b$、电子碰撞(H–e⁻)∝ $x_e\, n_b$、质子碰撞(H–p⁺)∝ $x_e\, n_b$。**注意 H–e⁻、H–p⁺ 两项正比于电离分数 $x_e$:X-ray(及 UV)电离产生自由电子,会"顺带"增强碰撞耦合**——这就是 X-ray 影响 Ts 的第二条路径,但它不是独立的 $x_c$ 项,而是内嵌在 $x_{\mathrm{col}}$ 的 $x_e$ 依赖里(旧版手册里的独立 $x_c$ 记号在 21cmFAST 中并不存在,此处更正)。量级上,$z \gtrsim 25$ 时密度高、$x_{\mathrm{col}} \gg 1$,碰撞主导;$z \lesssim 15$ 时碰撞衰减,转而靠 Lyα 与 X-ray 加热。
- $x_\alpha$:Wouthuysen–Field 耦合。Lyα 光子把 HI 激发到 2P 态,自发辐射回基态时两个超精细子能级被"再分配",等效于把 $T_s$ 推向 Lyα 色温 $T_c \approx T_k$。$x_\alpha \propto J_\alpha$(Lyα 背景强度)。X-ray 次级电子的激发正好产生 Lyα(P3 的 Lyα 积分),所以 X-ray 还通过 Lyα 间接贡献 $x_\alpha$。
- CMB 项:文献常把分母写成 $1+x_{\mathrm{col}}+x_\alpha$,CMB 权重取 1。**21cmFAST 有一处额外修正**:CMB 项权重取 $x_{\mathrm{CMB}} = (1-e^{-\tau_{21}})/\tau_{21}$,即考虑 21cm 自身光学深度——当 $\tau_{21}$ 大(如 Lyα 散射强)时 CMB 光子难以穿透到该单元,CMB 耦合被压低。对应代码为:

$$
T_s = \frac{x_{\mathrm{col}} + x_\alpha + x_{\mathrm{CMB}}}{x_{\mathrm{col}}/T_k + x_\alpha/T_c + x_{\mathrm{CMB}}/T_{\mathrm{CMB}}}
$$

**定量标尺(PL2012 式 9–13)**:

- **碰撞耦合系数**:$x_c^{(i)} = \dfrac{C_{10}}{A_{10}}\dfrac{T_*}{T_\gamma} = \dfrac{n_i\,\kappa_{10}^{(i)}(T_k)}{A_{10}}\,\dfrac{T_*}{T_\gamma}$;速率系数标准拟合:
  - H–H 道($10<T_k<10^3$ K):$\kappa_{10}^{\mathrm{HH}} \approx 3.1\times10^{-11}\,T_k^{0.357}\,e^{-32/T_k}\ \mathrm{cm^3\,s^{-1}}$
  - e–H 道($T_k \le 10^4$ K):$\log_{10}\!\left(\kappa_{10}^{\mathrm{eH}}/\mathrm{cm^3\,s^{-1}}\right) = -9.607 + 0.5\log_{10}T_k\cdot\exp\!\left[-(\log_{10}T_k)^{4.5}/1800\right]$,更高温取 $10^4$ K 值
- **WF 耦合系数**(PL2012 式 11–13):$x_\alpha = \dfrac{4P_\alpha}{27A_{10}}\dfrac{T_*}{T_\gamma}$,散射率 $P_\alpha = 4\pi\chi_\alpha\int d\nu\,J_\nu\phi_\alpha(\nu)$,或写成 $x_\alpha = \dfrac{16\pi^2 T_* e^2 f_{\mathrm{osc}}}{27A_{10}T_\gamma m_e c}\,S_\alpha J_\alpha$($f_{\mathrm{osc}}$ 为 Lyα 振子强度,$S_\alpha \sim 1$ 为共振线附近光子分布形状修正)
- **临界条件**:耦合显著要求 $x_\alpha \sim 1$,对应临界 Lyα 通量 $J_\alpha^{\mathrm{C}} = 1.165\times10^{10}[(1+z)/20]\ \mathrm{cm^{-2}\,s^{-1}\,Hz^{-1}\,sr^{-1}}$,折合每个氢原子 $J_\alpha^{\mathrm{C}}/n_H = 0.0767[(1+z)/20]^{-2}$ 个 Lyα 光子——恒星开启后极易满足,所以 WF 耦合饱和得很快,这也是 $z_\alpha$ 与 $z_\star$ 接近的原因。

**色温(color temperature)与 WF 耦合的深层机制(PL2012 式 14)**:WF 耦合把 $T_s$ 推向的不是 Lyα 背景的"等效温度",而是**色温** $T_c$:

$$
\frac{h}{k_B T_c} = -\frac{d\ln n_\nu}{d\nu}
$$

其中 $n_\nu = c^2J_\nu/2\nu^2$ 是光子占据数。Lyα 光子反复散射时每次因原子反冲(recoil)损失能量 $\sim h\nu/m_p c^2$,频谱畸变在共振线附近形成不对称结构,把光子分布推向与气体的局地热平衡,使 $T_c \approx T_k$。**物理结论:无论碰撞还是 Lyα,两条耦合通道最终都把 $T_s$ 挂到 $T_k$ 上**——这正是"加热 $T_k$"(X-ray 的专长)能操控 21cm 信号的根本原因。

**第四步:为什么 X-ray 加热能翻转 21cm 信号。** 在 $z \gtrsim 15$ 的再电离前,绝热冷却的气体 $T_k \sim 5\text{–}20\ \mathrm{K}$,而 $T_{\mathrm{CMB}} \sim 2.7(1+z) \sim 40\text{–}55\ \mathrm{K}$。只要碰撞/Lyα 耦合显著,上式就把 $T_s$ 拉到 $T_k$ 附近($\ll T_{\mathrm{CMB}}$),产生强吸收。X-ray 加热把 $T_k$(从而 $T_s$)抬到 $T_{\mathrm{CMB}}$ 之上,信号翻转为发射——正是 P1 的"翻转点"。

### Tk 的演化——绝热冷却与 Compton 耦合

$T_k$ 是 P2 的"锚"。PL2012 式(15)给出其演化方程:

$$
\frac{dT_k}{dt} = \frac{2T_k}{3n}\frac{dn}{dt} + \frac{2}{3k_B}\sum_j \frac{\epsilon_j}{n}
$$

第一项是宇宙膨胀的**绝热冷却**($T_k \propto (1+z)^2$,使暗时代气体远冷于 CMB);第二项是各加热/冷却源 $j$ 的净贡献。下面把式(15) 从零推一遍——它只需要两个假设,**其余全是代数**。

**假设 1:单原子理想气体。** 氢、氦及其电离产物在 21cm 时代都是非相对论单原子粒子,每个粒子 3 个平动自由度,能量均分给出内能密度:

$$
U = \frac{3}{2}n k_B T_k \qquad\Longleftrightarrow\qquad \bar E_{\text{每粒子}} = \frac{3}{2}k_B T_k
$$

这个 $3/2$(及其倒数翻倍的 $2/3$)会一路贯穿到式(15) 的两个系数。

**假设 2:热力学第一定律(每单位体积)。** 气体团内能的变化 = 外界注入的净热量 − 它对外做的膨胀功:

$$
dU = \varepsilon\,dt - p\,dV, \qquad \varepsilon \equiv \sum_j \varepsilon_j
$$

其中 $\varepsilon$ 是单位体积、单位时间的净能量沉积率(加热为正、冷却为负)。

**第 1 步:展开内能 $dU$。** 注意 $n$ 不是常数——宇宙膨胀让密度变稀、电离让粒子数变多,两者都写进 $dn$:

$$
dU = \frac{3}{2}k_B\big(n\,dT_k + T_k\,dn\big)
$$

**第 2 步:把做功项 $p\,dV$ 翻译成密度语言。** 理想气体状态方程 $p = n k_B T_k$;质量守恒要求体积与密度反着变($dV/V = -dn/n$:膨胀 = 密度下降)。于是:

$$
p\,dV = (n k_B T_k)\cdot\frac{dV}{V} = (n k_B T_k)\cdot\Big(-\frac{dn}{n}\Big) = -k_B T_k\,dn
$$

> 直觉:膨胀时 $dn<0$,故 $-k_B T_k\,dn > 0$,气体对外做功、从内能里"扣能量"——这就是绝热冷却的物理来源。

**第 3 步:代入、消项、除系数。** 把第 1、2 步代入第一定律:

$$
\frac{3}{2}k_B\big(n\,dT_k + T_k\,dn\big) = \varepsilon\,dt + k_B T_k\,dn
$$

右边的 $+k_B T_k\,dn$ 与左边 $\frac{3}{2}k_B T_k\,dn$ 相消后剩 $\frac{1}{2}k_B T_k\,dn$:

$$
\frac{3}{2}k_B n\,dT_k + \frac{1}{2}k_B T_k\,dn = \varepsilon\,dt
$$

两边除以 $\frac{3}{2}k_B n\,dt$:

$$
\boxed{\;\frac{dT_k}{dt} = \frac{2T_k}{3n}\frac{dn}{dt} + \frac{2}{3k_B}\sum_j\frac{\varepsilon_j}{n}\;}
$$

第一项系数 $\frac{2}{3}$ 正是"每粒子 $3/2$ 个自由度"的倒数翻倍;第二项先把单位体积的能量沉积率 $\varepsilon_j$ 除以 $n$ 折成"每粒子",再乘 $\frac{2}{3k_B}$ 折成"温度"。

**第 4 步:为什么绝热冷却恰好是 $T_k \propto (1+z)^2$。** 无加热时($\varepsilon_j = 0$)式(15) 退化为 $dT_k/T_k = \frac{2}{3}\,dn/n$,积分得 $T_k \propto n^{2/3}$。宇宙膨胀中重子固有密度 $n \propto (1+z)^3$,所以:

$$
T_k \propto (1+z)^2 \quad(\text{绝热}),\qquad T_\gamma = 2.725(1+z)\,\mathrm{K}
$$

两者都随红移上升而下降,但气体比 CMB 降得快($T_k/T_\gamma \propto 1+z$)——这就是"暗时代气体越来越冷于 CMB"的代数根源,也是 21cm 吸收信号存在的热力学基础,更是 X-ray 必须**逆着绝热冷却**、把 $T_k$ 从远低于 $T_\gamma$ 抬到高于 $T_\gamma$ 的原因(回到 P0 时间表:加热期 $z_h$ 就是 $T_k$ 追上 $T_\gamma$ 的红移) 。

**第 5 步:式(15) 里"看不见"的两个修正(源码里有,推导中藏了)。** 式(15) 的 $n$ 是**当地单位体积的粒子数密度**,而 $T_k$ 是"每粒子的平均动能"。所以 $T_k$ 变化只有两条路:要么**每个粒子的动能变了**(第二项的加热/冷却 $\varepsilon_j$),要么**粒子数变了而总动能没变**——同一份动能摊给更多/更少的粒子。第一项 $(2T_k/3n)\,dn/dt$ 走的就是第二条路,而这条路上的 $n$ 变化来源**不止膨胀**,共有三个:

- **膨胀(空间被拉大)**:粒子总数不变,固有体积 $V \propto (1+z)^{-3}$ 变大 → $n = N/V$ 下降,气体对外做功 → 绝热冷却。这就是第 4 步讲的 $T_k \propto (1+z)^2$。
- **电离/复合(粒子裂变与合并)**:一个中性 H 电离成质子+电子,当地粒子数从 1 变 2 → $n$ 上升;复合则反向。总动能基本不变 → 每粒子平均动能被摊薄 → $T_k$ 下降。这就是下面的"电离稀释"。
- **结构形成(物质搬运)**:过密区 $\delta$ 生长、气体从周围流入 → 当地 $n$ 上升(压缩),低密区反之。这是工程手册 [E2](XRAY_engineering_manual.md#e2tk-与-ts-的演化get_ts_fast) 里 `dadia_dzp` 中 `dgrowth_dzp` 那一项的物理来源。

代码把这三条路径分开积分(`dadia_dzp` = 膨胀+结构,`dspec_dzp` = 电离),因为物理来源不同、数值步进精度需求不同。具体来看电离这条:

- **电离稀释**:每个 H 核的粒子数从 1 涨到 $1+x_e$,即 $n \propto 1+x_e$。若粒子总动能不变,粒子数变多 → 每粒子平均动能下降,即 $T_k \propto 1/(1+x_e)$。取对数微分得 $dT_k/T_k = -dx_e/(1+x_e)$,对应代码 `dspec_dzp = -dxe_dzp * rad->prev_Tk / (1 + rad->prev_xe)`(见工程手册 [E2](XRAY_engineering_manual.md#e2tk-与-ts-的演化get_ts_fast))。
- **Compton 加热**:第二项里最重要的一个 $j$,其 $\varepsilon_{\mathrm{Compton}}$ 的具体形式见下。

再电离前最重要的源:

| 源                   | 机制                                                                    | 有效范围                                                                   | 备注                                               |
| -------------------- | ----------------------------------------------------------------------- | -------------------------------------------------------------------------- | -------------------------------------------------- |
| Compton 加热         | CMB 光子散射残余自由电子($x_e \sim 10^{-4}$),电子再与重子碰撞传递能量 | $z \gtrsim 150$ | 把$T_k$ 耦合到 $T_\gamma$;设定恒星开启前的初始条件 |                                                    |
| Lyα 加热            | Lyα 散射反冲沉积                                                       | 需极大 Lyα 通量                                                           | 通常可忽略(PL2012 §3.4),21cmFAST 默认开启但贡献小 |
| **X-ray 加热** | 光电离 + 次级电子沉积                                                   | 源点亮之后                                                                 | **EoH 主加热机制**,见 P3–P5                 |

Compton 加热率(PL2012 式 24–25):

$$
\frac{2}{3}\frac{\epsilon_{\mathrm{Compton}}}{k_B n} = \frac{x_e}{1+f_{\mathrm{He}}+x_e}\,\frac{T_\gamma - T_k}{t_\gamma}\left(\frac{u_\gamma}{\bar u_\gamma}\right)(1+z)^4
$$

$$
t_\gamma^{-1} = \frac{8\bar u_\gamma\sigma_T}{3m_e c} = 8.55\times10^{-13}\ \mathrm{yr^{-1}}
$$

$z \gtrsim 150$ 时 Compton 项迫使 $T_k \to T_\gamma$;更低红移失效后气体转入绝热冷却,为 X-ray 加热留下"低温起点"(约 5–20 K)——X-ray 必须把 $T_k$ 从远低于 CMB 抬升到高于 CMB,这就是 P1 翻转点的全部物理。

## P3:X-ray 加热/电离速率——物理核心

这是 X-ray 物理的**心脏**。X-ray 光子能量(0.5–10 keV)远高于 HI/HeI 电离势(13.6/24.6 eV),单个 X-ray 光子电离原子后产生**高能次级电子**,次级电子再进一步电离、加热、激发 Lyα。分配比例由 **Shull & van Steenberg (1985)** 的解析拟合决定。

### 从光子能量到三份去向——一步步推被积函数

**第 1 步:一个 X-ray 光子的"能量预算"。**

X-ray 光子能量 $h\nu$(0.5–10 keV)远大于把原子电离所需的最小能量 $h\nu_i$(HI:13.6 eV,HeI:24.6 eV,HeII:54.4 eV)。当一个光子被物种 $i$ 吸收:

$$
h\nu = h\nu_i + E, \qquad E = h(\nu-\nu_i) > 0
$$

- $h\nu_i$:拆开电子–离子对,消耗掉(最终变成"阻止化学势差",不进入气体动能);
- $E$:**次级电子初始动能**,这才是后续一切分配的来源。

> 记牢:$E = h(\nu-\nu_i)$ 而不是 $h\nu$。这就是被积函数里出现 $(h\nu - h\nu_i)$ 的原因。

**第 2 步:次级电子把 $E$ 分成三份。**

次级电子在气体里减速时,能量沿三条通道流失(Shull & van Steenberg 1985 的蒙特卡洛结论;21cmFAST 用其拟合插值表):

| 通道            | 作用对象           | 能量去向       | 截面特征                                        |
| --------------- | ------------------ | -------------- | ----------------------------------------------- |
| 电离(可连锁)    | 束缚电子           | 新电子–离子对 | 需$E>13.6$ eV,截面在 $E\sim30$–100 eV 最大 |
| 激发(1s→2p 等) | 束缚电子           | Lyα 光子      | 需$E>10.2$ eV,截面在 $E\sim20$–40 eV 最大  |
| 库仑散射(e–e)  | **自由电子** | 气体热能(Tk)   | 任意$E$;能量损失率 ∝ $n_e$                 |

定义三份能量份额 $f_{\mathrm{heat}}(E,x_e)$、$f_{\mathrm{ion}}(E,x_e)$、$f_{\mathrm{Ly\alpha}}(E,x_e)$,满足:

$$
f_{\mathrm{heat}} + f_{\mathrm{ion}} + f_{\mathrm{Ly\alpha}} = 1
$$

(三者都依赖 $E$ 和当地电离分数 $x_e$——$x_e$ 决定自由电子多不多,从而决定库仑通道的强弱。)

**第 3 步:关键物理——$f_{\mathrm{heat}}$ 随 $x_e$ 增大而增大(而非减小)。**

- **中性介质**($x_e\to 0$):没有自由电子,库仑通道关闭,能量几乎全部消耗于电离与 Lyα 激发,$f_{\mathrm{heat}} \sim 0.15\text{–}0.3$。
- **电离介质**($x_e\to 1$):自由电子多,库仑散射频繁,动能连续转给热电子池,$f_{\mathrm{heat}}\to 1$。

这是 Shull & van Steenberg (1985) 蒙特卡洛模拟的经典结论,21cmFAST 的 `x_int_tables` 直接复刻:以 100 eV 电子为例,插值表中 $f_{\mathrm{heat}}$ 从 $x_e=10^{-4}$(几乎中性)时的 ~0.15 单调上升到 $x_e \approx 0.999$(几乎完全电离)时的 ~1.0。

**推论(修正常见直觉)**:X-ray 加热并非"早期(中性介质)效率更高"。纯中性介质里 X-ray 的能量大头花在电离与 Lyα 激发上;只有先电离出自由电子,后续 X-ray 的加热份额才升高——**X-ray 加热与再电离之间存在正反馈**。这也解释了为什么 21cmFAST 把 $x_e$ 作为插值表的第一维:同一能量的光子,在不同电离状态的介质里能量去向截然不同。

**第 4 步:把"单位体积、单位频率"的吸收率写出来。**

设到达目标点的 X-ray 背景强度为 $J_\nu$($\mathrm{erg\,s^{-1}\,cm^{-2}\,Hz^{-1}\,sr^{-1}}$),则单位体积每秒、在频率 $[\nu,\nu+d\nu]$ 内被物种 $i$ 吸收的能量(吸收能量率)为:

$$
d\varepsilon_i = 4\pi\, J_\nu\, n_i\,\sigma_i(\nu)\,d\nu
$$

($4\pi$ 来自对各向同性辐射方向积分;$n_i$ 是物种 $i$ 的数密度;$\sigma_i(\nu)$ 是其光电离截面。)这一份能量里,只有份额 $f_{\mathrm{heat}}$ 变成热。于是**加热率的微分形式**为:

$$
\frac{d\varepsilon_{\mathrm{heat}}}{d\nu} = 4\pi\,J_\nu \sum_{i=\mathrm{HI,HeI,HeII}} n_i\,\sigma_i(\nu)\,f_{\mathrm{heat}}\!\big(E(\nu),x_e\big)
$$

这正是 PL2012 式(26)的形式(把 $J_\nu$ 换成源发射率场并积分即得)。**注意**:这里的 $J_\nu$ 是"已经过传播衰减到达目标点"的背景,其由 P4/P5 给出;P3 只负责"给定 $J_\nu$ 后,吸收的能量怎么分"。

**第 5 步:把 $J_\nu$ 的谱形代进来(21cmFAST 的被积函数)。**

21cmFAST 中源 SED 是幂律谱 $L_\nu \propto \nu^{-\alpha_X}$,归一在参考频率 $\nu_0$(=`NU_X_THRESH`)处。则光子数谱 $N_\gamma \propto L_\nu/h\nu \propto \nu^{-\alpha_X-1}$。对每个物种 $i$,$n_i = X_i\,n_b\,(1-x_e^{(i)})$($X_i$ 为质量丰度,$1-x_e^{(i)}$ 为该物种可被电离的中性比例)。于是加热被积函数为:

$$
\frac{d\varepsilon}{d\nu} \propto \sum_{i=1}^{3} f_{\mathrm{heat}}\!\left(\frac{\nu-\nu_i}{\mathrm{eV}},\,x_e\right)\; h(\nu-\nu_i)\; X_i\; \left(1-x_e^{(i)}\right)\; \sigma_i(\nu)\; \left(\frac{\nu}{\nu_0}\right)^{-\alpha_X-1}
$$

**物理解读(从左到右逐因子)**:到达频率为 $\nu$ 的光子数为 $\propto\nu^{-\alpha_X-1}$(光子数谱);它被物种 i 吸收的概率 ∝ 丰度 $X_i$ × 中性比例 $(1-x_e^{(i)})$ × 截面 $\sigma_i(\nu)$;每次吸收产生动能 $h(\nu-\nu_i)$ 的次级电子,其中 $f_{\mathrm{heat}}$ 份额转化为气体加热。把频率从 $\nu_{\tau=1}$(P4)到 $\nu_{\max}$ 全部积分,即得总加热率。

**注意被积函数里两处 $x_e$ 依赖方向相反**:吸收概率 ∝ $(1-x_e)$ 随电离增强而**减小**,加热份额 $f_{\mathrm{heat}}$ 却随电离增强而**增大**——净加热率由二者乘积决定,这是"X-ray 加热与再电离正反馈"的数学来源。

(被积函数中每个符号的代码落点,见工程手册[E3:频率积分表](XRAY_engineering_manual.md#e3频率积分表被积函数-插值表)的映射表。)

#### 三类积分的物理差异

三张表对应同一吸收事件的三条能量去向,物理侧重不同:

| 项目     | 加热                                       | 电离                                                                                         | Lyα                            |
| -------- | ------------------------------------------ | -------------------------------------------------------------------------------------------- | ------------------------------- |
| 积分对象 | 每次吸收沉积的**能量**               | **净电离数**:1 次初级电离 + 次级电子连锁电离($F_i = 1 + \sum_j f^j_{\mathrm{nion}}$) | **Lyα 光子数**           |
| 能量因子 | $h(\nu-\nu_i)$(超出电离势的次级电子动能) | 无(按"吸收事件"计数)                                                                         | 无                              |
| 额外因子 | —                                         | —                                                                                           | 换算成通量(角度平均 + 红移因子) |
| 物理解读 | 次级电子 → 气体动能                       | "一个 X-ray 光子最终电离多少个原子"(连锁反应)                                                | 每次吸收产生多少 Lyα 光子      |

**电离的"+1"很关键**:它对应初级光电离本身,其余各项对应次级电子继续电离 HI/HeI/HeII——体现 X-ray 电离的**连锁反应**:一个高能光子可净产生多个电离。三份去向共用同一套次级电子能量分配(S&S85 拟合,以 $E$、$x_e$ 为双参数),只是按不同比例计到能量、粒子数、光子数上。

## P4:X-ray 传播——光学深度与自吸收

### 为什么 X-ray 传播必须"非局部"处理

**关键对比**:UV 电离光子的平均自由程 ≈ 电离光子数密度梯度尺度(局部);X-ray 光子的吸收截面小得多(截面 $\propto \nu^{-3}$),平均自由程可达上百 Mpc——**X-ray 是长程量**,一个网格点的加热来自视线方向几十个红移前的源。因此:

1. 不能像 UV 那样"就地吸收",必须沿视线积分光学深度;
2. 光子从发射到吸收经历了**宇宙学红移**:发射频率 $\nu_e$ 与到达频率 $\nu$ 的关系是 $\nu = \nu_e/(1+z)$(能量降低);
3. 沿途介质对高频更透明、对低频更不透明(截面 $\propto \nu^{-3}$),所以**低能 X-ray 走不远、高能 X-ray 走得远**——"频率越高,越能打穿宇宙"。

### 光学深度与自吸收下限的推导

**第 1 步:光学深度定义。**

从源红移 $z_p$ 到观测红移 $z$ 的视线光学深度(PL2012 式 27):

$$
\tau_X(\nu_0; z_p, z) = \int_{z}^{z_p} \frac{c\,dt}{d\tilde z}\, n_b(\tilde z)\, x_{\mathrm{HI}}^{\mathrm{fill}}(\tilde z)\, \bar\sigma_X\!\big(\nu_0(1+\tilde z),\, x_e(\tilde z)\big)\, d\tilde z
$$

- $\nu_0$:观测到的频率(在 z 处);发射频率是 $\nu_0(1+\tilde z)$,与 $\tilde z$ 处吸收截面匹配
- $c\,dt/d\tilde z$:红移步长 $dz$ 对应的共动路径($c\,dt/dz = c/[(1+z)H(z)]$)
- $n_b(\tilde z)$:重子数密度(共动)
- $x_{\mathrm{HI}}^{\mathrm{fill}}$:中性氢填充因子(源之间没有中性氢的地方不吸收)
- $\bar\sigma_X$:物种加权平均光电离截面(见 P3 的被积函数)

**物理解读**:这是"沿途每一小段红移都吸收一点点"的积分。吸收强度 = 途中中性氢柱密度 × 在该红移处(频率被红移成 $\nu_0(1+\tilde z)$)的光电离截面。

**第 2 步:自吸收下限 $\nu_{\tau=1}$。**

光学深度是频率的增函数:频率越低、截面越大、$\tau$ 越大。定义:

$$
\tau_X(\nu_{\tau=1}) \equiv 1
$$

物理意义:频率 $\nu < \nu_{\tau=1}$ 的光子平均在到达目标点前就被吸收殆尽(平均自由程 < 传播距离),**对目标点加热无贡献**。因此 P3 的频率积分从 $\nu_{\tau=1}$ 开始——**低于它的一切都被"宇宙本身"屏蔽了**。

> **核心——宇宙对 X-ray 的"低能屏蔽"**:积分下限 $\nu_{\tau=1}$ 随红移上升(更早更稠密的中性介质屏蔽更多低能光子),所以**越早期的 X-ray 加热越依赖高能(硬)X-ray**。这也解释了 P5 里 `NU_X_THRESH`(宿主星系自吸收)与谱指数 $\alpha_X$ 的协同:谱越陡(低能越多)或阈值越低,被屏蔽的部分越多,实际到达远方的高能光子越少。

## P5:X-ray 源场——从光晕到发射率

### 为什么用"光度—SFR 缩放"

X-ray 源(高能双星、微类星体、超新星遗迹、年轻恒星)都产生于恒星形成,因此**X-ray 光度正比于恒星形成率**是第一性原理的合理假设(PL2012 式 30):

$$
L_X^{\mathrm{tot}} = L_X^{\mathrm{norm}} \times \frac{\mathrm{SFR}}{M_\odot\,\mathrm{yr}^{-1}}\ \mathrm{erg\,s^{-1}}
$$

- $L_X^{\mathrm{norm}}$:每单位 SFR 的 X-ray 光度(常取 $10^{40}\,\mathrm{erg\,s^{-1}}$ 量级,对应"0.1–2 keV 硬 X-ray",见 PL2012 式 30 与 SRE 2010)
- 物理依据:高能双星(HMXB)与微类星体在星暴星系中随 SFR 同步增加;观测上近邻星暴星系的 $L_X$–SFR 关系散射约 0.4 dex

21cmFAST 的 `L_X` 参数即 $\log_{10}(L_X^{\mathrm{norm}})$,默认 `L_X = 40.5`(即 $10^{40.5}\,\mathrm{erg\,s^{-1}}$ per M☉/yr)。

### 源谱(SED)的归一化——`xray_prefactor` 的推导

**第 1 步:光子数谱与波段归一化。**

设源在频率 $\nu$ 的**能量光度**为 $L_\nu \propto \nu^{-\alpha_X}$。光度的定义波段是 $[\nu_0,\nu_{\mathrm{band}}]$,其中:

- $\nu_0$ = `NU_X_THRESH`(宿主星系自吸收阈值,默认 500 eV):低于它软 X-ray 在源内被吸收;
- $\nu_{\mathrm{band}}$ = `NU_X_BAND_MAX`(默认 2000 eV):光度积分上限(即"X-ray 波段"的高能端,0.5–2 keV)。

定义归一化常数 $A$:

$$
L_\nu = A\,\nu^{-\alpha_X},\qquad \text{约束:} L_X^{\mathrm{tot}} = \int_{\nu_0}^{\nu_{\mathrm{band}}} L_\nu\,d\nu = \int_{\nu_0}^{\nu_{\mathrm{band}}} A\,\nu^{-\alpha_X}\,d\nu
$$

解出 $A = L_X^{\mathrm{tot}}\dfrac{1-\alpha_X}{\nu_{\mathrm{band}}^{1-\alpha_X} - \nu_0^{1-\alpha_X}}$($\alpha_X \neq 1$)。注意归一化积分上限是 `NU_X_BAND_MAX` 而非积分上限 `NU_X_MAX`(10 keV):**"光度归一"与"积分范围"是两个独立的频率上限**——前者决定 SED 有多强,后者决定频率积分积到多高(见参数全景表)。

**第 2 步:为什么被积函数里是 $\nu^{-\alpha_X-1}$。**

被积的是**光子数×每光子能量**,即能量谱 $L_\nu \propto \nu^{-\alpha_X}$ 本身。但 21cmFAST 的被积函数写的是光子数谱权重 $\nu^{-\alpha_X-1}$(见 P3)。两者等价:光子数 $N_\gamma(\nu) \propto L_\nu/(h\nu) \propto \nu^{-\alpha_X-1}$;被积函数中"每个光子能量 $h\nu$"与"光子数谱中 $\nu^{-1}$"抵消,净效果仍是能量谱 $L_\nu \propto \nu^{-\alpha_X}$。**用光子数谱写被积函数、让每光子的能量因子显式出现,是为了配合次级电子能量分配($E=h(\nu-\nu_i)$)的插值表。**
