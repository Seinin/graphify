# 引力扰动

初始条件那张场记的是复合前后的图案，而塌缩、电离与辐射转移都发生在晚得多的红移上。这一块把图案接成随时间演化的物质场：密度按生长因子整体缩放，再在低分辨体元的尺度上做顶帽平均——缩放给出振幅，平均给出这张场实际能被下游使用的分辨率；速度场不是另一份独立信息，它由同一批扰动经线性连续性方程给出，纵向部分完全跟着密度走。

分工也很清楚：密度场是所有偏晚环节的底场（塌缩分数、电离与加热的源项、红移空间畸变都按它加权），速度场只管把视线方向的速度折进观测到的密度。代价写在用途里——体元尺度以下的起伏在这里完全不可见，下游拿到的是大尺度图案；真要用到小尺度速度，得另找一条路。另一处代价是近似本身的：Zel'dovich 搬粒子在小尺度会偏，二阶能把主要偏差补回来，但两者都停在准线性，初始红移以下的非线性演化不归这里管。

它在源码侧集中在 `PerturbedField.c` 一个文件里，入口是 `ComputePerturbedField`，输出两个——一张低分辨密度场与一张速度场（速度按需要只算视线方向那一个分量）。这篇文档顺着计算真实发生的次序写：先讲这块在链上做什么与它依据的物理，再落到代码上，然后是参数与陷阱；文末两节逐个交代两个成员的定位与落点，代码地图与论文出处收在末尾。公式、系数与行号均取自本仓当前源码。

## 一、这块在链上做什么

**一句话**：把初始条件那张按今天功率谱归一的密度场，接成随红移演化的物质密度场，并由同一批扰动给出速度场。

| | 内容 |
| :--- | :--- |
| 输入 | 初始条件盒子（初始密度场 $\delta_i$、两条拉格朗日位移场与相对速度）；目标红移 $z$；生长因子 $D(z)$ 与生长率 $\dot D/D$ |
| 输出 | 低分辨扰动密度场 $\delta(\mathbf x,z)$、低分辨速度场 $\mathbf v(\mathbf x,z)$ |
| 下游 | 密度场进塌缩分数、电离与加热的源项、红移空间畸变；速度场进红移空间畸变（只用视线分量） |
| 参数 | 无物理参数；形状由四个算法开关与上游选择决定（§四） |

**物理图像**：结构一直在长，但长的方式在准线性区非常省事——图案不变，振幅随时间整体放大。所以这一块不必重做动力学，只要把初始场乘上这段时间里长出来的倍数，再把小于分辨率的起伏抹掉，就是下游要的那张图。速度也是一步代数：密度在长，物质就朝密度高的地方流，流速由连续性方程直接给出，不必再解一次运动方程。

**为什么是独立一块**：它既不属于初始条件（那一步不读红移、不乘生长因子），也不属于晕与星系（那一步已经在讨论塌缩成团）。它在链上的位置就是"从这里开始有时间"——后面所有偏晚的环节都拿这一层的密度当底场、拿这一层的速度做畸变。

## 二、物理骨架

### 2.1 密度场：乘生长因子，再在体元尺度上平均

$$\delta(\mathbf x,z)=\frac{D(z)}{D(z_i)}\,\delta_{\rm hi}(\mathbf x)\ \ast\ W_{\rm cell},\qquad 1+\delta\ge 0$$

两步：先按生长因子之比把初始场缩放到目标红移，再与体元窗卷积。前者是准线性生长的全部内容——线性区里各模式独立增长，图案不动、振幅乘一个统一倍数；后者把体元尺度以下的起伏抹掉，留下的只有下游网格能承载的大尺度部分。

前提是平滑尺度仍落在准线性区：只要体元尺度大于非线性尺度，整张场就还是线性倍数的叠加，不必逐红移重做动力学。唯一的非线性动作是负总密度处截断到零——物理上不可能出现负质量，代价是空腔区被削平，所以这张场在偏高密度区准确、在空腔里是被压平的。

有一条岔路的物理不一样，落点却相同：不乘生长因子，而是把初始网格上的质量元按位移场**搬**到目标位置（Zel'dovich 近似，选到二阶时再加修正）。它把体元尺度以下的塌缩以质量堆积的形式保留下来，代价是搬完之后小尺度上会偏——两条路都只描述大尺度图案。

### 2.2 速度场：连续性方程把密度变成流速

$$\mathbf v_{\mathbf k}=i\,\frac{\mathbf k}{k^{2}}\,\frac{\dot D}{D}\,\delta_{\mathbf k},\qquad \mathbf v=\frac{\dot D}{D}\,\nabla\nabla^{-2}\delta$$

它是密度场的梯度：一阶微扰下流速无旋，纵向部分完全由密度的增长决定，横向部分在一阶为零。波数空间里速度正比于波数除以波数平方再乘生长率，转到实空间就是一步逆拉普拉斯卷积。直流模（$k=0$）必须单独置零——那里 $1/k^{2}$ 发散，而且整盒的平均密度本来就不该带来任何流动。

它不带来新信息，也不独立演化：密度一改，速度跟着改。局限在低分辨与线性两端——体元尺度以下的速度结构与晕内的非线性运动都不在其中，真要用到小尺度速度时得另算。

## 三、代码：算一张、抄一张

### 3.1 总装：`ComputePerturbedField` 的次序

整个块只有一条主线（`src/py21cmfast/src/PerturbedField.c:385-490`），顺序本身就是口径：

分配低分辨工作盒，开了高分辨再加一份高分辨工作盒与一份"留给速度用"的副本（`:408-427`）→ `make_density_grid` 算出一张 $1+\delta$ 或质量密度（`:429`）→ 走高分辨时 `assign_to_lowres_grid` 降采样（`:432-435`）→ 算法档位大于零时 `normalise_delta_grid` 把均值拉回 1 再减 1（`:436-438`）→ `smooth_and_clip_density` 平滑并保证 $\delta\ge-1$（`:441`）→ 逐格点抄进输出结构体（`:446-460`）→ 由副本算出速度分量（`:464-471`）。

三件事值得先记住：

- **高、低分辨是两条支路，不是两个阶段。** `PERTURB_ON_HIGH_RES` 决定工作盒尺寸与降采样走不走（`:415-435`），`PERTURB_ALGORITHM` 决定密度场是"乘生长因子"还是"搬粒子"（§3.2），两个开关各管一段。
- **"留给速度用"的副本在滤波之前抄。** 高分辨那条路在 `assign_to_lowres_grid` 里、动手滤波之前就把 k 空间密度场 `memcpy` 出来（`:151`）；低分辨那条路在 `smooth_and_clip_density` 里抄（`:235-237`）。所以速度派生自**未做体元平均**的那张场（§3.6）。
- **截断做在 $1+\delta$ 上**，也就是保证 $\delta\ge-1$（`:259-269`）。越界会在日志里点名前五处，再往后只计数。

### 3.2 两条路：乘生长因子，或把粒子搬过去

`make_density_grid`（`:24-134`）先按 `PERTURB_ON_HIGH_RES` 选工作尺寸：高分辨用 `DIM`、低分辨用 `HII_DIM`（`:32-54`）。选完尺寸，走哪条路由 `PERTURB_ALGORITHM` 决定：

- **档位为零——线性支**（`:65-80`）：一个乘法逐格点，`fft_density_grid = dicke(z) * ic_density`。初始条件里不乘生长因子，乘的就这一下。
- **档位大于零——搬粒子支**（`:81-133`）：先清零，再用 `move_grid_masses` 把初始网格上的质量元搬到目标网格（`:107`），累加用 `double` 存中间结果（注释写明是为了避免舍入误差，`:99-100`），最后搬回 `float`（`:114-127`）。

搬粒子那一步在 `map_mass.c:149-211`。位移量是"从初始时刻到目标红移长出来的那一段"：一阶用 $\Delta D=D(z)-D(z_i)$，二阶用 $-\tfrac37(D^{2}-D_i^{2})$，两者都除以盒子边长再乘目标网格数，换算成网格单位的位移（`:160-174`）；质量取该格在初始红移时的值 $1+\delta_i D_i$（`:205`），按八点 CIC 权重分散到邻近格点（`map_mass.c:57-60`，累加处带原子更新）。二阶项只在档位等于 2 时加（`:196-199`）。

一处容易看反的地方：搬粒子**总是**从高分辨的初始条件出发（密度固定取 `boxes->hires_density`，`:106-107`），高分辨与低分辨之分只体现在**目标网格**与位移场取哪一份上（`:36-53`）。

### 3.3 降采样：先顶帽滤波，再取中心值

`assign_to_lowres_grid`（`:136-177`）把高分辨盒降到低分辨：变换到 k 空间 → 把未滤波的 k 空间场抄给速度用（`:151`）→ 顶帽滤波 → 转回实空间 → 每个低分辨格点取高分辨对应位置的值并除以高分辨总格点数（`:161-176`）。

滤波半径取 `l_factor × BOX_LEN / HII_DIM`（`:154-155`），其中 `l_factor = 0.620350491`，也就是 $(4\pi/3)^{-1/3}$（`Constants.c:41`，`Constants.h:60` 的注释写明它的来路）——把体元等效成同体积的球，顶帽半径就取这个球的半径。取中心值而不是体元平均之所以可以接受，是因为已经先做了顶帽滤波：滤波后的场在体元内近似常数。

代码自己承认这段不整齐：两处 TODO 写着"网格副本的保存位置很别扭——随分辨率落在不同函数里，而且低分辨那份是在平滑之后才存的"（`:149-151`、`:233-235`）。读这段以实际调用次序为准，不要按 TODO 猜。

### 3.4 把质量密度变回对比度

`normalise_delta_grid`（`:179-209`）只做一件事：把"每个格点装了多少质量"变回"比平均多多少"。倍数按 `PERTURB_ON_HIGH_RES` 取 1 或低分辨格点数比高分辨格点数（`:187-190`）——低分辨时一个体元收了 $(DIM/HII\_DIM)^{3}$ 个初始格点的质量，均值不再是 1，要按体积比缩回去；缩完减 1（`:201-202`），就成了对比度。

### 3.5 平滑与截断：`smooth_and_clip_density`

`:211-278` 是密度场出炉前最后一道：转 k 空间 → 若开了 `SMOOTH_EVOLVED_DENSITY_FIELD`，用高斯滤波（滤波类型 2，半径取 `DENSITY_SMOOTH_RADIUS × BOX_LEN / HII_DIM`，`:220-226`）→ 低分辨率时把 k 空间场抄给速度用（`:235-237`）→ 转回实空间 → 逐格点除以低分辨总格点数，并把小于 $-1$ 的值截到 $-1+\varepsilon$（`:246-274`）。

这里除以格点数的原因和 §3.3 末尾那次一样：`dft.c` 里的正反变换就是两个裸的 FFTW 调用（`dft.c:18-72`），不带任何归一，谁调用谁补。归一补在变换前还是变换后是等价的，速度那条路补在变换前（§3.6）。

### 3.6 速度场：在 k 空间乘方向分量

`compute_perturbed_velocities`（`:280-383`）一次只算一个方向，三个分量算几个由调用方决定（`:464-471`）。核心动作是逐模的：

```c
                    if ((n_x == 0) && (n_y == 0) && (n_z == 0)) {  // DC mode
                        velocity_fft_grid[grid_index] = 0.0 + 0.0 * I;
                    } else {
                        velocity_fft_grid[grid_index] *=
                            dDdt_over_D * kvec[axis] * I / k_sq / n_r_pixels;
                    }
```

（`:337-342`。）这一乘就是 §2.2 那条式子：$\dot D/D$ 乘方向分量再除以 $k^{2}$，虚单位负责把梯度变成相移；末尾的 `/n_r_pixels` 是把逆变换缺的 $1/N$ 补在这里。生长率是算出来的差值：`ddickedt` 用 `(dicke(z+dz)-dicke(z))/dz` 再除 `dtdz` 数值求导（`cosmology.c:753-759`，函数里自称 lazy non-analytic form），不是解析式。

乘完若走高分辨且两套分辨率不同，先在 k 空间滤波到低分辨体元尺度（`:352-358`），再转回实空间、按 `resample_index` 取中心值写进低分辨速度数组（`:363-379`）。算几个分量：开了 `KEEP_3D_VELOCITIES` 就把 x、y 一起算，z 无条件算（`:464-471`）——红移空间畸变只需要视线方向那一个。

### 3.7 写进结构体的那一步

密度场算完还有一次搬运：把低分辨工作盒逐格点抄进 `perturbed_field->density`，索引从实空间顺序换成 FFTW 的实空间顺序（`:446-460`）。能查到位置的是这段搬运，物理发生在被搬的那份数组生成的时候——缩放、降采样、平滑与截断都在它之前（§3.2–§3.5）。

## 四、参数

本模块名下没有参数标签：$\delta(\mathbf x,z)$ 与 $\mathbf v$ 的输入全是上游量——初始密度场、生长因子与生长率、位移场与相对速度。能改它的是几处上游选择：初始红移（经 $\Delta D$ 与 $D(z)/D(z_i)$ 定长了多少）、功率谱归一（$A_s$ 或 $\sigma_8$，定涨落幅度）、随机种子（定实现），以及相对速度那一份所属的开关。所以这两张场是"给定条件就唯一确定"的场，参数扫描改的是它们的统计性质，不是算法。

改这块形状的是四个算法开关，它们不属物理参数：`PERTURB_ALGORITHM` 选线性缩放还是搬粒子（以及要不要二阶）、`PERTURB_ON_HIGH_RES` 选在哪个分辨率上算、`KEEP_3D_VELOCITIES` 决定速度算一个分量还是三个、`SMOOTH_EVOLVED_DENSITY_FIELD` 决定密度场要不要再高斯平滑一次。它们与 `DENSITY_SMOOTH_RADIUS` 一起，只改这张场的精度与代价，不改上游的物理。

## 五、陷阱

**一、本块不读初始红移以外的东西，也不自己造生长因子。** $D(z)$ 与 $\dot D/D$ 都来自 `cosmology.c`（`:699`、`:753`），本块只取用；初始条件那一步不乘生长因子，乘的就是 `PerturbedField.c:60-77` 这一处（§3.2）。

**二、搬粒子那条路看的是位移场的**差**，不是位移场本身。** 用的是 $D(z)-D(z_i)$ 与 $-\tfrac37(D^{2}-D_i^{2})$（`map_mass.c:160-174`）：初始红移选得晚，位移量就小。以为搬到的是"从零长到现在"，在换初始红移时会得到不一样的结果。

**三、速度场派生自未做体元平均的密度场。** 给速度用的 k 空间副本在顶帽滤波之前抄（§3.1 第二条），所以 $\mathbf v$ 与 $\delta$ 不是同一张场出的：拿两者逐格点比参数关系，会差一个体元尺度的滤波。

**四、直流模必须置零。** 本块唯一一处是速度那条乘除（`PerturbedField.c:337-338`）：凡是"除以 $k^{2}$"的位置都得单独处理，漏掉就是 nan 传染整盒（§3.6）。初始条件那几步里还有两处同类的置零，见「初始条件」那一篇。

**五、FFT 归一由调用方补，位置不统一。** `dft.c` 的 `dft_r2c_cube` 与 `dft_c2r_cube` 都是裸的 FFTW 调用（`:18-72`），密度那条路补在变换后（`PerturbedField.c:172`、`:257`），速度那条路补在变换前（`:341`）。自己接一段 k 空间算子时要自己决定补在哪，两处都补就会小一个 $1/N$。

**六、`normalise_delta_grid` 不是"再归一化一次"。** 它减 1 之前乘的倍数随分辨率变（§3.4），只能被调用一次；把它当成幂等的通用归一函数重复调用，得到的是负密度。

**七、搬到哪张网格由目标尺寸定，不由密度尺寸定。** 搬粒子总是从高分辨初始条件出发（§3.2 末），位移场取哪一份才随 `PERTURB_ON_HIGH_RES` 变。

### 一份最小检查清单

- 要比不同红移：确认初始红移没变（位移量是差值）。
- 怀疑速度不对：先看它派生自哪张副本（滤波前/后），再查直流模。
- 改了 `HII_DIM`：`normalise_delta_grid` 的倍数、滤波半径、平滑半径都跟着动。
- 在 k 空间加算子：自己补 $1/N$，并且处理 $k=0$。
- 这张场只有大尺度：体元尺度以下的起伏不在其中，别用它做小尺度断言。

## 六、δ(x) · 扰动密度场

它是这块交给下游的底场：同一批初始扰动先在低分辨体元的尺度上做顶帽平均，再随红移整体缩放，得到一张每个体元一个值的物质密度对比图（§2.1、§一 的表格）。平滑把体元尺度以下的起伏抹掉，所以塌缩分数、电离场与红移空间畸变拿到的都是这一张图。

代码上它分两处：算在 `ComputePerturbedField` 这条主线上（`PerturbedField.c:385-490`，缩放、降采样、平滑与截断依次走 §3.2–§3.5），写出的那一步是把低分辨工作盒逐格点抄进 `perturbed_field->density`（`:446-460`）。标注在真源里的落点就是这段搬运，索引从实空间顺序换成 FFTW 的实空间顺序。

**它的位置是底场，局限在分辨率。** 所有偏晚的环节都按它加权，因此它一改，整条链的空间图案跟着改；而体元尺度以下的结构在这里完全不可见，下游用它近似源项，得到的只能是大尺度图案。

**名下没有参数**（§四）：改它的是初始红移、功率谱归一、随机种子与那几个算法开关。论文出处：无登记的节号（见文末）。

## 七、v(x) · 低分辨速度场

它是同一批扰动的另一面：由线性连续性方程给出，纵向部分就是密度场的梯度（§2.2），给出每个体元中心处的流速。三个分量、逐格点，但通常只需要视线方向那一个——红移空间畸变只把视线速度折进观测到的密度。

代码上它由 `compute_perturbed_velocities`（`PerturbedField.c:280-383`）一次一个方向地算：k 空间乘 $\dot D/D$ 与 $k_i/k^{2}$ 并补上 $1/N$（`:337-342`），滤波到低分辨尺度（`:352-358`），转回实空间后取中心值写进对应分量数组（`:363-379`）。算几个分量由 `ComputePerturbedField` 在 `:464-471` 决定：开了 `KEEP_3D_VELOCITIES` 就三个都算，否则只算 z。

**它与密度场同源，不是独立信息。** 密度一改它就改，也不会比密度多出小尺度内容；因此它在链上只管畸变那一件事。**名下没有参数**（§四）：能间接改它的是功率谱归一、初始红移与宇宙学参数经生长率进入的那一项——它的幅度会显形在功率谱上。论文出处：无登记的节号（见文末）。
