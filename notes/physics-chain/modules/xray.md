# X 射线源的历史卷积

源块给出的是每个格点、每个红移上的发光量，而 X 射线与莱曼-α 这两条线要的都不是"此刻此地发了多少"，而是"此前各时刻发出的光，经沿途吸收后还剩多少落在这里"。这一块因此只做两件事：把源按尺度抹开，再把抹开的源沿红移累加。抹开的尺度由平均自由程定——软光子在本地就被吸收，硬光子能穿过整个电离泡，代码用一条平均光程把两者的差别合成一个尺度。

三样产出各有用处：过滤后的 X 射线源供气体热那张账分装（加热、电离与莱曼-α 三份从同一趟频积分里分），过滤后的恒星形成率场供莱曼-α 背景，体积平均的恒星形成率则是一个诊断数——用来把网格化的幅度校准回解析平均。前两样共用同一套壳层，所以两条线在空间上是同源的，改一处平滑尺度，两条一起动。

## 过滤后的 X 射线源 · X 射线源的历史卷积（加热源）

### 物理

这是把 X 射线源折成能量沉积的那一步：先对每个滤波半径做环带平均，得到该尺度上被平滑过的源，再把源随时间按光程衰减后沿红移累加，一直积到当前红移为止。它记的是整段历史——每往上加一层就多算一层壳层，所以它是到该红移为止的卷积，带着记忆。

公式是一个双重积分：外层对红移积分，把每一层发出的 X 射线按时间间隔与光程衰减折算后叠加；内层对频率积分，用光子能量超过阈值的余量给权重。前提是 X 射线在传播中只被中性氢吸收、且源谱取平均形状——吸收用当前的中性氢份额估计光程，源谱被压成一条比光度。

它读入逐格点的 X 射线源与剩余中性氢给出的光程，红移既是积分变量也是上界；频积分的结果再按预先算好的份额表分装到加热、电离与莱曼-$\alpha$ 三处。因为源与吸收用的是同一张场，这一步把源的强度与环境的屏蔽耦合起来——源亮的地方未必沉积得多，光程长的壳层贡献会被压低。

数学上它是历史卷积，非线性地依赖源的历史与中性氢的演化，而且是空间非局域的：一个格点上的加热率取决于整段过去的源与沿途的吸收。它对 X 射线归一本身是线性的，但在观测量里与电离效率、恒星形成效率彼此简并——加热幅度可以由好几个因子同时搬动。

它把 X 射线源折成加热率与部分电离，是气体热与自旋温度两条线的输入，莱曼-$\alpha$ 背景也从同一趟频积分里分走一份。局限在壳层近似与平均光程：真实的 X 射线输运随能量有很强的穿行差异，硬光子能穿过整个电离泡、软光子则在本地就被吸收，被一条平均光程抹平之后，加热的空间形状会比真实更平滑。

$$\varepsilon_X(\mathbf x,z)=\int_{z}^{z_{\max}}\mathrm dz^{\prime}\frac{\mathrm dt}{\mathrm dz^{\prime}}\int_{\nu_{\min}}^{\nu_{\max}}\mathrm d\nu\,(\nu-\nu_{\rm th})\,\frac{L_\nu}{4\pi r^{2}}\,e^{-\tau(\nu)}$$

### 代码解析

这一步落在 `SpinTemperatureBox.c` 的 `UpdateXraySourceBox`（765–767 行）：它把逐格点的 X 射线源 `halobox->halo_xray` 交给 `one_annular_filter` 做一次环形滤波，结果写进 `source_box->filtered_xray` 里编号为 `R_ct` 的那一层——一层一张场，`R_ct` 就是壳层编号，号越大代表越远的壳。滤波本身在波数空间做：按该壳层对应的尺度截断再变换回实空间，所以留下的是"这个尺度内总共发了多少 X 射线"，而不是邻近几个格点的局部平均。

写着滤波的这三行只是卷积里的一次壳层取样：沿红移往上走，每一层都要这样铺一张场，最后按时间间隔与光程衰减把各层叠起来。看代码时把 `R_ct` 认成"历史里的一层"而不是"一个空间位置"就不会迷路。

### 工程

- `src/py21cmfast/src/SpinTemperatureBox.c:765-767`

```c
        one_annular_filter(halobox->halo_xray,
                           &(source_box->filtered_xray[R_ct * HII_TOT_NUM_PIXELS]), R_inner,
                           R_outer, &xray_avg, &fxray_avg);
```

- 输入：X 射线源网格、壳层半径 $R$ 与剩余中性氢给的光程；上游为 source_grid
- 产出：逐壳层累加的历史卷积结果（X 射线源的骨架）

### 参数语境

本篇名下没有参数标签：它把 X 射线源网格按壳层与光程做历史卷积，输入来自上游（源强、壳层半径、剩余中性氢给的光程）。因此能改它的是源侧与谱侧那一组参数——`L_X`、`L_X_MINI`（源强）、`NU_X_THRESH`、`NU_X_BAND_MAX`、`NU_X_MAX`、`X_RAY_SPEC_INDEX`（谱形与积分窗口），以及 `N_STEP_TS`、`R_MAX_TS`（壳层划分）。这些参数的语境记在加热率那一篇，这里只是把它们的乘积摊到各壳层上。

## ρ̇*_R(x) · 环形滤波后的恒星形成率场

### 物理

滤波后的恒星形成率场是与 X 射线源走同一趟环带滤波的结果：在各层上把恒星形成率密度按环带累加，得到该尺度上被平滑过的源。它逐红移一张，供莱曼-$\alpha$ 背景与气体热演化取用。

滤波在波数空间完成：按环带对应的尺度做一个截断再变换回实空间，所以它反映的是在这一尺度内能看到多少恒星形成。公式是一次壳层平均，权重就是壳层体积；它与 X 射线那条链共用同一套壳层，两条场因此严格同源、只是权重不同。

它是中间量而不是观测量：平滑的尺度由平均自由程决定，尺度一改，源的对比度就跟着变——小尺度噪声被抹平，剩下的是大尺度图案。局限在它只按固定的环带尺度做平均，而真实的莱曼-$\alpha$ 输运是各向异性的多次散射，这一步用各向同性的壳层平均近似它。

$$\bar{\dot\rho}_\star(R,\mathbf x)=\frac{1}{V_{\rm shell}}\int_{R_{\rm in}}^{R_{\rm out}}\dot\rho_\star(\mathbf x^{\prime})\,\mathrm d^{3}x^{\prime}$$

### 代码解析

同一趟滤波在 762–764 行又作用了一次，这次入口场换成 `halobox->halo_sfr`，出口写进 `source_box->filtered_sfr` 的同一层 `R_ct`。两处调用挨着写，正是"两条线同源"这句话在代码里的样子：壳层半径、滤波函数、层编号全一样，只有输入的场不同。

它也是理解莱曼-α 背景的关键一步——背景强度吃的是这张平滑过的源，而不是逐格点的恒星形成率，所以平滑尺度一旦改动，莱曼-α 涨落的空间图案会跟着变，X 射线的加热尺度也一起变。

### 工程

- `src/py21cmfast/src/SpinTemperatureBox.c:762-764`

```c
        one_annular_filter(halobox->halo_sfr,
                           &(source_box->filtered_sfr[R_ct * HII_TOT_NUM_PIXELS]), R_inner, R_outer,
                           &sfr_avg, &fsfr_avg);
```

- 输入：各层的 $\dot\rho_\star$ 与壳层区间 $[R_{\rm in},R_{\rm out}]$
- 产出：环壳滤波后的 $\bar{\dot\rho}_\star(R,\mathbf x)$

### 参数语境

本篇名下没有参数标签：它是对上游源网格做一趟环壳滤波，输入是各层的恒星形成率与壳层区间。壳层怎么分由 `N_STEP_TS`（层数）与 `R_MAX_TS`（半径上界）设定，幅度则完全由源侧参数决定。也就是说，这里能做的是把已经算好的源按尺度摊开，本身不引入新的物理选择。

## ⟨ρ̇*⟩ · 恒星形成率的体积平均

### 物理

恒星形成率的体积平均是同一趟滤波顺带给出的一个数：把整盒的恒星形成率密度求和再除以体积，每个红移存下一个值。它不携带空间结构，只供恒星形成率密度的自洽修正项使用。

它是一次全域平均：对同一张逐格点的源场求和，结果对源项的整体幅度线性、对分辨与滤波方式不敏感。把它与解析积分给出的平均值对照，可以用来判断有限分辨、滤波与网格化是否引入了偏差。

它是诊断量而非链条上的传递量：源项网格已经提供了逐格点的场，这个平均数只用来把网格化的幅度校准回解析平均。局限在平均本身——平均值相同并不代表在尺度上的分布相同，所以它只能校幅度，校不了图案。

$$\langle\dot\rho_\star\rangle(z)=\frac{1}{V}\int_V \dot\rho_\star(\mathbf x)\,\mathrm d^{3}x$$

### 代码解析

这个数不是另算一遍全场求和，而是拾起滤波函数顺带返回的平均值：769 行把 `fsfr_avg` 直接存进 `source_box->mean_sfr[R_ct]`，逐红移攒成一个数组。`one_annular_filter` 在给出滤波场的同时也算出了它的平均，环带平均本来就是一种体积平均，这里只是把同一个数留了下来。

看代码时容易把它当成另一项独立计算而找错地方——它没有自己的循环，就在恒星形成率滤波那两行的下面。

### 工程

- `src/py21cmfast/src/SpinTemperatureBox.c:762-769`

```c
        one_annular_filter(halobox->halo_sfr,
                           &(source_box->filtered_sfr[R_ct * HII_TOT_NUM_PIXELS]), R_inner, R_outer,
                           &sfr_avg, &fsfr_avg);
        one_annular_filter(halobox->halo_xray,
                           &(source_box->filtered_xray[R_ct * HII_TOT_NUM_PIXELS]), R_inner,
                           R_outer, &xray_avg, &fxray_avg);

        source_box->mean_sfr[R_ct] = fsfr_avg;
```

- 输入：同一趟滤波的各层 SFRD
- 产出：体积平均 $\langle\dot\rho_\star\rangle$，逐红移存下

### 参数语境

本篇名下没有参数标签：平均值来自同一趟滤波的各层恒星形成率，本身没有可调量。它的水平由源侧参数（恒星形成效率、截断质量、迷你晕开关等）决定，但它的角色是"全局参照"——X 射线与莱曼-$\alpha$ 的全局量与局域量都拿它做比较基准，所以它的口径（是按体积平均还是按质量加权）比它的数值更值得注意。

## 参数

本模块不携带参数：这块把已经算好的 X 射线源按壳层与光程做历史卷积、把源网格按环壳摊开，输入是源强、壳层半径与剩余中性氢给的光程，本身不引入新的物理选择。能改它的参数全在源侧与谱侧——`L_X`、`L_X_MINI`（源强），`NU_X_THRESH`、`NU_X_BAND_MAX`、`NU_X_MAX`、`X_RAY_SPEC_INDEX`（谱形与积分窗口），以及 `N_STEP_TS`、`R_MAX_TS`（壳层划分）——这一组参数的语境记在加热率那一篇。
