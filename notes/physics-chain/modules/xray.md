# X 射线源的历史卷积

源块给出的是每个格点、每个红移上的发光量，而 X 射线与莱曼-α 这两条线要的都不是"此刻此地发了多少"，而是"此前各时刻发出的光，经沿途吸收后还剩多少落在这里"。这一块因此只做两件事：把源按尺度抹开，再把抹开的源沿红移累加。抹开的尺度由平均自由程定——软光子在本地就被吸收，硬光子能穿过整个电离泡，代码用一条平均光程把两者的差别合成一个尺度。

三样产出各有用处：过滤后的 X 射线源供气体热那张账分装（加热、电离与莱曼-α 三份从同一趟频积分里分），过滤后的恒星形成率场供莱曼-α 背景，体积平均的恒星形成率则是一个诊断数——用来把网格化的幅度校准回解析平均。前两样共用同一套壳层，所以两条线在空间上是同源的，改一处平滑尺度，两条一起动。

它在源码侧落在自旋温度那一个文件里：滤波与落盘是 `UpdateXraySourceBox`，沿红移的叠加却发生在 `ComputeTsBox` 的壳层循环里（§3.3）——这一层最容易被找错的地方就在这里。这篇文档先讲它在链上做什么与依据的物理，再按"一次滤波、一趟落盘、一趟累加"的次序落到代码上，然后是参数与陷阱；文末三节逐个交代三个成员的定位与落点，代码地图与论文出处收在末尾。公式、系数与行号均取自本仓当前源码。

## 一、这块在链上做什么

**一句话**：把逐格点、逐红移的源，按尺度抹开并按光程沿历史累加，折成气体热与莱曼-α 能用的那几张场。

| | 内容 |
| :--- | :--- |
| 输入 | 各红移的源盒子（X 射线源、恒星形成率，开了迷你晕再加一份）；壳层半径序列 $[R_{\rm in},R_{\rm out}]$；当前电离份额 |
| 输出 | 逐壳层的过滤后 X 射线源 $\varepsilon_X$ 与逐壳层的过滤后恒星形成率 $\bar{\dot\rho}_\star(R,\mathbf x)$；一个逐红移的体积平均值 |
| 下游 | 气体热与自旋温度：由过滤后的源与频率积分表折出加热、电离与莱曼-α 三份 |
| 参数 | 无参数标签；形状由源侧与壳层划分决定（§四） |

**物理图像**：X 射线从源到气体要走过一段光程，所以这一步不能只看当前时刻。做法是把历史切成若干壳层，每一层先按该层的尺度把源平均一遍，再按该层到现在的距离与沿途吸收折算一次，最后把各层加起来。加上去的每一层都带着"那时光有多亮、路有多长、挡了多少"——这就是"历史卷积"四个字的含意。

**为什么是独立一块**：源块只管把晕里的恒星与气体折算成逐格点的发光量，不含任何传播；而气体热与自旋温度要的是沉积量。两者之间隔着尺度与时间两件事，都在这块完成。它也是气体热账上唯一的加热入口——那张账上的其它项要么是原初的、要么是复合与绝热，只有 X 射线这一项来自这里。

## 二、物理骨架

### 2.1 先按尺度抹开源：环壳平均

$$\bar{\dot\rho}_\star(R,\mathbf x)=\frac{1}{V_{\rm shell}}\int_{R_{\rm in}}^{R_{\rm out}}\dot\rho_\star(\mathbf x^{\prime})\,\mathrm d^{3}x^{\prime}$$

一个壳层一张场：把环带内的源按体积权重平均，得到"在这个尺度上总共发了多少"的图。尺度不是随便取的——它代表光子在到达之前大致能走多远，所以软光子对应小尺度（本地吸收）、硬光子对应大尺度（穿过电离泡）。真实输运随能量的这种差异被压成一条平均光程，代价是加热的空间形状比真实更平滑。

### 2.2 再沿红移累加：有记忆的卷积

$$\varepsilon_X(\mathbf x,z)=\int_{z}^{z_{\max}}\mathrm dz^{\prime}\frac{\mathrm dt}{\mathrm dz^{\prime}}\int_{\nu_{\min}}^{\nu_{\max}}\mathrm d\nu\,(\nu-\nu_{\rm th})\,\frac{L_\nu}{4\pi r^{2}}\,e^{-\tau(\nu)}$$

外层对红移积分：每一层发出的光按时间间隔折算、按光程衰减后叠加；内层对频率积分：用光子能量超过阈值的余量给权重。吸收用当前的中性氢份额估计光程，源谱被压成一条比光度（谱指数只管振幅随红移的整体缩放）。

因此它是**历史卷积**而不是瞬时量：它非线性地依赖源的历史与中性氢的演化，而且是空间非局域的——一个格点上的加热率取决于整段过去的源与沿途的吸收。它对 X 射线归一本身是线性的，但在观测量里与电离效率、恒星形成效率彼此简并：加热幅度可以由好几个因子同时搬动。

## 三、代码：一次滤波、一趟落盘、一趟累加

### 3.1 `one_annular_filter`：一趟滤波给两张场

`one_annular_filter`（`SpinTemperatureBox.c:650-747`）吃一张实空间源场，给出三样东西：滤波后的场、未滤波的平均值、滤波后的平均值。步骤是一条标准的 FFT 回路：

把实空间图按 FFTW 的实空间索引抄进工作盒并顺带累加未滤波平均（`:664-681`）→ 若 `HII_DIM > 1`，变换到 k 空间（`:686-687`）→ 除以总格点数补上 $1/N$（注释写明"先不加 VOLUME 因子，因为下面还有逆变换"，`:689-696`）→ 复制一份 → `R_inner > 0` 时用球壳滤波（滤波类型 4，内外半径都由调用方给，`:704-705`）→ 转回实空间（`:709-710`）→ 逐格点写回实空间索引、把负值截到零（注释写着"correct for aliasing in the filtering step"，`:729-730`），同时累加滤波后的平均（`:732-733`）→ 两个平均各自除以格点数（`:739-740`）→ 输出（`:742-743`）。

两个特例值得记住：`HII_DIM == 1` 时整段 FFT 跳过（`:683`），滤波后的场就取原格点值（`:724-727`）；`R_inner == 0` 时不做滤波（`:704`），最小那一层是原场。

### 3.2 逐壳层落盘：`UpdateXraySourceBox`

`UpdateXraySourceBox`（`:751-798`）一次只管一层。它挨着调两次同一个滤波：

```c
        one_annular_filter(halobox->halo_sfr,
                           &(source_box->filtered_sfr[R_ct * HII_TOT_NUM_PIXELS]), R_inner, R_outer,
                           &sfr_avg, &fsfr_avg);
        one_annular_filter(halobox->halo_xray,
                           &(source_box->filtered_xray[R_ct * HII_TOT_NUM_PIXELS]), R_inner,
                           R_outer, &xray_avg, &fxray_avg);

        source_box->mean_sfr[R_ct] = fsfr_avg;
```

（`:762-769`。）入口场一个是恒星形成率、一个是 X 射线源，出口写进同一层 `R_ct` 的两个数组——两处调用挨着写，正是"两条线同源"在代码里的样子：壳层半径、滤波核、层编号全一样，只有输入的场不同。`R_ct` 是壳层编号，`&array[R_ct * HII_TOT_NUM_PIXELS]` 就是"一层一张整场"。开了迷你晕再加第三次调用（`:771-773`），并把那一层的阈值质量一起存下（`:776`）。

函数注释写明这条设计：每个尺度用**不同的红移**，所以滤波没法一次全做完（`:749-750`、`:684-685`）。

### 3.3 累加那一趟在自旋温度那一段

沿红移的叠加不在上面两个函数里，而在 `ComputeTsBox` 的壳层循环（`:1566` 起）：从最外一层往回走，每一层把该层的源乘上时间权重 `z_edge_factor`（随 `SOURCE_MODEL` 取不同形式，`:1570-1576`）与谱指数因子 $(1+z'')^{-X\_RAY\_SPEC\_INDEX}$（`:1578`），再按预积分表把这份源拆成三份累加：

```c
                    if (astro_options_global->USE_X_RAY_HEATING) {
                        dxheat_dt_box[box_ct] +=
                            xray_sfr * (freq_int_heat_tbl_diff[xidx][R_ct] * ival +
                                        freq_int_heat_tbl[xidx][R_ct]);
                    }
                    dxion_source_dt_box[box_ct] +=
                        xray_sfr *
                        (freq_int_ion_tbl_diff[xidx][R_ct] * ival + freq_int_ion_tbl[xidx][R_ct]);
                    dxlya_dt_box[box_ct] += xray_sfr * (freq_int_lya_tbl_diff[xidx][R_ct] * ival +
                                                        freq_int_lya_tbl[xidx][R_ct]);
```

（`:1703-1712`；`xray_sfr` 在 `SOURCE_MODEL > 1` 时由 `filtered_xray` 得出，否则由过滤后的塌缩分数乘恒星形成效率与 `L_X` 得出，两条支路在 `:1672-1685`。）表的行号 `xidx` 取的是该格点当前的中性氢份额（`:1701`）——这一处就是"沿途吸收"：同一个源，挡得多的地方沉积得少。

同一段循环里还累加了莱曼-α 背景与恒星辐射那一组（`:1697-1720`）。代码注释解释了为什么要用这么多增量盒子而不是一层一个盒子：一是让省内存模式能把 $\sim 40$ 张场压到几张，二是先铺盒子再按壳层求和更快（`:1666-1670`）。

### 3.4 频率积分表：吸收被预先算进表里

频积分不是每次现算，而是预先按（电离份额 × 壳层）造表：`fill_freqint_tables`（`:804` 起）逐行填一张 $[x_e][R_{ct}]$ 的表，之后每次累加只是查表与线性插值。表头注释写明两条口径：这些表**一直是**按电离份额插值的（与开关无关），而且频率积分用的是**上一**快照的体积平均电离份额（`:801-803`）。省内存模式下每轮只填一行（`:810-816`）。所以"吸收"这件事在代码里的样子是一张查表，不是当场积分。

## 四、参数

本模块名下没有参数标签：这块把已经算好的源按壳层与光程摊开，输入是源强、壳层半径与当前电离份额，本身不引入新的物理选择。能改它的参数全在源侧与壳层划分——`L_X`、`L_X_MINI`（X 射线归一）、`NU_X_THRESH`、`NU_X_BAND_MAX`、`NU_X_MAX`、`X_RAY_SPEC_INDEX`（积分窗口与谱形）、`N_STEP_TS`、`R_MAX_TS`（壳层数与半径上界），外加上游的 `SOURCE_MODEL`（决定源是过滤后的网格还是当场由塌缩分数算）。这一组参数的语境记在「气体热与自旋温度」那一篇，这里只是把它们的乘积摊到各壳层上。

## 五、陷阱

**一、这块不产生源，只把源摊开。** 源在「网格化源项」那一篇；在本块里找"恒星怎么变成 X 射线"会一无所获，这里只有尺度与时间。

**二、沿红移的累加不在名下这两个函数里。** `UpdateXraySourceBox` 看上去只是逐层滤波，真正把层叠成"历史"的是 `ComputeTsBox` 的壳层循环（§3.3）。按函数名找卷积会找错地方。

**三、频率积分表用的是上一快照的电离份额。** 表头注释明写（`:801-803`），电离份额变化快时这一处是滞后来源；把表当成"当下吸收"会在电离前缘附近判错。

**四、`mean_sfr` 是滤波后的平均，而且当前没有读取方。** 写进盒子的 `fsfr_avg` 是**滤波后**那一个；同一个函数还返回未滤波的平均 `sfr_avg`，只进日志、没有存下（`:769`、`:781-783`）。而 C 侧没有任何地方读 `source_box->mean_sfr`——自旋温度那一段用的是自己解析算出的平均值 `EvaluateSFRD`（`:1604`、`:987`）。它是产物里的一个字段，目前的角色是诊断。

**五、`HII_DIM == 1` 时滤波整段失效。** 此时"过滤后的场"就是原场（`:683`、`:724-727`），盒子里所有壳层完全一样——单格点测试里不能拿它验证尺度效应。

**六、`R_inner == 0` 的那一层没有滤波。** 第一个壳层走的是不滤波的分支（`:704`），所以它的"过滤后"等于未过滤；把这些层放在一起比较尺度效应时要记得这一层的定义不一样。

**七、这个盒子很大，且逐壳层存整场。** 一层一张 `HII_TOT_NUM_PIXELS` 的场，乘以壳层数再乘以场数，是全链最占内存的中间量之一——分析它时优先考虑要不要整盒读入。

### 一份最小检查清单

- 要看"过滤后的源"：确认壳层编号，`R_ct` 是历史里的一层，不是空间位置。
- 想改平滑尺度：改 `N_STEP_TS` 与 `R_MAX_TS`，预期 X 射线与莱曼-α 的空间图案一起变。
- 追踪加热幅度：源侧归一（`L_X`）与谱形（`X_RAY_SPEC_INDEX`）都要看，它们与电离效率简并。
- 单格点测试里不要用过滤后的场验证尺度效应（§五 第五条）。

## 六、过滤后的 X 射线源 · X 射线源的历史卷积（加热源）

它是这块的头号输出，也是气体热账上唯一的加热入口（§一 表格）。把各尺度的 X 射线源折成能量沉积要两步：先在每个壳层上把源平均（§2.1），再把这个平均值按该层的光程与时间间隔折算后沿红移累加（§2.2）。因此它记的是整段历史，带着记忆。

代码上它分两段落点。落盘在 `UpdateXraySourceBox`（`SpinTemperatureBox.c:765-767`）：把逐格点的 X 射线源交给 `one_annular_filter`，结果写进 `source_box->filtered_xray[R_ct * HII_TOT_NUM_PIXELS]`。折成加热在 `ComputeTsBox` 的壳层循环里（`:1672-1712`）：该层的源乘时间权重与谱指数因子，再按预积分表拆成加热、电离与莱曼-α 三份。

**它的位置是气体热的唯一入口，局限在壳层近似与平均光程。** 真实的 X 射线输运随能量有很强的穿行差异，硬光子能穿过整个电离泡、软光子则在本地就被吸收，被一条平均光程抹平之后，加热的空间形状会比真实更平滑。**名下没有参数**（§四）：改它的是源侧与谱形那一组量。论文出处：无登记的节号（见文末）。

## 七、ρ̇*_R(x) · 环形滤波后的恒星形成率场

它与 X 射线源走同一趟环带滤波，只是入口场换成恒星形成率：逐红移一张，供莱曼-α 背景与气体热演化取用（§一 表格）。物理上它回答"在这个尺度内能看到多少恒星形成"，权重是壳层体积（§2.1）。

代码上它与 X 射线那一条只差一个入参（`SpinTemperatureBox.c:762-764`）：壳层半径、滤波核、层编号全一样，出口写进 `source_box->filtered_sfr` 的同一层 `R_ct`——两条线的记录、滤波函数与层编号都相同（§3.2）。

**它在链上的位置是上游源的平滑版本，局限在"按固定尺度做各向同性平均"。** 真实的莱曼-α 输运是多次散射、各向异性的，这一步用环壳平均近似它；尺度一改，源的对比度就跟着变——小尺度噪声被抹平，剩下的是大尺度图案。**名下没有参数**（§四）：壳层怎么分由 `N_STEP_TS` 与 `R_MAX_TS` 设定，幅度完全由源侧参数决定。论文出处：无登记的节号（见文末）。

## 八、⟨ρ̇*⟩ · 恒星形成率的体积平均

它是同一趟滤波顺带给出的一个数：每个红移一个值，不携带空间结构，作为产物里的诊断量用来把网格化的幅度校准回解析平均（§一 表格）。

代码上没有它自己的循环：`one_annular_filter` 在给出滤波场的同时也算出了它的平均，`UpdateXraySourceBox` 把滤波后的那一个直接存进 `source_box->mean_sfr[R_ct]`（`SpinTemperatureBox.c:769`）。所以它是"一次滤波的两个输出"里的第二个（§3.1）。

**它的位置是全局参照，局限在只有幅度。** 平均值相同并不代表尺度上的分布相同，所以它只能校幅度、校不了图案；而且 C 侧当前没有读取方（§五 第四条），自旋温度用的是解析平均值。**名下没有参数**（§四）：水平由源侧参数决定，口径（按体积平均还是按质量加权）比它的数值更值得注意。论文出处：无登记的节号（见文末）。
