# 电离场

这一块把源发出的电离光子折成"有多少气体被电离了"，并顺手记下两样带记忆的东西：每个格点累积的复合量与它第一次被电离时的红移。输入是电离光子率、逐格点的电离率、密度与相对速度；输出是电离分数（一个全局标量加一张逐格点场）、中性氢份额场、光致电离率、累积复合数、电离区平均自由程与逐格点的再电离红移。

它在链上的位置很重：亮温直接拿中性氢份额相乘，所以再电离的结束在观测上表现为信号消失；莱曼-α 与 X 射线在空间上也被它屏蔽。它与气体热之间还有一条弱耦合——早电离的地方被加热，当地能形成恒星的最小质量被抬高，后续的源反而被压住，这条反馈把电离的先后顺序固定下来。

这篇文档先讲它在链上做什么与依据的物理，再按"一处判据、一趟递推、一次记录"的次序落到代码上，然后是参数与陷阱；文末六节逐个交代六个成员的定位与落点，代码地图与论文出处收在末尾。公式、系数与行号均取自本仓当前源码。

## 一、这块在链上做什么

**一句话**：把源发出的电离光子折成"这个格点的氢是中性还是电离的"，并把这件事的四个副产物一并记下来——逐格点光致电离率、跨红移累加的复合数、电离区能长到的尺度、每个格点第一次被电离的红移。

| | 内容 |
| :--- | :--- |
| 输入 | 电离光子发射率与逐格点电离率、密度扰动、相对速度；上一快照的电离盒与累积复合数 |
| 输出 | 电离分数 $Q_{\rm HII}(z)$（全局标量）与中性氢份额场 $x_{\rm HI}(\mathbf x)$；$\Gamma_{12}$、$N_{\rm rec}$、$R_{\rm mfp}$、$z_{\rm reion}$ 四张场 |
| 下游 | 亮温的 $(1-x_{\rm HI})$ 项、光深读的电离历史曲线、莱曼-α 与 X 射线的屏蔽，以及经电离反馈回到上游源项 |
| 参数 | 18 条（§四） |

**物理图像**：电离分数按产生减复合演化——源项是电离光子发射率除以平均氢数密度，复合项正比于电离分数本身与复合系数，并随红移按体积因子的倒数变强（膨胀把离子拉近，复合越来越容易）。红移越低，电离分数依赖所有更高红移的光子积分历史，再电离的早晚由整段源历史决定，而不是当前时刻的源。逐格点看，同一件事被写成一个判据：把滤波尺度内的塌缩分数乘上综合效率，够一就判为电离。

**为什么是独立一块**：它是链上唯一把光子折成电离份额的地方，也是唯一同时向外给三样东西的地方——观测量（亮温）的输入、屏蔽的开关、以及回压源项的反馈量。前两块（源项、气体热）交出的是"有多少光子、气体多热"，到这里才结算成"哪些氢被打掉了"。

## 二、物理骨架

### 2.1 电离分数：源减复合的推进方程

$$\frac{\mathrm dQ_{\rm HII}}{\mathrm dt}=\frac{\dot n_{\rm ion}}{\bar n_{\rm H}}-\alpha_B\,C\,\bar n_{\rm H}\,Q_{\rm HII}\,(1+z)^{3}$$

公式左边是电离分数的变化率，右边第一项是源、第二项是复合；复合取 case-B 并带一个密度不均匀的增强因子，把电离泡对复合的贡献折进去。前提是都取格点的平均值、且光子被就地吸收——示踪量不区分单个电离泡的形状，只给出该格点有多大概率被电离。

进它的是电离光子发射率与逐格点电离率，两者之外还要累积复合数与密度，后两个本身就是带记忆的量，所以这一步把记忆再往下传一层。数学上它是非线性的一阶微分方程：复合项正比于电离分数本身，而复合系数又按当地电离率取值，于是方程与源历史耦合、没有闭式解。它对源项的幅度近似线性，但在复合抵消之后，同一段源历史可以对应差别很大的再电离时点，因而整体电离效率与质量下限在观测量里高度简并。

**这一条方程是理论写法，代码并不求解它。** 实现走的是逐格点的电离判据（§2.2 与 §3.1），两者的取舍在文献与源码里都写得明白；读文档时按代码那一支理解，理论这一条只用来解释"源减复合"这句话的来处。

### 2.2 逐格点判据：塌缩分数乘效率越过一即电离

$$x_{\rm HI}(\mathbf x)=1-\zeta f_{\rm coll}(\mathbf x)-\zeta_{\rm mini}f^{\rm mini}_{\rm coll}(\mathbf x)-x^{\rm X}_{\rm HII}(\mathbf x)\quad(\text{截断到 }[0,1]\text{；越门槛即置 0})$$

每个格点按滤波半径由小到大扫一遍，看累积塌缩分数够不够：塌缩分数乘上综合电离效率，够一就全电离。分子冷却支并进同一判据，用的是另一套效率；X 射线预先电离掉的那一份再减掉，最后把结果截断到 $[0,1]$。

越门槛的格点有两种写法，改的是电离区的形态而不是精度：一种只把格点自己置零，"泡"是逐格点判据拼出来的隐式形状；另一种把半径内的整片抹平。同一份输入因此可以给出两种拓扑的泡。没到门槛、但在最外层滤波步上仍有部分电离的格点走第三条路——减掉 X 射线那一份后截断。这个截断不是修饰：低密度体元上源项被小密度一除就会把份额推成负值，不夹住后面整条链都会带着非物理的数往下走。

还有一路是整体中性：当电离场没在被逐格求解时，全场取同一个值——要么由自旋温度盒里的 X 射线电离份额逐格给出（有结构，但结构全部来自那一份），要么直接取一条全局电离历史。**逐格点中性氢分数场在缺省口径下确实可以是一张常数场**，看它的分布之前先确认走的是哪一支。

### 2.3 逐格点光致电离率与电离区尺度

$$\Gamma_{12}(\mathbf x)=\frac{1}{10^{-12}\ \mathrm{s^{-1}}}\int_{\nu_{\rm th}}^{\infty}\mathrm d\nu\,\frac{\sigma_{\rm HI}(\nu)\,F_\nu(\mathbf x)}{h\nu},\qquad \zeta\,f_{\rm coll}(\mathbf x,R_{\rm mfp})=1$$

逐格点的光致电离率描述该处每个中性氢原子每秒被电离的概率：由电离光子通量按氢的电离截面与光子能量折成速率，再除以 $10^{-12}\ \mathrm{s^{-1}}$ 化成无量纲的数。它只在格点被判为已电离时写入，是逐格点的场而不是平均量。公式是一层频率积分：被积函数是光电截面乘通量再除以光子能量，权重随能量递减——软光子截面大但能量小，硬光子相反。前提是通量沿平均自由程衰减、且截面取氢的基态截面；光子谱的形状被压进几个有效系数里，不逐频率输运。

电离区平均自由程与它出自同一个答案：取电离判据在半径上的解——把效率因子乘塌缩分数调到一，解出的半径就是光子在被中性氢吃掉之前能走多远。含义是再往外，累积的电离光子就不足以把气体撑在电离态。前提是气泡各向同性、且光子在泡内被瞬时消耗。它不进观测量，却决定电离场的形态：自由程小的区域电离被限制在小泡里，大的区域电离连成片；源越密，判据要在更大的半径上才成立，于是它随电离区连成片而快速变大。

### 2.4 累积复合数：跨红移的求和

$$N_{\rm rec}(\mathbf x)=\sum_{z}\alpha_B\,C\,n_{\rm H}(\mathbf x)\,(1+z)^{3}\,x_{\rm HII}(\mathbf x)\,\Delta t$$

累积复合数是逐格点、跨红移累加起来的复合总量：每个时间步把复合系数乘上当时的密度与电离分数，再乘时间步长，加到上一快照的累计值上。它带着整段历史，用来判断电离能否净增长。被加项由两组复合系数的插值表给出，按红移与当地电离率取值——复合快慢跟着当地电离率走。前提是复合系数已按温度从表里插值好、且气体在一步内被视为均匀。

它随红移越积越多，因此对电离场是迟滞的作用：源弱的时候复合先消耗掉光子，源起来之后累积量继续抬升，把净增长压得比源历史本身更平。局限在它假定每格点的复合条件在一步内不变，非平衡电离与温度涨落都不在表里，只能靠系数表的插值近似。

### 2.5 第一次电离的时刻：再电离红移

$$z_{\rm reion}(\mathbf x)=\max\left\{\,z\;\middle|\;\zeta\,f_{\rm coll}(\mathbf x,z)\ge 1\,\right\}$$

逐格点再电离红移记下格点第一次被电离时的那个红移：首次被电离时存下当前红移，之后各快照沿用它，所以每个格点记的是它电离史上最早的那一刻。前提是判据只被跨过一次：源单调增长时判据的成立不会反复，否则第一次就不唯一。到当前红移仍未电离的格点记负值，表示还没有电离时刻。

它是这条链上唯一的纯记录量：不参与求解，也进不了观测量。留下它的理由是电离反馈——逐格点的电离时刻与光致电离率一起决定当地能形成恒星的最小质量，于是它要跨红移回到上游的源项。局限在它只记时刻、不记过程：电离持续了多久、局部电离率如何涨落、复合是否反复，都不在单个红移值里。

## 三、代码：一处判据、一趟递推、一次记录

### 3.1 `find_ionised_regions`：逐格点判据与三条出口

判据本身只有一行（`IonisationBox.c:1161-1162`）：塌缩分数乘综合效率、分子冷却支再乘它自己那一套效率，从 1 里减掉就是还剩多少中性。综合效率就是 §2.2 里的 $\zeta$，`USE_MINI_HALOS` 关掉时后一项不进入。

```c
                        res_xH = 1. - curr_fcoll * consts->ion_eff_factor -
                                 curr_fcoll_mini * consts->ion_eff_factor_mini;
```

越门槛的格点走两条路之一，取决于要不要整片抹平（`:1144-1151`）：不整片时只把格点自己置零，整片时把半径 $R$ 内抹平。**这里不是精度选项，它改的是电离区拓扑**——同一份输入，一种给出逐格拼出来的隐式泡，一种给出实心球。

```c

                            update_in_sphere(box->neutral_fraction, ...
                                             rspec.R / (simulation_options_global->BOX_LEN), ...);
```

没到门槛、但在最外层滤波步上仍有部分电离的格点走第三条出口（`:1180-1188`）：先减掉 X 射线预电离那一份，再截断到 $[0,1]$ 写回中性份额场。截断是必需的，低密度体元上源项被小密度一除就会把份额推成负值。

### 3.2 同一趟循环里的三个记录

光致电离率有两个分支（`:1123-1129`），对应判据的两种结果，写的是同一个字段。被判为已电离的格点走第一支：气泡半径积分给出的收敛因子 `rspec.R` 乘上系数 `gamma_prefactor`、按当地密度归一，再乘上滤过的恒星形成率——这里用平滑过的源而不是逐格点源，正因为电离光子走了一段路才到。其余格点走第二支：由塌缩分数与迷你晕那一项直接给出，量级更小。

```c
                                box->ionisation_rate_G12[index_r] =
                                    rspec.R * consts->gamma_prefactor / (1 + curr_dens) *
                                    (*((float *)fg_struct->sfr_filtered + index_f));
                            } else {
                                box->ionisation_rate_G12[index_r] =
                                    rspec.R * (consts->gamma_prefactor * curr_fcoll +
                                               consts->gamma_prefactor_mini * curr_fcoll_mini);
```

看这一段的意义在于认出它**不是积分量**：没有自己的红移历史，每快照按当前源场与判据重算一遍。真正的历史性在两处——滤过源里藏着源的过去，累积复合数里藏着电离的过去。

电离区尺度（`:1131-1133`）与再电离时刻（`:1137-1141`）紧跟在后面，都只是把这一趟循环里已经算出的东西留下来。

```c
                            if (!matter_options_global->MINIMIZE_MEMORY) {
                                box->mean_free_path[index_r] = rspec.R;
                            }
```

```c
                        if (previous_ionize_box->z_reion[index_r] < 0) {

                        } else {
```

### 3.4 `set_recombination_rates`：跨红移累加

累加本身是一行（`:1277-1292`）：增量 `dNrec` 等于插值出的复合系数乘时间步长、再乘电离份额 $\zeta$（即 $1-x_{\rm HI}$），加到上一快照的累积值上，就是 §2.4 那层求和落下的一步。

```c
                    dNrec = splined_recombination_rate(z_eff - 1., box->ionisation_rate_G12[idx]) *
                            consts->fabs_dtdz * consts->dz * (1. - box->neutral_fraction[idx]);

                    if (isfinite(dNrec) == 0) {
                        finite_error = true;
                        LOG_ERROR(
                            "RECOMB: non-finite cell (%d,%d,%d): d %.4e | G12 %.4e | xH %.4e ==> "
                            "dNrec %.4e Nrec_last (%.4e --> %.4e)",
                            x, y, curr_dens, box->ionisation_rate_G12[idx],
                            box->neutral_fraction[idx], dNrec,
                            previous_ionize_box->cumulative_recombinations[idx],
                            box->cumulative_recombinations[idx]);
                    }

                    box->cumulative_recombinations[idx] =
                        previous_ionize_box->cumulative_recombinations[idx] + dNrec;
```

两处细节值得留意。一是查表的自变量：复合系数按**有效红移** $z-1$（也就是上一步）与当时的电离率 `ionisation_rate_G12` 取——复合快慢跟着当地电离率走，这正是 §2.4 里那句话在代码里的样子。二是有限性检查：一旦算出非有限的增量，就把格点坐标与几个中间量一起报出来并终止。这一步不做容错是有道理的——累积量会一代代传下去，一个非有限值会在后面每个红移上放大，宁可就地停下。

## 四、参数

本块名下登记 18 个参数，按"它在物理里改哪一件事"分成五组（清单与画布上这块的「参数」卡一致；类别是 `inputs.py` 里的结构名）。同一个参数的作用点只在这里讲一次，各成员那几步的后果按下面的分组归属。

### 4.1 电离效率与源项：有多少光子可用

| 参数 | 类别 | 在代码里做什么 |
| :--- | :--- | :--- |
| `HII_EFF_FACTOR` | `AstroParams` | 综合电离效率（默认 30.0）。`SOURCE_MODEL == 0` 时它是唯一的效率旋钮，塌缩分数乘上它直接给出电离光子率；开分项参数化时它被 `F_STAR10`、`F_ESC10`、`POP2_ION` 的乘积取代。它是本块最直接的杠杆：调大它，电离分数曲线整体左移、再电离结束时点随之前移。 |
| `M_TURN` | `AstroParams` | 恒星形成的截断质量（默认 8.7，log10）。它定上游源强，因此改的是"有多少光子可用"；再电离时点对它的响应通常比对效率旋钮更敏感，因为它随红移演化，会在某个红移附近突然把源掐掉。 |
| `USE_MINI_HALOS` | `AstroOptions` | 迷你晕总开关（默认关闭）。打开后上游源项多一支，判据里多出 `ion_eff_factor_mini` 那一项（§3.1），早期电离可能由第 3 族恒星主导、再电离的起点前移；关闭时分子冷却那一支的参数在本块全部不进入。 |

### 4.2 复合与温度：电离气体"流失"多快

| 参数 | 类别 | 在代码里做什么 |
| :--- | :--- | :--- |
| `INHOMO_RECO` | `AstroOptions` | 非均匀再复合的总开关（默认打开）。打开时复合逐格点算（每格点按自己的密度与电离度消耗光子），关闭时只用全宇宙平均的复合率。它决定本块求解的是逐格点电离度场还是平均量，也决定计算量。 |
| `T_RE` | `AstroParams` | 电离区气体温度，落成求解里的常数 $T_{\rm re}$（`IonisationBox.c:161`）。复合系数随温度下降，所以这个值直接定复合率：调高它，复合变弱、气体更容易保持电离，再电离提前。 |

### 4.3 尺度分档与滤波：判据在哪些尺度上被评估

| 参数 | 类别 | 在代码里做什么 |
| :--- | :--- | :--- |
| `R_BUBBLE_MAX` | `AstroParams` | 尺度上限：实际取 $\min(R_{\rm BUBBLE\_MAX},\ \text{盒长})$（`IonisationBox.c:962`）。它决定电离场里能出现的最大尺度，也就是盒子能不能装下一个更大的电离泡。调小它，大尺度电离区被切掉，电离分数场的功率谱在大尺度上被压低。 |
| `R_BUBBLE_MIN` | `AstroParams` | 尺度下限：实际取 $\max(R_{\rm BUBBLE\_MIN},\ \text{格点尺度})$（`IonisationBox.c:973`）。它保证尺度分档不会细到格点以下；调大它会牺牲小尺度电离结构。 |
| `DELTA_R_HII_FACTOR` | `AstroParams` | 半径网格的等比步长：第 $i$ 档尺度取 $R_{\min}\cdot{\rm factor}^{i}$（`IonisationBox.c:977`、`991`）。它不改能电离的尺度范围，只改档与档之间的疏密——取值接近 1 时档密、代价高但尺度分辨率细，取值大时档稀、代价降但尺度方向变糊。 |
| `USE_EXP_FILTER` | `AstroOptions` | 是否把电离判据用的滤波核换成指数型（`IonisationBox.c:614` 处 `filter_hf` 在 `hii_filter` 与 3 之间切换）。它改的是判据的平滑程度：尖锐截断与指数衰减会让同一个格点在不同尺度上有不同的通过条件，于是电离场的边界形态随之变。 |

### 4.4 光子守恒校准：把电离历史钉在光子预算上

| 参数 | 类别 | 在代码里做什么 |
| :--- | :--- | :--- |
| `PHOTON_CONS_TYPE` | `AstroOptions` | 光子守恒修正的类型（`z-photoncons` / `alpha-photoncons` / `f-photoncons` / 关闭）。打开时本块算出的电离分数会被按累积光子数重标定，使全局电离度与"总光子数除以总氢原子数"一致；不同类型改的是被重标定的量（红移、效率或分数）。代价是它使电离历史对源项参数不再完全自洽。 |

### 4.5 上游口径与运行开关：本块自己不改的那几条

| 参数 | 类别 | 在代码里做什么 |
| :--- | :--- | :--- |
| `OMb` | `CosmoParams` | 重子密度。它同时进两处：中性氢数密度（复合率与光子消耗的基准）与源强里的重子比例。调大它，气体更难被电离，再电离推迟。 |
| `OMm` | `CosmoParams` | 总物质密度。它进坍缩分数、密度阈值与膨胀率，改的是源强随红移的形状与时间步长，因此对电离历史的影响不是整体缩放——形状也跟着变。 |

## 五、陷阱

**一、理论那条 ODE 代码并不求解。** 文档里的推进方程是"源减复合"这句话的来处，实现走的是逐格点判据（§2.1、§3.1）。按公式去代码里找积分器会找不到。

**二、给亮温的 $x_{\rm HI}$ 与给温度的 $x_{\rm HI}$ 是两个数。** 动能温度用的是**截断之前、减 X 射线之前**的那个 `res_xH`（`IonisationBox.c:1166-1171`），代码注释把理由写明了：温度要排除 X 射线那一份。因此在部分电离区，同一个格点上报给亮温的中性分数与上报给温度的中性份额并不相等。看到温度与 $x_{\rm HI}$ 不自洽时，先回想这一条。

**三、逐格点场可以是常数场。** 电离场没被逐格求解时，全场取同一个值（§3.3）。此时"逐格点中性氢分数场"退化成一张常数场，看直方图或求功率谱之前先确认走的是哪一支。

**四、判据的截断是必需的，不是保护性冗余。** 低密度体元上 $1-\zeta f_{\rm coll}$ 会冲出 $[0,1]$（§3.1），不夹住的非物理值会一路传到亮温。

**五、`MINIMIZE_MEMORY` 会让两张诊断场整张消失。** 打开它时电离区平均自由程与动能温度都不写（§3.2、§3.3）。分析脚本读到的空场不是"值为零"，而是这一段根本没执行。

**六、光子守恒重标定与源项参数不再自洽。** 打开 `PHOTON_CONS_TYPE` 后，电离历史被按累积光子数重标定（§4.4），此时电离历史与效率参数的对应关系不再由本块自己决定；而且校准只做到 `PHOTONCONS_CALIBRATION_END`，再往下的结果不可按同一口径读。

### 一份最小检查清单

- 看电离分数：先确认逐格求解还是整体中性那一路（§五 第三条）。
- 比再电离时点：`HII_EFF_FACTOR`、`M_TURN`、`USE_MINI_HALOS` 与 `T_RE`、`ALPHA_UVB` 一起看，前者改"有多少光子"、后者改"流失多快"，两组高度简并。
- 看 $x_{\rm HI}$ 与温度对不对得上：回想陷阱第二条。
- 用光深或亮温当约束：注意 `PHOTON_CONS_TYPE` 是否改变了电离历史的口径。

## 六、Q_HII(z) = 1 − x_HI(z) · 电离分数（中性氢分数）

它是这块的头号输出，也是再电离历史曲线上那个数：整条电离链的观测量都经过它的均值落地（§一 表格）。物理上它按"源减复合"演化，代码里则由逐格点判据拼出来（§2.1、§2.2）。

代码上它分两段落点：逐格份额在 `find_ionised_regions`（`IonisationBox.c:1180-1188`）写下，全局那个数在 `ComputeIonizedBox`（`:1586-1595`）里对全场求平均再取补（§3.1、§3.3）。

**它的位置是链上的结算口，局限在它是判据的产物。** 那条推进方程只在文档里解释来处，代码不求解它（§五 第一条）；因此它的时间形状由源历史与判据共同决定，而不是某一步积分的结果。**名下参数是本块全部 18 条**（§四）：源项那一组改"有多少光子"、复合与温度那一组改"流失多快"、尺度与滤波那一组改判据在哪些尺度上成立，逐条写在 §4.1–§4.5。论文出处：§3.3（见文末）。

## 七、x_HI(x, z) · 逐格点中性氢分数场

它是电离场的出口量，也是亮温公式里 $(1-x_{\rm HI})$ 那一项的输入，同时还决定哪些格点被算作已电离（§2.2）。

代码上它有三段落点：越门槛的格点在 `:1144-1148` 被置零或整片抹平，部分电离的格点在 `:1185-1188` 减掉 X 射线那一份并截断写回，整体中性那一路在 `:538-540` 全场取同一个值（§3.1、§3.3）。

**它的位置是观测量与屏蔽的公共入口，局限在它可以是一张常数场。** 缺省口径下全场拉平的情形确实存在，看分布之前先确认走的是哪一支（§五 第三条）；另外它与动能温度用的不是同一个中性份额（§五 第二条）。**名下参数是本块全部 18 条**（§四）：它的空间形态主要由尺度与滤波那一组（§4.3）决定，幅度口径由源项与复合那两组决定。论文出处：§3.3（见文末）。

## 八、Γ_12 · 逐格点电离光子率

它描述该处每个中性氢原子每秒被电离的概率，只在格点被判为已电离时取值（§2.3）。留下它不是为了观测量，而是电离反馈要它：跨红移回到源项的"网格化源强"里，与逐格点再电离时刻一起抬高当地的最小质量。

代码上它的落点是 `:1123-1129` 的两条分支，写同一个字段（§3.2）。**它不是积分量**——没有自己的红移历史，每快照按当前源场与判据重算一遍；真正带历史的是滤过的源与累积复合数。

**它在链上的位置是反馈的输入，局限在只在已电离的格点上取值。** 泡内泡外的穿行差异不区分，电离场的边界在分辨率以下被抹平。**名下参数是本块全部 18 条**（§四）：源项那一组直接缩放它的幅度，尺度与滤波那一组改它覆盖的区域（§4.1、§4.3）。论文出处：§3.3 H II 区的增长（见文末）。

## 九、N_rec · 累积复合数

它是逐格点、跨红移累加的复合总量，带着整段历史，用来判断电离能否净增长（§2.4）。

代码上它的落点是 `set_recombination_rates`（`:1277-1292`）：增量由插值出的复合系数乘时间步长与电离份额给出，加到上一快照的累积值上（§3.4）。查表用的是**上一步的有效红移与当地电离率**，这是"跟随当地状态"这句话在代码里的样子。

**它在链上的位置是判据的历史项，局限在一步内视为均匀。** 非平衡电离与温度涨落都不在系数表里，只能靠插值近似。**名下参数是本块全部 18 条**（§四）：复合是密度的平方效应，所以密度类参数（`OMb`、`OMm`）在这里的权重比在源项那几组里大一档；谱指数与温度那一组改写"流失多快"（§4.2）。论文出处：§3.3 H II 区的增长（见文末）。

## 十、R_mfp · 电离区平均自由程

它是判据在半径上的解：再往外，累积的电离光子就不足以把气体撑在电离态（§2.3）。它不进观测量，但决定电离场的形态——小则电离被限制在小泡里，大则连成片。

代码上它的落点是 `:1131-1133` 的一次赋值：把这一趟循环里刚用来算判据的收敛半径留下来（§3.2）。存不存还看 `MINIMIZE_MEMORY`。

**它的位置是诊断量，局限在它是各向同性的单一长度。** 真实的电离区有复杂的形状与遮挡，泡与泡之间的穿越不在这里。**名下参数是本块全部 18 条**（§四）：凡改"还剩多少中性氢"或"电离区能多大"的参数都会在这里显形（§4.2、§4.3）。论文出处：§3.3 H II 区的增长（见文末）。

## 十一、z_reion · 逐格点再电离红移

它记下格点第一次被电离时的那个红移，之后不再改（§2.5）。留下它的理由和光致电离率一样：电离反馈要这两个量一起决定当地的最小质量。

代码上它的落点是 `:1137-1141` 的两条分支——上一快照为负就写下当前红移，否则沿用（§3.2）。这张场写一次就不再改，靠快照一代代传下去。

**它是纯记录量，局限在只记时刻、不记过程。** 电离持续了多久、局部电离率如何涨落、复合是否反复，都不在单个红移值里；到当前红移仍未电离的格点记负值。**名下参数是本块全部 18 条**（§四）：都是经"电离什么时候走到这片区域"间接进入——改的或是时点，或是先后的空间格局。论文出处：§3.3 H II 区的增长（见文末）。
