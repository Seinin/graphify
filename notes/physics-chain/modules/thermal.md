# 气体热与自旋温度

这块管两件事：气体怎么被加热，以及 21 厘米信号由什么温度决定。它是链上唯一含时间导数的部分——气体温度按膨胀、加热与康普顿交换逐红移演化；自旋温度则由三个温度竞争得出，而竞争的通道（光子、气体、莱曼-$\alpha$ 散射给出的色温）都要先各自算出来。这也是全链唯一需要迭代的地方：莱曼-$\alpha$ 的色温依赖自旋温度，自旋温度又依赖耦合，只能迭代到自洽。

两个温度的分工要分清：气体温度是真实的动力学量，由 X 射线加热与绝热冷却决定；自旋温度不是真实温度，只描述两个自旋态上各有多少原子，是它决定了信号的正负与幅度。前者算错会改信号出现的早晚，后者算错会直接改信号的方向。除了这两个温度，这块还顺手产出两条背景——一条是恒星的光（莱曼-$\alpha$，当场用掉），一条是更硬的紫外（莱曼-维尔纳，留给下一个红移的源项去用）。

本篇按"这块在链上做什么 → 逐个成员讲物理 → 代码怎么走 → 参数 → 陷阱 → 成员索引卡 → 代码地图 → 论文出处"排。物理骨架按成员次序讲它依据的物理（不出现代码标识）；代码那一节按函数讲实现，一条代码落点只印一次；成员节是索引卡，给定位与落点、在链上的位置与局限、名下参数的去处，不重述算法。

## 一、这块在链上做什么

**一句话**：把源折成的能量与背景，演化成气体温度与自旋温度两张场，交给亮温公式。

| | 内容 |
| :--- | :--- |
| 输入 | X 射线加热率（由 X 射线源的历史卷积折出）、各类源的恒星形成率、上一快照的温度与电离度、密度扰动、光子温度 |
| 输出 | 气体动力学温度、莱曼-$\alpha$ 与莱曼-维尔纳背景、两个耦合系数、自旋温度 |
| 下游 | 亮温与观测：由自旋温度与电离度折成 21 厘米亮温；莱曼-维尔纳背景回流到下一个红移的源项 |
| 参数 | 24 个（源强与电离历史、X 射线谱窗口、壳层划分、亚网格与自屏蔽、实现选择、开关、宇宙学背景），§四 |

**物理图像**：源提供能量与光子，这块负责把能量变成温度、把光子变成耦合。加热沿着历史累加——X 射线从过去各时刻走来，沿途被吸收，没被吸收的部分才留下当热；温度沿着时间往前走，一边被膨胀拉低，一边被加热抬起，还跟光子交换能量。自旋温度则是一本三方角力的账：光子、气体、莱曼-$\alpha$ 各想把自旋态掰到自己那一边，谁的耦合强谁说了算，而莱曼-$\alpha$ 那边的色温本身又取决于角力的结果，所以要迭代。

**为什么是独立一块**：它接的是"能量与背景"（上游已经算好），出的是"温度"——这一步既不是源、也不是观测量，而是链上唯一需要解时间导数的环节。它也是唯一会迭代的环节：耦合依赖自旋温度、自旋温度依赖耦合，这个圈只能在这里合上。局限也跟着来——它把气体当成单相介质、把能量沉积压成平均份额、把莱曼-$\alpha$ 的多次散射折叠进一个修正项。

## 二、物理骨架

### 2.1 X 射线加热率

X 射线加热率是气体热账上唯一的加热项：X 射线从源出发沿视线被中性氢吸收，沉积下来的能量先按电离度分摊——一部分进加热、一部分进电离、一部分转成莱曼-$\alpha$ 光子——剩下的部分折成单位体积、单位时间的加热量。

$$\varepsilon_{\rm heat}(z)=(1-x_e)\,\frac{L_X}{E_X}\,\bar n_{\rm H}\int_{z}^{\infty}\mathrm dz^{\prime}\,\frac{(1+z^{\prime})^{3}}{H(z^{\prime})}\,e^{-\tau_X(z,z^{\prime})}$$

公式分两层：内层把源的能量按频率积成沉积份额，外层沿红移把历史各层的贡献按时间间隔与光程衰减累加。前提是吸收只由中性氢提供、源谱取平均形状，气体温度不高、复合可忽略也是这层折算的隐含假设。前面那个中性氢份额因子是关键：电离度越高，同样的 X 射线留给加热的能量越少——加热与再电离因此不是两条独立的线。

它是空间非局域的：某个格点的加热率由它上游整段历史上的 X 射线源共同决定，所以强弱同时被源的演化与吸收光程调节。它是自旋温度的间接来源——气体温度被它抬高之后，自旋温度才会重新偏离光子温度。局限在这一步只给平均份额：真实的能量沉积随能量与电离度分布，被压成一条平均曲线后，加热的空间对比会比逐频率的结果更平滑。

### 2.2 气体动力学温度

气体动力学温度按绝热膨胀加受热演化：膨胀项以两倍哈勃率降温，加热项把 X 射线沉积的能量按总粒子数摊进温度，另加与光子温度之间的康普顿耦合——电子与光子散射交换能量，把气体拉向光子温度。

$$\frac{\mathrm dT_K}{\mathrm dt}=-2HT_K+\frac{2}{3}\frac{\varepsilon_{\rm heat}}{k_B n_{\rm tot}}+\Gamma_{\rm Compton}(T_\gamma-T_K)$$

公式左边是温度的时间变化率，右边三项分别是绝热冷却、加热与康普顿交换；前提是气体被视为单一温度的单相介质，密度扰动只通过绝热项与加热项进入。演化在整段红移上做，每个格点带自己的密度，因此温度场随密度场一起起伏。

高红移时康普顿耦合把温度钉在光子温度上；复合之后耦合退居次要，气体按绝热膨胀自由降温；再往后 X 射线加热把它重新抬起来。这条曲线的最低点，就是 21 厘米吸收信号最深处的取温来源。局限在方程是一维、逐格点演化的：流体动力学、激波与并合造成的加热都不在其中，只能靠密度扰动与外部加热近似。

### 2.3 莱曼-$\alpha$ 辐射场强度

莱曼-$\alpha$ 背景强度是 Wouthuysen–Field 效应的强度来源：恒星发出的更高能级莱曼光子最终都会级联退化成莱曼-$\alpha$ 光子，把每个能级的贡献按回收分数加权、再沿光程累加，就得到该红移处的背景强度。

$$J_\alpha(z)=\frac{c}{4\pi}\int_{z}^{\infty}\frac{\mathrm dz^{\prime}}{H(z^{\prime})(1+z^{\prime})}\sum_{n\ge 2}f_{\rm recycle}(n)\,\epsilon_{n}(z^{\prime})$$

公式是一层红移积分：被积函数是各能级发射率乘回收分数的和，权重是光程元；前提是莱曼级联的回收分数已由原子物理定好、且光子在本地被反复散射到饱和——真正输运的细节被压成这一层积分。回收分数对低能级是 1、对刚好落在莱曼-$\alpha$ 上的能级是 0，更高级次按表给出，这一条分档决定了背景强度的整体幅度。

它对上依赖恒星形成率密度（也就是恒星形成效率与最小源质量），对下与气体温度、中性氢份额一起决定莱曼-$\alpha$ 耦合系数。它是历史积分、带记忆，在观测量里与 X 射线加热、电离效率彼此简并——三条线的强度都随源的整体幅度一起动，单看 21 厘米信号很难把它们分开。

### 2.4 莱曼-$\alpha$ 耦合系数

莱曼-$\alpha$ 耦合系数把 Wouthuysen–Field 效应折成一个无量纲的耦合强度：由背景强度乘上跃迁的振子强度与光子温度给出的系数得到，中间还带一个散射不完全热化的修正——把散射色温与气体温度的差别折进去。

$$x_\alpha=\frac{16\pi^{2}T_\star f_{12}}{27A_{10}T_\gamma}\,S_\alpha\,J_\alpha(z)$$

公式是一个乘积，前面的系数由原子常数与光子温度定死，可调的只有背景强度与色温修正；前提是散射达到统计平衡、色温能用一个有效值代表，而这个有效值本身又依赖自旋温度，所以这一条要迭代求解。它与碰撞耦合一起进自旋温度那本账，两者相加后与光子项做调和加权。

红移较高时碰撞主导，中间一段莱曼-$\alpha$ 主导，而这一段的宽度与位置决定了自旋温度跟随气体温度的早晚。局限在它假定莱曼-$\alpha$ 光子只在本地散射、输运被抹平——真实的多次散射会改色温，这一步用修正项近似它。

### 2.5 莱曼-维尔纳背景强度场

莱曼-维尔纳背景是 $11.2$–$13.6$ eV 那一段紫外，它不进亮温，作用面在另一边：把分子氢解离掉，抽走低质量晕的冷却剂，于是抬高分子冷却支的转折质量。也就是说，这一块在算自己温度的同时，顺手为下一个红移的源项准备了一份输入——一条向后的腿，闭合点在下游的源。

它由滤过的恒星形成率逐环壳累加而成：同一红移内按半径由近及远把各环壳的贡献叠起来，这就是它在物理上非局域的来源。论文与源码都没有给它闭式，能确定的只有这条"按环壳叠加"的结构，以及最终折算到 $10^{-21}$ 的无量纲口径。它只在迷你晕开启时才存在，因为只有那条支才需要分子冷却的反馈强度；方向是单向的——它只影响分子冷却支的转折质量，不反馈回自己。

### 2.6 碰撞耦合系数

碰撞耦合系数是碰撞激发率与自发跃迁率之比：它是自旋温度与气体温度之间的第三条通道，不需光子参与，靠氢原子之间、原子与电子、原子与质子的碰撞直接翻转自旋。

$$x_c=\frac{T_{21}}{T_\gamma}\,\frac{n_{\rm HI}\kappa_{\rm HI}+n_e\kappa_e+n_p\kappa_p}{A_{10}}$$

分子是三条碰撞道贡献之和、分母是自发跃迁率；三条道各按自己的数密度与温度决定的碰撞率进入。前提是碰撞率取热平衡下的拟合值、且气体被视为单一温度——非热速度分布与激波不在这里。它只依赖气体温度与各类粒子的数密度，因此在气体密度高、温度低的地方最强。

它随红移演化完全由密度与温度决定：宇宙膨胀使密度按三次方下降、温度按绝热冷却下降，两者一起让碰撞耦合很快退居次要。它对密度扰动是线性放大的——同样温度下密度高的格点耦合更强，因此它在低红移的空腔区几乎消失、在过密区还能留住一些。它与莱曼-$\alpha$ 耦合在自旋温度里相加，两者彼此竞争也彼此简并，在信号里都表现为自旋温度被拉向气体温度。

### 2.7 自旋温度

自旋温度由三处耦合竞争给出：光子温度、莱曼-$\alpha$ 散射的色温、气体温度各按自己的耦合系数加权，加权形式是调和平均——系数越大，自旋温度越被拉向对应的那个温度。

$$T_S^{-1}=\frac{T_\gamma^{-1}+x_\alpha T_\alpha^{-1}+x_c T_K^{-1}}{1+x_\alpha+x_c}$$

前提是自旋态与三个热源都达到统计平衡，而色温与莱曼-$\alpha$ 耦合本身又依赖自旋温度，所以要迭代到收敛。红移较高、密度较大时碰撞耦合主导；莱曼-$\alpha$ 背景起来后它接管；两者都弱时康普顿散射把自旋温度钉在光子温度上，亮温趋于零。

三种极限都能从它读出：只有康普顿散射时自旋温度等于光子温度，信号为零；莱曼-$\alpha$ 耦合足够强时自旋温度等于气体温度，发射或吸收最强；中间过渡里自旋温度介于两者之间，决定了亮温随红移的整条曲线形状。局限在平衡假设：自旋态的非平衡分布、莱曼-$\alpha$ 的多次散射与 X 射线对自旋的直接扰动都不在这套三温度加权里，只能靠上游的有效修正项近似。

## 三、代码怎么走

入口有两条，跑的是同一套账：网格化的那条走 `ts_main`（`SpinTemperatureBox.c:1375`）逐格点调 `get_Ts_fast`（`:1198`），高红移初值与单格点另走解析版 `get_Ts`（`heating_helper_progs.c:720`）。前者把每格点的源项、常数与表都预先算好，热账与耦合在一个函数里一次结清；后者按同一组公式现算，慢但自成一体。

### 3.1 总装：`ts_main` 的次序

一次调用把整个盒子的温度解出来，次序是固定的：

1. 先备料：`init_ps`、`alloc_global_arrays`、`init_heat`（读沉积能量的插值表）、`setup_z_edges`（按 `N_STEP_TS` 划壳层、给每层配 `zpp` 与半径）；随后建 $\sigma(M)$ 插值表（`:1404-1422`）。
2. 红移高于 `Z_HEAT_MAX` 时直接返回，只调 `init_first_Ts`（`:1424-1429`）——这一段不是"算出来"的，而是解析历史给的值（§3.6）。
3. `calculate_spectral_factors`、`prepare_filter_boxes`：把密度场与莱曼-维尔纳阈值场搬到傅里叶空间备用（`:1431`、`:1454`）。`SOURCE_MODEL < 2` 时自己滤波并填 `delNL0`；`SOURCE_MODEL >= 2` 时改用 `source_box` 里上一环存好的平均值（`:1482-1486`）。
4. `set_zp_consts` 把本快照的常数一次算齐（§3.4）。
5. 取上一快照的体积平均电离份额与温度 `x_e_ave_p`、`Tk_ave_p`（`:1491-1501`），进 `global_reion_properties` 得到全局电离光子数与 `Q_HI`，并据此填频率积分表（`:1513`）。
6. 逐格点先把电离份额的查表索引与插值系数算好（`locate_xHII_index`，`:1521-1533`），因为下面每个壳层都要用一次；同时把 `+=` 累加盒子清零（`:1536-1545`）。
7. 壳层循环（`R_ct`）把每个半径上的源按光程与时间权重累加进加热、电离、莱曼-$\alpha$、恒星莱曼-$\alpha$、莱曼-维尔纳与两个加热项盒子（累加点见 §3.7）。
8. 逐格点那一趟（代码注释写作 `R==0 part`，`:1793-1873`）把盒子字段与上一快照的 `prev_Ts` / `prev_Tk` / `prev_xe` 装进 `struct Box_rad_terms`，调 `get_Ts_fast`，把 `Ts`、`Tk`、`x_e`、`J_21_LW` 写回输出盒。
9. 收尾：逐格点查 `spin_temperature` 是否有限，出现 NaN 或无穷就抛 `InfinityorNaNError`（`:1897-1914`）。

红移步长就是这里的 `dzp = redshift - prev_redshift`（`:1401`），**是负的**——所有"每单位红移"的导数都按这个符号写在更新式里。

### 3.2 快通道：`get_Ts_fast` 的一格账

一格从上一快照的三个人口（`prev_Ts`、`prev_Tk`、`prev_xe`）加当前源项出发，依次算：

**一、光学的自旋抑制因子。** 先算 $\tau_{21}$，再折成

```c
    if (tau21 > 1e-8) {
        xCMB = (1. - exp(-tau21)) / tau21;
    } else {
        xCMB = 1. - tau21 / 2 * (1 - tau21 / 3 * (1 - tau21 / 4));
    }
```

（`:1206-1216`。）这里的 `xCMB` **不是常数 1**，而是光子把自旋拉住的那个强度：光学厚时被压低，光学薄时趋于 1。后面自旋温度的分子分母都用它，不是用 1。

**二、电离度推进。** `dxe_dzp` 由源项减复合汇项得到，汇项是 $\alpha_A(T_K)\cdot$ `CLUMPING_FACTOR` $\cdot x_e^2$ 乘密度因子（`:1220-1223`）——`CLUMPING_FACTOR` 只出现在这一处，不进加热。

**三、气体温度的各项。** 依次累加：绝热项（`3/(1+zp)` 加结构增长项，再乘 $2T_K/3$）、物种变化项（电离度变化带走温度）、康普顿项（用 `Trad` 与 `prev_Tk` 之差）、X 射线加热项（`dxheat_dt * dt_dzp * 2/3/k_B/(1+x_e)`，受 `USE_X_RAY_HEATING` 管）、CMB 加热项（Meiksin 2021 的形式，受 `USE_CMB_HEATING` 管）、莱曼-$\alpha$ 连续与注入两个加热项（`Energy_Lya_heating` 的两个 flag，受 `USE_LYA_HEATING` 管，带负号）。六项相加乘 `dzp` 更新 `Tk`（`:1241-1304`）。

这一处有两个硬闸门：`Tk` 超过 `MAX_TK`（`5e4`，文件头 `:30`）时**整段更新被跳过**——不是封顶，而是那一格这一轮不动；`Tk` 被梯形积分推成负数时直接重置为 `Trad`（`:1307-1308`，代码注释把这个伪影记在欠密区过冷上）。

**四、三处耦合。** `xc_fast` 是 `xc_inverse` 乘三条碰撞道之和（`(1-x_e)·No·κ_HI + x_e·N_b0·κ_e + x_e·No·κ_pH`，`:1326-1328`）；`xa_tilde` 先算 $\xi=$ `Ts_prefactor` $\cdot$ $\sqrt[3]{(1+\delta)(1-x_e)/T_K^2}$，代入 $1/(1+2.98394\xi+1.53583\xi^2+3.85289\xi^3)$ 再乘一个含 $T_K$、$T_S$ 的四项多项式（`:1330-1346`）。

**五、自旋温度。** `J_alpha_tot > 1e-20` 时从 `Trad` 出发迭代：

```c
        while (fabs(TS_fast - TSold_fast) / TS_fast > 1.0e-3) {
            ...
            TS_fast = (xCMB + xa_tilde_fast + xc_fast) *
                      pow(xCMB * consts->Trad_inv + xa_tilde_fast * (...) + xc_fast * T_inv, -1.);
        }
```

（`:1337-1354`。）门限以下走"只有碰撞"的闭式（`:1355-1357`）；结果取绝对值后输出（`:1368`）。

**六、出口。** `J_21_LW` 只在迷你晕开启时给 `dstarLW_dt`，否则直接给 0（`:1312`）——**关闭时不是"算了没存"，而是根本没算进这一格**。

### 3.3 慢通道：`get_Ts` 与三个碰撞率小函数

解析版把同一套账写成一组独立的小函数：`xcoll_HI`、`xcoll_elec`、`xcoll_prot` 各按自己的数密度与碰撞率表给一项，`xcoll` 是三者之和（`heating_helper_progs.c:681-714`）——这一组就是 §2.6 那条公式的代码原型。色温走 `Tc_eff(T_K, T_S) = 1/(T_K + 0.405535\,T_K(T_S-T_K))`（`:715-718`），散射修正走 `Salpha_tilde` 与 `xalpha_tilde`（`:650-678`），自旋温度写成

$$T_S=\frac{1+\tilde x_\alpha+x_c}{1/T_\gamma+\tilde x_\alpha/T_\alpha+x_c/T_K}$$

（`:720-745`。）两处差别要记住：解析版的分母里光子项就是 $1$（没有 $\tau_{21}$ 抑制），散射修正是现算的幂次式而不是查表。

### 3.4 一次算齐的常数：`set_zp_consts`

本快照用到的每个常数都在 `:1086-1171` 一次算完，之后每格点只做乘加：X 射线谱积分因子（`X_RAY_SPEC_INDEX` 恰为 1 时走对数分支，避免 $\int$ 退化成除零，`:1094-1110`）、`Trad`、`Ts_prefactor`、`xa_tilde_prefactor`、`xc_inverse` $=(1+z)^3T_{21}/(T_\gamma A_{10})$、康普顿系数、`Nb_zp`/`N_zp`、恒星莱曼-$\alpha$ 的换算因子、以及把网格发射率换算成每立方厘米的 `volunit_inv`。注意 `xc_inverse` 是 $1/x_c$ 的骨架：格点上的 `xc_fast` 是它乘上粒子数与碰撞率。

### 3.6 高红移的初值与平均历史

**平均历史不在这块演化出来。** `T_RECFAST` 与 `xion_RECFAST`（`heating_helper_progs.c:94`、`:145`）读一张外部 RECFAST 表，给出只含康普顿加热与绝热膨胀的平均温度与电离历史——高红移时它是初值来源，也是"不做涨落"时的参照。`init_first_Ts`（`SpinTemperatureBox.c:885`）取这两个值，按 `cT_approx` 给每格点做密度缩放，再调慢通道 `get_Ts` 得到初值自旋温度。所以红移高过 `Z_HEAT_MAX` 时输出盒是**解析值加密度缩放**，不是演化出来的。

### 3.7 加热源怎么进入这一块

X 射线源侧的工作（滤波、落盘、频率积分表）在「X 射线源的历史卷积」那一篇；本块只做最后一趟查表累加：壳层循环里按当前格点的中性氢份额选表的行号 `xidx`，把该层的源乘时间权重与谱指数因子后拆成加热、电离、莱曼-$\alpha$ 三份（`SpinTemperatureBox.c:1703-1712`）。恒星那条线同段处理（`:1697-1720`）。这也解释了参数的去向：`L_X` 一类的幅度旋钮不在本块名下，但最终是它们决定了这里累加出多少。

## 四、参数

本块名下登记 24 个参数，分七组：源强与电离历史、X 射线谱窗口、壳层划分、亚网格与自屏蔽、实现选择、开关、宇宙学背景。它们的关系是"少数几个乘积决定幅度，其余决定形状与窗口"。

### 4.1 源强与电离历史

恒星那一侧由三对量组成：`F_STAR10`（$10^{10}M_\odot$ 晕的恒星形成效率，默认 $-1.3$）、`F_ESC10`（逃逸分数，默认 $-1.0$）、`POP2_ION`（每重子电离光子数，默认 5000）；`SOURCE_MODEL = 0` 时改用综合效率 `HII_EFF_FACTOR`（默认 30）。迷你晕那一侧是 `F_STAR7_MINI`、`F_ESC7_MINI`（默认 $-2.0$）、`POP3_ION`（默认 44021）。它们只以乘积的整体幅度进入本块：三条线索曼-$\alpha$、加热与电离都随同一组源强一起动，所以单看 21 厘米信号很难把效率、逃逸与光子数分开。

### 4.2 X 射线谱窗口

四个量圈定 X 射线那块谱：`NU_X_THRESH`（阈值能量，默认 500 eV）、`NU_X_BAND_MAX`（光度带的上界，默认 2000 eV）、`NU_X_MAX`（热积分上界，默认 $10^4$ eV）、`X_RAY_SPEC_INDEX`（谱指数，默认 1.0，恰好 1 时代码走对数分支）。它们改的是"硬光子占多少"，因此改的是加热的空间对比与它出现的早晚。

### 4.3 壳层划分

`N_STEP_TS`（壳层数，默认 40）与 `R_MAX_TS`（滤波半径，默认 500 Mpc）决定历史卷积的粒度与最大尺度。它们不进任何公式的分子，只决定有多少层、最外一层多远——改动它们，X 射线与莱曼-$\alpha$ 的空间图案一起变。

### 4.4 亚网格与自屏蔽

`CLUMPING_FACTOR`（默认 2.0）只出现在复合汇项里（§3.2），不进加热，所以它改的是电离度与热的平衡点；`F_H2_SHIELD`（默认 0.0）是分子氢在莱曼-维尔纳抑制下的自屏蔽因子，只经最小源质量影响恒星形成率，从而间接进本块。

### 4.5 实现选择

`INTEGRATION_METHOD_ATOMIC` 与 `INTEGRATION_METHOD_MINI`（默认均为 `GAUSS-LEGENDRE`）选的是条件质量函数的积分方法，影响源侧求值的精度与速度，不动物理。

### 4.6 开关

四个开关里两个直接管本块的项：`USE_X_RAY_HEATING`（默认开）决定加热项是否存在、`USE_CMB_HEATING`（默认开）与 `USE_LYA_HEATING`（默认开）分别决定康普顿之外的两种加热通道。`USE_MINI_HALOS`（默认关）关掉时，莱曼-维尔纳背景直接给 0（§3.2）。这些开关改的是"算不算"，不是"算多少"。

### 4.7 宇宙学背景

`hlittle`、`OMb`、`Y_He`（默认 0.24）经哈勃率、重子密度与氦份额进入所有换算因子（§3.4）。改它们等于改时间与密度两把尺子，本块的每一条式子都跟着变。

## 五、陷阱

**一、`xCMB` 不是 1。** 快通道里光子项是 $\tau_{21}$ 的抑制因子（§3.2 第一条），解析版里却是 1（§3.3）——同一物理量的两个版本，对照公式时不要混。

**二、自旋温度只在门限以上迭代。** `J_alpha_tot > 1e-20` 才进循环；以下走"只有碰撞"的闭式。检查收敛性时要先确认走的是哪一支。

**三、`Tk` 有两个硬闸门。** 超过 `MAX_TK`（$5\times10^4$）时那一格的更新被整段跳过，不是封顶；被推成负数时重置为 `Trad`。二者都在 `get_Ts_fast` 的更新段，不在源项里。

**四、这块给的是"中性气体"温度。** 输出字段名就是 `kinetic_temp_neutral`，而电离区的温度另走 McQuinn 2015 的解析式（`thermochem.c:32`）。把它当成总气体温度会读错电离泡内的热史。

**五、`xray_ionised_fraction` 不是再电离的电离度。** 它是 X 射线部分电离累积出来的份额，盒子里另存着 `Q_HI`。两者别混。

**六、`J_21_LW` 只在迷你晕开启时非零。** 关闭时那一格直接写 0，文件中看不到"算了没存"的痕迹——查这条量之前先看开关。

**七、迭代的初值与容差都是固定的。** 初值取 `Trad`，判据是相对变化 $10^{-3}$；强耦合格点需要更多轮，步长（`dzp`）大时误差主要落在这里。

**八、红移步长是负的。** 所有更新式都按 `dzp < 0` 写，自己重算时容易漏掉符号。

**九、平均历史来自外部表。** `Z_HEAT_MAX` 以上不做演化（§3.6）：这一段若与别处的平均温度不一致，先看那张 RECFAST 表，而不是查本块的公式。

**十、频率积分表用的是上一快照的平均电离份额。** 与「X 射线源的历史卷积」那一篇同一条口径：变化快的时期这里是滞后来源。

### 一份最小检查清单

- 想看加热何时起效：查 `Tk` 的最低点与它之后的抬升，同时确认 `USE_X_RAY_HEATING` 与谱窗口那一组量。
- 想看吸收何时出现：查 `Ts` 与 `Tk` 的分离时刻，那一处由莱曼-$\alpha$ 耦合接管。
- 想改信号方向：动的是耦合与温度的关系（`CLUMPING_FACTOR`、源强），不是观测量。
- 单格点测试里不要拿 `Z_HEAT_MAX` 以上的输出验证演化（§五 第九条）。

## 六、ε_heat(z) · X 射线加热率

它是气体热账上唯一的加热入口（§2.1），单位体积、单位时间的沉积能量。物理上它由三步折出：源的谱按频率积成沉积份额，按电离度分摊出留在加热上的那一份，再沿红移把历史各层按光程与时间间隔累加。因此它记的是整段历史，带记忆。

代码上它的落点分两处。源侧的求值在 `global_reion_properties`（`SpinTemperatureBox.c:919-997`）与 `calculate_sfrd_from_grid`（`:998-1085`），但真正折成加热率是壳层循环里的一次查表累加：

```c
                    if (astro_options_global->USE_X_RAY_HEATING) {
                        dxheat_dt_box[box_ct] +=
                            xray_sfr * (freq_int_heat_tbl_diff[xidx][R_ct] * ival +
                                        freq_int_heat_tbl[xidx][R_ct]);
                    }
```

（`:1703-1707`。）表行号 `xidx` 取当前格点的中性氢份额，所以"沿途吸收"在代码里的样子是"换一行查表"；三个增量盒子（加热、电离、莱曼-$\alpha$）来自同一次乘法，只是表的列不同。

**它在这条链上的位置是"源与温度之间的一步折算"，局限在平均份额。** 真实的能量沉积随光子能量与局部电离度分布，这里被压成一条平均曲线；硬光子能穿出电离泡、软光子在本地就被吃掉，这个差异被壳层近似抹掉。**名下参数**是 §4.1、§4.2、§4.3、§4.5、§4.6 五组：源强、谱窗口、壳层划分、积分方法与开关都经它进入。论文出处：§3.4 加热与电离（见文末）。

## 七、T_K(z) · 气体动力学温度

它是气体真实的动力学温度（§2.2），也是本块两个温度里唯一的"物理温度"。物理上它沿时间前进：膨胀降温、X 射线加热升温、与光子交换能量。它不是单独演化出来的场，而是每格点自己那一份密度下的演化结果——密的地方绝热压缩得热，疏的地方过冷。

代码上它在 `get_Ts_fast` 的更新段：先按上一快照的 `prev_Tk` 算出六项（绝热、物种变化、康普顿、X 射线加热、CMB 加热、莱曼-$\alpha$ 加热），相加乘 `dzp` 得到新值（`:1241-1305`），再过两道闸门：

```c
    Tk = rad->prev_Tk;
    if (Tk < MAX_TK) {
        ...
        Tk += (dxheat_dzp + dcomp_dzp + dspec_dzp + dadia_dzp + dCMBheat_dzp + eps_Lya_cont +
               eps_Lya_inj) *
              dzp;
    }
    if (Tk < 0) Tk = consts->Trad;
```

（`:1293-1308`。）`MAX_TK` 处的分支是跳过更新，不是封顶。

**它在链上的位置是自旋温度的取温来源，局限在"单相、中性气体"。** 这块不含流体动力学、激波与并构加热；输出的字段名是 `kinetic_temp_neutral`，电离区那段温度另走解析式（§五 第四条）。**名下没有参数**：改它的是 X 射线那一组（经 `eps_heat`）与光子温度（由宇宙学背景定），§4.1、§4.2、§4.6 三组是入口。论文出处：§3.4（见文末）。

## 八、J_α(z) · Ly-α 辐射场强度

莱曼-$\alpha$ 背景强度是 Wouthuysen–Field 效应的强度来源（§2.3）。恒星与 X 射线两条源都往里加：前者是恒星谱经级联退化后的贡献，后者是 X 射线在电离过程中转出的莱曼-$\alpha$ 光子。所以它不是一个源的产物，而是两条线在同一处汇合。

代码上汇合点只有一行：

```c
    double J_alpha_tot = rad->dstarlya_dt + rad->dxlya_dt;  // not really d/dz, but the lya flux
```

（`:1314`。）两个 `_dt` 名字里带时间导数，但注释明写它们就是流量本身。两个分量的累加在壳层循环里（`:1697-1720`）：恒星那一份乘恒星莱曼-$\alpha$ 换算因子，X 射线那一份乘 X 射线源的谱因子，两者都逐壳层叠加。

**它在这条链上的位置是耦合的强度来源，局限在"折成流量而不做输运"。** 真实的莱曼-$\alpha$ 输运是多次散射、各向异性的，这里用环壳平均与散射修正项近似它（§2.4）；而且它与加热、电离共享同一组源强，三者在观测上彼此简并。**名下参数**是 §4.1（源强）、§4.3（壳层划分）、§4.4（自屏蔽）、§4.6（`USE_LYA_HEATING`、`USE_MINI_HALOS`）。论文出处：§2.3 Wouthuysen–Field 效应（见文末）。

## 九、x_α · Ly-α 耦合系数

它把背景强度折成一个无量纲的耦合（§2.4）：前因子由原子常数与光子温度定死，可调的只有背景强度与一个散射修正。修正项不只用 $T_K$，还用上一轮的自旋温度——这正是"这一条要迭代"的原因。

代码上它分两步写在同一个函数里。先算散射修正的自变量：

```c
    xi_power = consts->Ts_prefactor * cbrt((1.0 + rad->delta) * (1.0 - x_e) * T_inv_sq);
    xa_tilde_fast_arg = consts->xa_tilde_prefactor * J_alpha_tot *
                        pow(1.0 + 2.98394 * xi_power + 1.53583 * xi_power * xi_power +
                                3.85289 * xi_power * xi_power * xi_power,
                            -1.);
```

（`:1330-1335`。）再在迭代里补上含 $T_K$、$T_S$ 的四项多项式相乘（`:1343-1346`，与 `heating_helper_progs.c:655-663` 的 `Salpha_tilde` 是同一个式子）。

**它在这条链上的位置是"密度也进耦合"的那一环，局限在色温被折成一个修正项。** 修正式本身是以 $T_K$、$T_S$ 与光学深度为自变量的拟合，多次散射的细节不在里面。**名下参数**与 `jalpha` 同一组：§4.1、§4.3、§4.4、§4.6。论文出处：§2.3（见文末）。

## 十、J_21^LW(x, z) · 莱曼-维尔纳背景强度场

$11.2$–$13.6$ eV 那一段紫外的强度场（§2.5）。它不进亮温，作用在下一个红移的源项上：解离分子氢，抬高分子冷却支的转折质量。它是本块唯一向外回流的一条腿，出口不是观测量。

代码上它有三处落点：累加在壳层循环里按环壳栈加权叠加（`:1697-1699`），写场时再乘恒星莱曼-$\alpha$ 的换算因子与 `1e21` 的无量纲口径（`:1822-1831`），出口在 `get_Ts_fast` 里：

```c
    output.J_21_LW = astro_options_global->USE_MINI_HALOS ? rad->dstarLW_dt : 0.;
```

（`:1312`。）消费方在下一个红移的 `ComputeHaloBox`（`HaloBox.c:491` 逐格点读上一快照的这张场）。

**它在链上的位置是"往回走的一步"，局限在只在分子冷却支上有意义。** 关闭迷你晕时它整条支路不存在，字段直接写 0；开启时它的口径是 $10^{-21}$，与内部量之间隔着一个 `1e21`，跨模块取用时不要漏。**名下参数**是 §4.1（迷你晕源强）、§4.3、§4.4（`F_H2_SHIELD` 与它同属分子冷却那一套）、§4.6（`USE_MINI_HALOS` 是它的开关）。论文出处：§3.6 天体物理源与历史（见文末）。

## 十一、x_c · 碰撞耦合系数

碰撞激发率与自发跃迁率之比（§2.6）：三条碰撞道（H–H、e–H、p–H）各按自己的数密度与温度进入，分母是自发跃迁率。它不需要光子，靠原子之间的碰撞直接翻转自旋；在气体密、温度低的地方最强。

代码上它是一行乘积：

```c
    xc_fast = (1.0 + rad->delta) * consts->xc_inverse *
              ((1.0 - x_e) * No * kappa_10(Tk, 0) + x_e * N_b0 * kappa_10_elec(Tk, 0) +
               x_e * No * kappa_10_pH(Tk, 0));
```

（`:1326-1328`。）`xc_inverse` 是 $1/x_c$ 的骨架（§3.4），括号里三支与解析版 `xcoll_HI` / `xcoll_elec` / `xcoll_prot` 一一对应（`heating_helper_progs.c:681-714`）——同一个公式的两个写法，数值上一致。

**它在链上的位置是自旋温度与气体温度之间的第三条通道，局限在热平衡拟合率。** 非热速度分布、激波与电离区内部都不在它考虑之内；三条道里电子与质子的两项依赖电离度，因此它随再电离历史一起变。**名下参数**：`CLUMPING_FACTOR`（§4.4）与两个开关（§4.6）经它进入。论文出处：§2.2 碰撞耦合（见文末）。

## 十二、T_S(z) · 自旋温度

这块的最终输出（§2.7）：由光子温度、色温与气体温度按耦合强度做调和加权。它不是真实温度，只描述两个自旋态上的原子数之比——信号的正负与幅度都由它定。

代码上它紧跟耦合系数之后，分两支（`:1337-1357`）：背景足够强时从 `Trad` 出发迭代到相对变化小于 $10^{-3}$，否则走只含碰撞的闭式；最后取绝对值输出（`:1368`）。

```c
            TS_fast = (xCMB + xa_tilde_fast + xc_fast) *
                      pow(xCMB * consts->Trad_inv +
                              xa_tilde_fast * (T_inv + 0.405535 * T_inv * pow(TS_fast, -1.) -
                                               0.405535 * T_inv_sq) +
                              xc_fast * T_inv,
                          -1.);
```

（`:1348-1353`。）解析版把同一式写成 $T_S=(1+\tilde x_\alpha+x_c)/(1/T_\gamma+\tilde x_\alpha/T_\alpha+x_c/T_K)$（`heating_helper_progs.c:737-742`），差别只在光子项是 1 还是 `xCMB`（§3.3）。

**它在链上的位置是本块交出去的那张场，局限在平衡假设。** 自旋态的非平衡分布、莱曼-$\alpha$ 的多次散射细节与 X 射线对自旋的直接扰动都不在这套三温度加权里；而它依赖上一快照的三个量，所以步长与初值都在影响它。**名下参数**：`CLUMPING_FACTOR` 与四个开关（§4.4、§4.6），其余经 `x_α`、`x_c`、`T_K` 与 `T_γ` 传入。论文出处：§2.2 碰撞耦合、§3.5 耦合（见文末）。
