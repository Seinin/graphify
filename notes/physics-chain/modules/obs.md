# 亮温与观测

这一块是链的出口：把前面算出的中性氢份额、自旋温度与密度折成差分亮温，再把盒子统计成功率谱。另一个成员属于观测侧——汤姆逊光深。整条链上，模型参数最后都要靠这里的亮温与功率谱去约束。

三个成员的分工也在这里定下。差分亮温与它的功率谱带着空间信息，能量出"电离到哪一步、气体热不热"；汤姆逊光深只有一个数，量的是微波背景光子被自由电子散射的累积概率，只能用全宇宙平均的电离历史去算。两者一起用，才能把再电离的时点和形状拆开。前两个出自同一个盒子，第三个不然——它是热化学那一段沿红移积出来的，不在本块的产物结构里。这块最容易被找错的地方就在这里。

这篇文档先讲它在链上做什么与依据的物理，再按"一格点一行乘积、一段分析侧统计、一次历史积分"的次序落到代码上，然后是参数与陷阱；文末三节逐个交代三个成员的定位与落点，代码地图与论文出处收在末尾。公式、系数与行号均取自本仓当前源码。

## 一、这块在链上做什么

**一句话**：把链上算出的份额、温度与密度折成能跟观测比的三个数——逐格点的差分亮温、它的功率谱，以及一个标量光深。

| | 内容 |
| :--- | :--- |
| 输入 | 逐格点的中性氢份额、自旋温度、光子温度与密度扰动；光深那一支另要全宇宙平均的电离历史 |
| 输出 | 亮温盒 $\delta T_b(\mathbf x,z)$ 与它的全盒平均；21 厘米功率谱 $P_{21}(k,z)$；汤姆逊光深 $\tau_e$ |
| 下游 | 观测对比、参数约束与光锥拼接（光锥与仪器效应在本链之外） |
| 参数 | `OMb`、`OMm`、`hlittle`、`USE_TS_FLUCT`（§四） |

**物理图像**：亮温是"宇宙微波背景上叠出来的那一点吸收或发射"，所以它的式子必然由三段构成：那里有多少中性氢（份额）、自旋温度与光子温度差多少（对比度），以及这段历史在什么红移上（前因子）。份额为零就没有信号，温度相等也没有信号——这两个零点把亮温随红移的曲线切成"吸收—发射—消失"的形状。光深是另一件事：光子被自由电子散射的概率沿整段红移累积，因此它只看电离总量，不看电离发生在哪。

**为什么是独立一块**：前面各块产出的都是物理量本身（份额、温度、密度、源强），而观测对上的是亮温与功率谱。这是链上唯一做"折成观测量"这件事的地方，也是整条链的终点：气体热、电离与源的变化最终都要经过它才能和观测比。光深虽然由另一段代码积出，但它回答的是同一个问题——微波背景那一侧对再电离知道些什么。

## 二、物理骨架

### 2.1 差分亮温：三个因子相乘

$$\delta T_b(z)=27\,x_{\rm HI}(z)\left(1-\frac{T_\gamma}{T_S}\right)\left(\frac{1+z}{10}\right)^{1/2}\frac{\Omega_b h^{2}}{0.023}\left(\frac{0.15}{\Omega_m h^{2}}\right)^{1/2}\ \mathrm{mK}$$

它是差分亮温：衡量在宇宙微波背景上叠出来的那一点吸收或发射，数值由三个因子相乘——中性氢份额、自旋温度与光子温度的相对差，以及按宇宙学参数与红移算出的前因子。自旋温度低于光子温度时为吸收（亮温为负），高于时为发射，量级在几十毫开尔文。

物理上有两种等价写法：按自旋温度写（上面这一条），或按光深与两个温度之差写。前提是光学厚度在分辨率以下被视为局域，且气体温度与自旋温度已由上游自洽求出，取温也用到了瑞利-金斯近似。

它有两个零点：自旋温度与光子温度相等时信号被抵消；中性氢份额为零（完全电离）时信号消失——再电离的结束因此在亮温上表现为信号消失而不是变号。亮温对自旋温度的依赖是非线性的：自旋温度越接近光子温度，同样大小的温度变动给出的信号越小，所以信号最深的那一段出现在耦合刚把自旋温度拉下来的时候，而不是自旋温度最低的地方。

它是整条链唯一的可观测量：气体热、电离与源的变化最终都要经过它才能和观测对比，涨落盒再做统计就得到功率谱。局限在它按格点局部计算、不做沿视线的辐射转移积分——真实的观测是沿光锥累积的，光锥与演化效应的差别留给下游的光锥拼接。

### 2.2 亮温功率谱：三项按角度加权

$$\Delta^{2}_{21}(k,z)=\frac{k^{3}}{2\pi^{2}}P_{21}(k,z),\qquad P_{21}=\delta T_b^{2}\left[\mu^{4}P_{\delta\delta}+2\mu^{2}P_{\delta x}+P_{xx}\right]$$

21 厘米功率谱是分析侧的统计量：把亮温的盒子在波数空间做统计得出，振幅是亮温平均值的平方乘上三项组合——密度自功率、密度与中性氢份额的交叉项、中性氢份额的自功率。权重由波矢与视线夹角的余弦给出，四次的给密度自功率、二次的给交叉项、常数项给中性氢份额的自功率；视线方向的速度梯度以红移空间畸变的形式进到密度项里。前提是亮温涨落相对平均足够小、可以做线性分解，且各向异性的来源只有速度梯度这一项。

波矢与视线夹角的余弦决定各项的权重：垂直于视线时中性氢份额的自功率主导，沿视线时密度与速度梯度的贡献放大，所以不同角度对应不同物理主导的尺度，同一张谱在不同角度上给出不同信息。

它是与观测直接对比的那一层，也是把模型参数约束住的地方：三项的相对幅度分别对源、电离与气体热敏感，因此联合不同红移与不同角度可以把几个简并的因子拆开。局限在实现只做均匀盒的统计，光锥几何、有限带宽与仪器噪声都要在观测侧另加，盒子里的模式离散也会在小波数端造成采样误差。

### 2.3 汤姆逊光深：一行历史积分

$$\tau_e=\sigma_T\,\bar n_{\rm H,0}\,c\int_{0}^{\infty}\mathrm dz\,\frac{(1-Q_{\rm HII})\,(1+z)^{2}}{H(z)}$$

汤姆逊光深量的是微波背景光子被自由电子散射的累积概率：沿整段红移历史对自由电子积分，被积函数是电离份额、红移平方与膨胀率的组合。它是微波背景侧对再电离唯一的直接约束量。

公式是一层红移积分，被积项为电离份额乘红移平方再除以膨胀率；完全电离的红移区间以及氦的再电离也按各段的电子份额分段处理。前提是均匀电离：被积函数只用全宇宙平均的电离份额，电离泡的形态与增长历史都不进入积分。

信息极度压缩：整条电离历史被压成一个标量，所以不同的电离历史可以给出同一个光深——这也是光深不能单独定出再电离红移的原因。它与 21 厘米一起用，才能把再电离的时点与形状分开。

## 三、代码：一格点一行乘积、一段分析侧统计、一次历史积分

### 3.1 `ComputeBrightnessTemp`：两条等价写法在一处

`ComputeBrightnessTemp`（`BrightnessTemperatureBox.c:72-86`）把 §2.1 那两条等价写法都实现了，分支条件就是 `USE_TS_FLUCT`。默认那一支只有一行乘积：前因子 `const_factor`（循环外按红移与宇宙学参数算好）乘中性氢份额、乘密度扰动。

```c
                        box->brightness_temp[index] =
                            const_factor * pixel_x_HI * (1 + pixel_deltax);

                        if (astro_options_global->USE_TS_FLUCT) {
                            // Converting the prefactors into the optical depth, tau. Factor of 1000
                            // is the conversion of spin temperature from K to mK
                            box->brightness_temp[index] *=
                                (1. + redshift) / (1000. * spin_temp->spin_temperature[index]);
                            box->tau_21[index] = box->brightness_temp[index];
                            box->brightness_temp[index] =
                                (1. - exp(-box->brightness_temp[index])) * 1000. *
                                (spin_temp->spin_temperature[index] - T_rad) / (1. + redshift);
                        }

                        ave += box->brightness_temp[index];
```

（`:72-86`。）打开自旋温度涨落之后，同一行被拆成两步：先把乘积折成光深 `tau_21`——乘上 $(1+z)/(1000\,T_S)$，其中 1000 是把自旋温度从开尔文换成毫开尔文；再按饱和形式 $(1-e^{-\tau})\cdot 1000\cdot(T_S-T_\gamma)/(1+z)$ 写回亮温。同一趟循环里还把逐格点的值累加出全盒平均，标量 $\delta T_b$ 就是从这里出来的。

### 3.3 `dtau_e_dz`、`tau_e` 与 `ComputeTau`：一次历史积分

被积函数在 `dtau_e_dz`（`thermochem.c:161-191`），读它主要看两个边界情形怎么处理。一是红移数组为空、或目标红移高于数组起点（表示再电离还没开始），被积函数直接取完全电离的值——这就是 §2.3 里"完全电离的红移区间按段处理"落在代码里的样子。二是在数组区间内，中性份额按红移线性插值再取补得电离份额；插值结果越界会被夹回 $[0,1]$ 并告警，因为一次非物理的插值会被积分成系统性偏差，而不是一个可以忽略的局部错误。

```c
double dtau_e_dz(double z, void *params) {
    float xH, xi;
    int i = 1;
    tau_e_params p = *(tau_e_params *)params;

    if ((p.len == 0) || !(p.z)) {
        return (1 + z) * (1 + z) * drdz(z);
    } else {
        // find where we are in the redshift array
        if (p.z[0] > z)  // ionization fraction is 1 prior to start of array
            return (1 + z) * (1 + z) * drdz(z);
        while ((i < p.len) && (p.z[i] < z)) {
            i++;
        }
        if (i == p.len) return 0;

        // linearly interpolate in redshift
        xH = p.xH[i - 1] + (p.xH[i] - p.xH[i - 1]) / (p.z[i] - p.z[i - 1]) * (z - p.z[i - 1]);
        xi = 1.0 - xH;
        if (xi < 0) {
            LOG_WARNING("in taue: funny business xi=%e, changing to 0.", xi);
            xi = 0;
        }
        if (xi > 1) {
            LOG_WARNING("in taue: funny business xi=%e, changing to 1", xi);
            xi = 1;
        }

        return xi * (1 + z) * (1 + z) * drdz(z);
    }
}
```

积分收尾在 `tau_e`（`:269-272`）：结果乘上汤姆逊截面与氢、氦的柱密度组合——其中氦的电子数用再电离红移前后两套值，这就是分段处理里的另一段。

```c
    gsl_integration_workspace_free(w);

    return physconst.sigma_T * ((N_b0 + He_No) * prehelium + N_b0 * posthelium);
}
```

外面的入口是 `ComputeTau`（`:274-276`）：把整条 `x_HI(z)` 与红移网格交给它，含 HeII 再电离红移 `z_re_HeII`。

```c

```

## 四、参数

本模块 4 个参数，按"它在这块里改什么"分成两组（与画布上这块的「参数」卡同一份清单；类别是 `inputs.py` 里的结构名）。

### 4.1 幅度与红移形状：`OMb`、`OMm`、`hlittle`

| 参数 | 类别 | 在代码里做什么 |
| :--- | :--- | :--- |
| `OMb` | `CosmoParams` | 重子密度。亮温正比于中性氢的数密度（经 $n_{\rm H}\propto\Omega_b h^2$），所以它直接进幅度；同时又经上游源项改电离历史，也就是改 $x_{\rm HI}$ 随红移的曲线。两个作用方向相同地压低或抬高信号；到功率谱那一级，它正比于亮温的平方，以平方级别的权重进幅度。 |
| `OMm` | `CosmoParams` | 总物质密度。它进膨胀率与密度扰动的归一，因此改亮温随红移的演化形状以及涨落盒的对比度——改的不是整体高度，而是曲线怎么弯；到功率谱那一级，它还改波数到物理尺度的换算，于是形状随时间的漂移也跟着变。 |
| `hlittle` | `CosmoParams` | 无量纲哈勃常数。亮温正比于 $1/H(z)$、又正比于重子数密度（$\propto\Omega_bh^2$），两个方向同时作用；它还把波数与物理尺度的换算改掉，因此分析侧的尺度读数也随之变。 |

三条都在 §3.1 循环外算出的前因子 `const_factor` 里落地，所以它们改的是整盒的幅度口径，而不是空间图案；`OMm` 是这三条里唯一同时动上游电离历史的一条。

### 4.2 开关：`USE_TS_FLUCT`

自旋温度涨落的总开关，也是本块唯一一条改"走哪条式子"的参数。打开时盒子里每个格点取自己的自旋温度，亮温按饱和形式（先折光深再写回）算，涨落里因此含自旋温度那一份贡献（黎明段这一份往往是主导）；关闭时全盒只有一个自旋温度，亮温走那条一行乘积，涨落只剩密度与电离度的贡献。功率谱在两种口径下形状明显不同，比较结果前必须先对齐这条开关（§五 第一条）。

本块没有空转的参数：四条都在 §三 那三处算式或分支里真实生效，其中前三条进亮温的前因子、`USE_TS_FLUCT` 决定亮温走哪条写法。光深那一支算式里没有自由参数——它的输入是上游的整条电离历史。

## 五、陷阱

**一、亮温有两条等价写法，比较之前先对齐开关。** 默认那一支与开自旋温度涨落那一支在光深很小时一致，但格点上的自旋温度一旦偏离全盒值，两者给出的涨落盒就不同（§3.1）。同一模型的两次运行若开关不同，看不出"物理差在哪"。

**二、两处 1000 不是同一个换算。** `:75-77` 那个 1000 是把自旋温度从开尔文换成毫开尔文（量纲），`:79-80` 那个 1000 来自前因子里的温度比例。代码注释专门点明了这一点，照抄公式时容易合并成一个。

**三、$\delta T_b$ 有两个零点，都是信号消失。** 自旋温度与光子温度相等时对比度为零；中性氢份额为零时也没有信号（§2.1）。所以再电离的结束在亮温上看不到变号，只看到信号消失。

**四、$P_{21}$ 不是模拟产出的。** 它是分析侧对亮温盒子做的统计（§3.2），产物清单里没有功率谱。想从模拟输出里找它，会一无所获。

**五、$\tau_e$ 把整条历史压成一个数。** 不同的电离历史可以给出同一个光深（§2.3），所以它不能单独定出再电离红移；反过来，拿它当约束用时，约束的是整条电离历史，不是某一个参数。

**六、光深不在本块的盒子里算。** 它由热化学那一段沿红移积出（§3.3），本块的主体是亮温那一支。按产物结构去找光深会找错地方。

### 一份最小检查清单

- 比较亮温盒：先确认两次运行的 `USE_TS_FLUCT` 是否一致（§五 第一条）。
- 追亮度：`OMb`、`hlittle` 与源侧的效率参数一起看，它们高度简并。
- 用 $\tau_e$ 当约束：记住它约束的是整条电离历史（§2.3）。
- 想要功率谱：去分析侧，模拟输出里只有亮温盒。

## 六、δT_b(z) · 21cm 平均亮温

它是本块的头号输出，也是整条链唯一的观测量：气体热、电离与源的变化最终都要经过它才能和观测对比（§一 表格）。物理上它是三个因子相乘——中性氢份额、自旋温度与光子温度的相对差，以及按宇宙学参数与红移算出的前因子（§2.1）。

代码上它的落点在 `ComputeBrightnessTemp`（`BrightnessTemperatureBox.c:72-86`）：一格点一行乘积，开自旋温度涨落时改走光深那一支，同一趟循环里累出全盒平均（§3.1）。

**它的位置在链的末端，局限在按格点局部计算。** 真实的观测是沿光锥累积的，这里不做辐射转移积分，光锥与演化效应的差别留给下游拼接。**名下没有参数**（§四）：改它的是前因子里的三条宇宙学参数与那条自旋温度涨落开关，各自的作用写在 §4.1 与 §4.2。论文出处：§3 全局 21cm 信号（见文末）。

## 七、P_21(k,z) · 21cm 功率谱

它把亮温盒子的涨落折成波数空间的统计：振幅是亮温平均值的平方，乘上密度、密度与份额的交叉项、份额自功率三项按角度加权的组合（§2.2）。它是与观测直接对比的那一层。

代码上它的落点在分析脚本的 `pr_feature`（`cli.py:718-734`）：沿光锥逐片调用功率谱库，两条光锥各扫一遍（§3.2）。它不在模拟推进的路径上。

**它的位置在分析侧，局限在均匀盒统计。** 光锥几何、有限带宽与仪器噪声都要在观测侧另加，盒子里的模式离散还会在小波数端留下采样误差。**名下没有参数**（§四）：它继承亮温那一组的四条——`OMb`、`OMm`、`hlittle` 改幅度口径，`USE_TS_FLUCT` 决定谱里有没有自旋温度那一份贡献；到这一级这些幅度以亮温的平方进权重（§4.1 表）。论文出处：§4 涨落与功率谱（§4.1 红移空间畸变、§4.2 电离涨落）（见文末）。

## 八、τ_e · 汤姆森光深（标量）

它是微波背景侧对再电离唯一的直接约束量：沿整段红移历史积分自由电子，得到一个数（§2.3）。它不出自亮温盒子，而是热化学那一段的产物（§3.3）。

代码上它的落点分三处：被积函数 `dtau_e_dz`（`thermochem.c:161-191`）、积分收尾与柱密度组合 `tau_e`（`:269-272`）、入口 `ComputeTau`（`:274-276`）。

**它的位置是全局参照，局限在只有一个数。** 整条电离历史被压成一个标量，不同的历史可以给出同一个值，所以它只能与 21 厘米一起用来拆再电离的时点与形状。**名下没有参数**（§四）：能改它的量全在上游——电离分数随红移的曲线与膨胀率。论文出处：§3.2 全局信号的演化（见文末）。
