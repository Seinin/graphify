# 初始条件

这块给整条链定起点：盒子里物质分布的随机实现、它引起的第一批运动，以及重子与暗物质之间那条速度差。后面的引力演化、晕目录、电离与加热都从这几张场长出来——起点一定，整条链的空间结构就跟着定。

几个成员的性质并不对称。密度场是唯一的随机源：零均值高斯、相位随机，全部统计信息压在一条功率谱里。两条位移场不是新信息，而是同一张密度场的加权梯度（一阶）与它的自耦合修正（二阶）——密度场一改，位移场跟着改。相对速度与密度场同相位，但在代码里它是另一种东西：不是从密度场算出来的，而是**换一套振幅重新装配**出来的场。

四张场都只算一次，不随红移重算：位移场记的是初始时刻的位移，不是任意时刻解出来的速度，乘生长因子那一步在下游。这也划出了本块的边界——初始红移以下的非线性演化不归这里管。这篇文档顺着计算真实发生的顺序写：先讲这块在链上做什么与它依据的物理，再逐段落到 `InitialConditions.c` 上，然后是参数读法与陷阱清单；文末四节逐个交代本块四个对象的定位与落点，代码地图与论文出处收在末尾。公式、系数与行号均取自本仓当前源码。

## 一、这块在链上做什么

**一句话**：把一条按物质功率谱抽出的高斯随机密度场，连同它的一阶、二阶位移场与重子—暗物质相对速度，一次算好交给引力那一段。

| | 内容 |
| :--- | :--- |
| 输入（链上） | 无。这块在链的最上游，与宇宙学背景并列，不吃任何上游盒 |
| 输入（参数） | 本模块不挂参数标签；它读的是功率谱、随机种子与几个开关（见 §四） |
| 主输出 | 初始密度场 $\delta_i$（高分辨网格，另存一份低分辨降采样），一阶位移三分量 |
| 可选输出 | 二阶位移三分量（`PERTURB_ALGORITHM == 2LPT` 时）；重子—暗物质相对速度场（`USE_RELATIVE_VELOCITIES` 打开时） |
| 下游 | 引力演化：线性支把 $\delta_i$ 乘 $D(z)$（`PerturbedField.c:60-77`），Zel'dovich 与 2LPT 两支按 $D(z)-D(z_i)$ 与 $-\tfrac37[D^{2}-D_i^{2}]$ 搬动粒子（`map_mass.c:160-174`）；晕目录、电离场与源项从这些场上长出来 |

**物理图像**：结构不是凭空长出来的。早期宇宙里那条近似尺度不变的曲率扰动，到这里变成一张具体的、带相位的空间图案：振幅按功率谱分布、相位随机，所以它只是一个统计实现——同一套宇宙学、不同种子给出不同的团块分布。位移场把"物质会往哪里流"提前写好：一阶取密度场的梯度方向（高密度处物质被拉过去），二阶补上一阶自身引力造成的偏差。相对速度是另一条独立线索：复合前后重子被光子拖住、暗物质只顾自引力塌缩，两者错开的运动留下一张几十千米每秒量级的场，它不改密度图案，只在小质量晕的成核上打一个门槛。

**为什么必须有这一步**：整条链的空间结构由这一步的实现唯一决定，换种子就换一个宇宙。它也划定了模拟的分工——初始时刻被假定在线性区，之后的非线性演化交给引力求解，把非线性硬塞进这里不成立。相对速度之所以单独存在，是因为它挂在一条与密度无关的物理线索上（两类物质受力不同），下游的恒星形成门槛直接读它。

## 二、物理骨架

### 2.1 一张高斯随机密度场

谐波空间里，物质密度对比的每一条模是零均值高斯变量：实部与虚部各抽一个标准正态，方差按功率谱定；回到实空间就是一张带相位的密度图案。

$$\delta_i(\mathbf x)=D(z_i)\,\delta(\mathbf x),\qquad \langle\delta_{\mathbf k}\delta^{*}_{\mathbf k^{\prime}}\rangle=V\,P(k)\,\delta_{\mathbf k\mathbf k^{\prime}}$$

第二条式子是抽样规则在统计上的结果：每条模的振幅量级是 $\sqrt{V\,P(k)/2}$（两个自由度的方差各分一半），相位随机。$\delta$ 的原点取整体平均密度，所以它是无量纲的对比值，全盒平均为零。

物理上它是一张"当时的物质分布图"：起伏从小到大连续分布，小尺度起伏更强（$P(k)$ 在小尺度更大），盒尺度上平滑之后的均方根通常只有千分之几到百分之一。它是**线性**场，全部统计信息压进一条两点功率谱——单点分布是高斯、相位随机，高阶矩不携带额外信息；功率谱放大多少倍，场就放大同样的倍数。

第一式里那个 $D(z_i)$ 是"外推到初始红移"这一步。物理上初始条件指初始红移处的场，代码里抽出来的却是按今天的功率谱归一的那一条（功率谱一律在 $z=0$ 口径给出，见宇宙学那一块），乘 $D(z_i)$ 的动作发生在下游（§3.1、§五 第一条）。成立的前提是初始红移仍落在物质主宰的线性区：初始红移取得越高，线性外推越干净；取得越低，初始时刻就已进入非线性的尺度越多，而这张场不管那些尺度。

驱动这张场的只有随机种子与功率谱；初始红移只决定它在什么时候被解读。

### 2.2 从密度场到位移场：一阶与二阶

位移场把结构形成写成一场搬移：粒子不是停在原地慢慢聚集，而是从均匀的初始位置被一个位移场整体搬走。一阶（Zel'dovich 近似）取位移的时间导数：

$$\mathbf v_{1\mathrm{LPT}}=-f(z)\,H(z)\,D(z)\,\nabla\nabla^{-2}\delta$$

位移势与密度场由同一个泊松方程挂钩，位移沿密度梯度方向——密度高的地方，物质被拉向更密处。它只有纵模：横向分量在膨胀中按 $1/a$ 衰减，到宇宙黎明已可忽略，所以整条场能由一个标量势的梯度完全表达。它是线性的，却不局域——逆拉普拉斯是卷积，一个点上的值取决于整条密度场；它也没有独立的随机性，密度场一改，它跟着改。

二阶补的是一阶自身引力造成的偏差：一阶把"位移正比于密度"写对，但一阶位移场自身也带引力，会让密度演化偏慢。它由一阶位移势的二阶导数组合解出：

$$\nabla^{2}\phi_2=\sum_{i>j}\left[(\partial_i^{2}\phi_1)(\partial_j^{2}\phi_1)-(\partial_i\partial_j\phi_1)^{2}\right],\qquad \mathbf v_{2\mathrm{LPT}}=-\tfrac{3}{7}D^{2}\,\nabla\!\left(\nabla^{-2}\mu_2\right)$$

前提与一阶相同（位移仍无旋），代价是多压一个生长因子 $D^{2}$，所以越晚它才越重要。尺度依赖也写在式子里：大尺度上它几乎不动，小尺度上它是主要的改正项——Zel'dovich 近似在小尺度会偏，二阶把那部分补回来。它是高阶修正，不改场的起点，只改位移的精度。

两条式子里的时间因子都明写在系数里，而代码里位移场**不含**它们（§3.1、§五 第一条）。

### 2.3 重子—暗物质相对速度

复合前后重子与暗物质受力不同：暗物质只受引力，重子还被光子拖住，于是两者之间留下一条随空间变化的相对速度。

$$\mathbf v_{cb}(\mathbf x)=\mathbf v_c(\mathbf x)-\mathbf v_b(\mathbf x)$$

它在复合时刻以几十千米每秒的均方根铺满整盒，相干长度是几个百万秒差距量级，之后随尺度因子反比衰减，但到宇宙黎明仍有可观振幅。它只在大尺度上有意义：相干尺度有限，小尺度上早被非线性演化抹平，那里真正起作用的是密度与电离的局部结构。

它不是独立的随机场——与密度扰动取自同一套初始条件、同相位，逐格点、无筛选，随初始条件一起给出。它的作用是对小质量晕的恒星形成额外界定一个局部门槛：相对速度大的地方，气体在塌缩前就被推走，成核与冷却被压后，那里的源形成更晚、更少。它不改密度图案，只改「哪里的气体能塌缩」。

## 三、代码：从随机相位到四张场

### 3.1 总装：`ComputeInitialConditions` 的次序

整个块只有一条主线（`src/py21cmfast/src/InitialConditions.c:547-776`）：`init_ps` 取功率谱 → 抽样（或读入）k 空间的密度场 → 备份成 `HIRES_box_saved` → 变换回实空间得到 `hires_density` → 按低分辨奈奎斯特滤波再降采样得到 `lowres_density` → 相对速度 → 一阶位移 → 二阶位移。

三件事值得先记住：

- **`HIRES_box_saved` 是这张密度场的 k 空间副本**（`:610` 分配、`:669` 备份），后面所有算子都作用在它上面，因此它是相对速度与两条位移场共同的输入。两处细节：降采样前用 `memcpy(HIRES_box, HIRES_box_saved, ...)`（`:699`）把工作盒复原回密度场；2LPT 那一步会**覆盖** `HIRES_box_saved`（`:507`，函数注释里明写 "modified in this function, and not restored afterwards"），所以它排在最后（`:751`）。
- **抽样与读入二选一**：先扫一遍 `hires_density` 找非零（`:622-632`），给了就反着走——把实空间密度乘 `VOLUME / TOT_NUM_PIXELS` 写进盒、变换到 k 空间当密度场（`:638-665`），跳过抽样（§3.6）。
- **`PERTURB_ALGORITHM` 只门控 2LPT**：一阶位移场无条件算（`:740`），只有档位等于 `2` 时才接二阶（`:751`）。选 `LINEAR` 时这些位移场照旧被算出来写进盒子，只是下游改用 $D(z)\delta_i$ 那条路（§五 第二条）。

### 3.2 `sample_ic_modes` 与 `adj_complex_conj`：抽模与实场约束

`sample_ic_modes`（`InitialConditions.c:103-139`）就是那条抽样规则本身：

- 三重循环里 `n_z` 只走到 `dim[2] / 2`（`:116`）——实空间场是实数，k 空间的后一半与前一半互为共轭，只有半边是独立模（这句写在注释里）。这个约定在文件里反复出现：后面每个 k 空间算子也都只写半边。
- 每条模的波数由 `index_to_k` 给出（`:112-117`），只取模长 `k_mag` 去查功率谱（`:121-122`），各向同性因此被显式用上。
- 两个标准正态 `a`、`b` 由当前线程的 GSL 流抽（`:126-127`），写成一条 k 空间的复数值：

```c
box[grid_index_fftw_c(n_x, n_y, n_z, grid_dim)] = sqrt(VOLUME * p / 2.0) * (a + b * I);
```

（`:129-130`。这里除了体积之外没有别的归一，也没有任何时间因子。）

`adj_complex_conj`（`:26-101`）紧接着把这张半边场补成一个合法的实场变换结果，三件事按顺序做：

- 七个自共轭角点（坐标取 $0$ 或 `dim / 2` 的那些位置：三条轴的中点、三个面心与那个角点）本来应当是实数，逐个取实部（`:47-49`）；
- 直流模（$k=0$）置零（`:51`）——全盒平均值不带信息，物理上这一项就是零；
- 其余每条模按 $\delta_{-\mathbf k}=\delta^{*}_{\mathbf k}$ 从半边补齐（`:60-100`），分三段处理：$i$ 在内部而 $j$、$k$ 取边界的那些行、$j$ 也在内部的那些行、以及 $i$ 取两端的边界行。

### 3.3 一阶位移：`compute_f_gradient` 与 `compute_velocity_fields`

两个 k 空间小算子（`InitialConditions.c:240-267` 与 `:269-297`）是一阶与二阶共用的：

- `compute_f_gradient`：`box_out = box_in * k_i * I / k²`（`:260`），一步做出"梯度 + 逆拉普拉斯"；
- `compute_f_laplacian`：`box_out = -k_i k_j box_in / k²`（`:290`），做二阶导数的组合。

两个函数都在末尾把直流模单独置零（`:266`、`:296`），注释写明了原因——那里要除以 $k^{2}$，循环里算出来是 nan。`compute_f_laplacian` 的注释里还有一句提醒："The Volume factor anticipates an inverse FFT"（`:289`），但这行本身并没有体积因子，归一在调用方（§3.4、§五 第四条）。

`compute_velocity_fields`（`:299-364`）按三个方向各做一遍，每遍两步。第一步在 k 空间用 `compute_f_gradient` 作用在 `box_saved` 上（`:327`）——"速度是位移的时间导数"在代码里就是这一步；第二步按需要滤波、变换回实空间、降采样写进 `vel_pointers[ii]`：

- 滤波只在 `PERTURB_ON_HIGH_RES` 关掉、且高低分辨不同时做（`:330-337`），截断尺度是 `l_factor · BOX_LEN / HII_DIM`，与低分辨的奈奎斯特一致；
- 降采样与密度场那次一样是**取值**：按分辨率之比算出中心像素、直接取那一个值（`:349-359`），再除以体积归一（`:356`）；
- 三个分量来自同一份 `box_saved`，只有轴指标不同——这是"速度不是独立自由度"在代码里最直接的体现。

输出指针由 `PERTURB_ON_HIGH_RES` 决定指向高分辨那三张还是低分辨那三张（`:585-599`）：这个开关改的是**存在哪张网格**，不改算法。

### 3.4 二阶位移：`compute_velocity_fields_2LPT`

`compute_velocity_fields_2LPT`（`InitialConditions.c:366-544`）先把源项拼出来，再走一阶同一条路：

1. 工作盒清零（`:405-418`）——源项靠累加得到。
2. 三个对角分量 $\phi_{1,ii}$ 各做一次 `compute_f_laplacian` → `dft_c2r_cube` → 存进 `diag_storage_pt`（`:421-447`）。这块存储借的是 `hires_vi_2LPT` 那三个盒（`:584`、注释 `:372-373`），为此不另分配内存。
3. 三个混合对 $(i,j)=\{(0,1),(0,2),(1,2)\}$（`:403` 的表）各做一次 `compute_f_laplacian` → `dft_c2r_cube`，然后逐格累加 $\phi_{ii}\phi_{jj}-\phi_{ij}^{2}$（`:451-482`，即式中的和项）。两项分成 `+=` 与 `-=` 两行写，注释说明这是为了与旧实现保持相近的舍入（`:475`），不是笔误，合成一行会在低位上变数。
4. 整盒除以 $V^{2}N$（`:486-498`），再变换回 k 空间（`:501-502`）、备份进 `box_saved`（`:507`，**覆盖**原来那张密度场）。
5. 之后与一阶同路：逐方向 `compute_f_gradient` → 按需滤波 → `dft_c2r_cube` → 降采样写 `out_v_pointers[ii]`（`:510-543`）。这一步**不再**除体积——体积因子在第 4 步已经除过（§五 第四条）。

### 3.5 相对速度：`compute_relative_velocities`

`compute_relative_velocities`（`InitialConditions.c:141-238`）不重新抽相位，而是在 `box_saved` 上换振幅：每条模取出方向因子与两个功率谱的比值，单位换算成千米每秒。

```c
box[index] = box_saved[index] * I * kvec[ii] / k_mag * sqrt(p_vcb / p) * physconst.c_kms;
```

（`:188-189`。$ik_i/k$ 把标量场转成沿 $i$ 方向的分量，$\sqrt{P_{vcb}/P}$ 换掉功率谱，"同一份相位、换一套振幅"在代码里就是这一个乘式。）

两次循环各有一次固定动作与一处约定：

- 直流模单独置零（`:184-185`）——那里要除以 $k$；与 3.2 小节里同一个处理一样，是这一族 k 空间算子的固定动作。
- 三个方向依次做完之后才输出：先按低分辨奈奎斯特滤波（`:194-206`，条件与截断尺度同一阶位移那处完全一致），变换回实空间，再把三分量的平方在低分辨格点上**累加**（`:230-231`），最后统一开方、除以体积（`:232-233`）：

```c
out_vcb_pt[grid_index_general(i, j, k, lo_dim)] =
    sqrt(out_vcb_pt[grid_index_general(i, j, k, lo_dim)]) / VOLUME;
```

所以下游读到的这张场是相对速度的**大小**，方向信息在累加那一步丢掉了；也因为累加写在输出数组自己身上，调用之前它必须为零（§五 第五条）。调用点由开关守着（`:734-736`）：不开就整项跳过，这张场保持为零，下游那条门槛修正也跟着不生效。

### 3.6 调用方给了密度场的那条岔路

`ComputeInitialConditions` 开头扫一遍高分辨密度场（`:622-632`）：只要有一个格点非零，就认为初始条件由调用方给定，于是

- 把给定的实空间场乘 `VOLUME / TOT_NUM_PIXELS` 写进盒（`:649-652`，注释写明这个因子的来路：实空间转 k 空间的换算）→ `dft_r2c_cube` 变换到 k 空间（`:659-662`）→ 备份成 `HIRES_box_saved`（`:665`）；
- 抽样整段被跳过（`:666-669` 的 else 支），而 `hires_density` **不被改写**——把高分辨密度从工作盒搬回结构体那一段（`:671-697`）整个属于抽样支，因此给定期场时结构体里留的就是调用方填进去的那张场；
- 低分辨密度照旧从 `box_saved` 滤波、降采样得到（`:699-732`），位移场与相对速度也照旧算——它们的输入是 `box_saved`，不关心它来自抽样还是来自输入。

这条路里有一处注释与全文件的叫法相反：`:660` 那行把 `dft_r2c_cube` 写成 "Inverse FFT'd"，而同一个文件里 `dft_c2r_cube` 才被注释称作 "FFT back to real space"。按注释判断方向会看反，认函数名才可靠。

## 四、参数

### 4.1 本模块不挂参数标签

本块四个对象名下都没有参数标签：它们读的全是上游量——功率谱、随机种子、以及几个开关。能改这张场的上游选择也就这么几处：归一（$A_s$ 或 $\sigma_8$）定整体幅度、功率谱口径定谱形、种子定具体实现。涉及随机种子的比较必须固定种子，否则换的是一个不同的实现——统计相同，图案不同。

作用在相对速度上的那几个参数（`A_VCB`、`BETA_VCB` 拿它算分子冷却阈值的放大与幂指数，`FIXED_VAVG` 配 `FIX_VCB_AVG` 把逐格点的值换成固定平均值）决定的是**怎么用它**，落点在下游的晕与源那一块。扫描时想改相对速度的影响，动的是那几个参数；改种子只会换一张实现。

### 4.2 决定它怎么跑的几个开关

- **`PERTURB_ALGORITHM`**（`MatterOptions`，默认 `2LPT`）：决定下游搬不搬粒子、用不用二阶项。取 `2LPT` 时本块多算一张二阶位移场（`:751`），取 `ZELOVICH` 只用一阶，取 `LINEAR` 则两条位移场都不进链——但它们照旧被算出来写进盒子（§五 第二条）。
- **`PERTURB_ON_HIGH_RES`**（默认关）：决定位移场存在高分辨还是低分辨网格上（`:585-599`），顺带决定那道低分辨滤波做不做（`:330-337`）。它只改存储与滤波位置，不改算法。
- **`USE_RELATIVE_VELOCITIES`**（默认关）：决定相对速度整项是否存在。它要求 `POWER_SPECTRUM == "CLASS"`，校验器在 `wrapper/inputs.py:695-700` 强制这一点，所以非 CLASS 口径下开这个开关会直接报错，不会静默失效；关掉时 `lowres_vcb` 保持为零，下游那条门槛修正也随之消失。
- **`INITIAL_REDSHIFT`**（`SimulationOptions`，默认 300）：**本块一个字都不读**（§五 第一条）。它是外推的基准点，由下游用 $D(z_i)$ 与 $D^{2}(z_i)$ 减掉（`map_mass.c:163-174`）。

### 4.3 在这块不起作用的东西

- **天文参数**：`HII_EFF_FACTOR`、`F_STAR10`、`F_ESC10` 这一类本块一个都不读，初始条件的图案与它们无关。
- **`POWER_SPECTRUM` 的非 CLASS 档位**：与相对速度搭配无意义，`power_in_vcb` 只支持 CLASS（`cosmology.c:339-361`），开开关时被校验器挡在前面。
- **`KEEP_3D_VELOCITIES`**：本块不读它；它决定下游 `PerturbedField` 要不要算 $x$、$y$ 两个速度分量（`PerturbedField.c:464-469` 只算 $z$ 之外的另两个），以及产物里留哪几张速度场。
- **`MINIMIZE_MEMORY`**：影响的是产物缓存策略与哪些盒被保留（`wrapper/outputs.py:581-609`），不改本块算出的场。

## 五、陷阱

**一、本块不读 `INITIAL_REDSHIFT`，也不乘生长因子。** 抽样给的是按今天功率谱归一的那一条（§3.2），乘 $D(z)$ 在下游（`PerturbedField.c:60-77`），搬粒子时用的是差值 $D(z)-D(z_i)$ 与 $-\tfrac37(D^{2}-D_i^{2})$（`map_mass.c:160-174`）。在本块里找生长因子会一无所获；拿初始条件与某个红移的密度场逐格相除，差的就是这一两个乘数。

**二、选 `LINEAR` 不会让本块少算东西。** 一阶位移场无条件算（`:740`），`PERTURB_ALGORITHM` 只门控 2LPT（`:751`）。以为"选了线性就是没有速度场"，会在读产物大小时出错，也会在下游取用速度场时误判"这些场是空的"。

**三、`HIRES_box_saved` 会被 2LPT 覆盖。** 覆盖点是 `:507`，函数头注释写明不还原（`:371`）。它同时是相对速度与一阶位移的输入，所以这两步必须排在 2LPT 之前——改调用次序会静默出错：场还在，内容已经是二阶源项。

**四、两条位移路的体积因子位置不同。** 一阶在降采样时除以 `VOLUME`（`:356`），二阶在源项处除以 $V^{2}N$（`:494`）而最后一步不再除（`:538`）。逐格比较两条路之前先确认比的是同一条；`compute_f_laplacian` 注释里那句 "The Volume factor anticipates an inverse FFT"（`:289`）说的正是这个约定，而不是那一行真的乘了体积。

**五、相对速度输出的是速率，不是矢量。** 三个方向的贡献平方累加进同一个数组（`:230-231`），最后统一开方（`:232`），方向信息在累加时丢掉。另外这个累加写在输出数组自己身上，复用它当暂存会得到平方和。

**六、降采样是取值，不是平均。** 密度场、两条位移场与相对速度都走 `resample_index` 取中心像素（`:725`、`:353`、`:535`），没有任何窗口平滑；平滑只发生在 k 空间滤波那一步，而且只在 `PERTURB_ON_HIGH_RES` 关掉且 `DIM != HII_DIM` 时才做。一个低分辨格点拿的就是它中心附近那一个高分辨像素。

**七、读注释会把方向看反。** `:660` 把 `dft_r2c_cube` 叫 "Inverse FFT'd"，而 `dft_c2r_cube` 在别处被叫 "FFT back to real space"（§3.6）。判方向认函数名。

**八、抽样的相位按线程分。** `seed_rng_threads` 给每个线程一条独立的 GSL 流（`:571-572`），循环里各线程用自己那条抽（`:126-127`）。固定种子、换线程数不保证逐格相同的实现；要逐格比较随机实现，种子与线程数都要固定。

**九、直流模在三处被单独处理。** 抽样后的补齐（`:51`）、梯度与拉普拉斯算子（`:266`、`:296`）、相对速度（`:184`）各置零一次，都是"要除以 $k$ 或 $k^{2}$"的位置。自己写一个作用在 k 空间上的算子时最易漏这一条，漏掉就是 nan 传染整盒。

**十、给定期场时抽样整段被跳过。** 非零检测只看 `hires_density` 这一张场（`:628`），所以只要结构体里被填过非零值，就会走进那条路（§3.6）：此时"初始条件"完全由输入决定，种子不再起作用。

### 一份最小检查清单

- 打开初始条件之前先确认 `PERTURB_ALGORITHM`：它决定下游搬不搬粒子、要不要二阶项。
- 要用相对速度，先确认 `POWER_SPECTRUM == "CLASS"`，否则校验器会先拦下 `USE_RELATIVE_VELOCITIES`。
- 涉及种子的比较，种子与线程数都固定。
- 在本块找不到生长因子是正常的：乘 $D(z)$ 与减 $D(z_i)$ 都在下游。
- 怀疑位移场不对，先查两条路的体积因子与降采样是不是取值。

## 六、v_cb · 重子-暗物质相对速度

它是两个速度场之差，也是本块唯一被当作输入读入的场：代码不抽它的相位，而是在密度场那条 k 空间副本上换一套振幅——每条模乘方向因子 $ik_i/k$、功率谱比值 $\sqrt{P_{vcb}(k)/P(k)}$ 与 `physconst.c_kms`（`InitialConditions.c:188-189`，§3.5）。"与密度扰动同相位"在代码里就是这句"同一份相位、换一套振幅"。

算法全在 `compute_relative_velocities`（`InitialConditions.c:141-238`）里，调用点由 `USE_RELATIVE_VELOCITIES` 守着（`:734-736`），输出写进 `boxes->lowres_vcb`——只有低分辨一张，没有高分辨版本。

**三处口径要记牢。** 其一，输出是速率大小（三分量平方累加后开方，`:230-233`），不是矢量；其二，那个累加写在输出数组自己身上，入场前它必须为零；其三，滤波与降采样跟密度场那次同一套约定（`:194-230`），只是它多一道"三个方向分别变换、再逐格累加"的顺序。

**它在链上的位置是输入数据。** 它不由任何上游量算出，也不进密度或位移的算式；下游拿它算小质量晕的成核与冷却门槛，`A_VCB`、`BETA_VCB`、`FIXED_VAVG`、`FIX_VCB_AVG` 决定的是怎么用它（§4.1）。局限在大尺度：相干长度有限，小尺度上它不再代表真实的速度差，那里起作用的是密度与电离的局部结构。

## 七、δ_i(x) · 线性初始密度场

它是本块的头号输出，也是整条链"结构从哪来"的唯一答案：一张按功率谱抽出的高斯随机场，每个格点一个数，零均值、无量纲，全盒平均为零（§2.1）。

代码上它分两段：抽样在 `sample_ic_modes`（`InitialConditions.c:103-139`）与 `adj_complex_conj`（`:26-101`），把半边 k 空间补成合法实场；落到网格在 `:667-697`——变换回实空间后除以 `VOLUME` 写进 `boxes->hires_density`。低分辨那一张是这份场滤波降采样后的样子（`:699-732`），少了高频，归一约定不变。

**两处最容易误读。** 其一，它不含生长因子：抽出来的是按今天功率谱归一的那一条，乘 $D(z)$ 在下游（§五 第一条）。其二，`INITIAL_REDSHIFT` 在这段代码里一个字都不读——初始时刻是下游解释这张场时才引入的。调用方也可以整张场由外部给定，此时抽样被跳过、`hires_density` 保持输入值（§3.6）。

**它的位置是起点，局限也在同一处。** 引力演化、晕目录、电离场里的密度都由它生长或平滑得到，所以它一旦定下，整条链的空间结构就跟着定下；而初始红移以下的非线性演化不归它管，那部分由引力与塌缩承担。

## 八、v_1LPT(x) · 一阶拉格朗日位移速度场

它是位移场的时间导数，但代码里存下来的是**不含时间因子的那一层** $\nabla\nabla^{-2}\delta$（§2.2）：乘 $-fH D$ 的活在下游，`map_mass.c:160-174` 用的是差值形式的 $\Delta D$。读这张场时要记住它记的是位移的方向与形状，不是一个物理速度。

代码由两个函数接力：k 空间算子 `compute_f_gradient`（`InitialConditions.c:240-267`，`box_out = box_in * k_i * I / k²`）与三分量总装 `compute_velocity_fields`（`:299-364`）。三个分量来自同一份 `box_saved`，只有轴指标不同；`vel_pointers` 指向哪三张盒由 `PERTURB_ON_HIGH_RES` 决定（`:585-599`）。

**两处约定与一处门控。** 直流模被单独置零（`:266`）；降采样是取值而不是平均，并在同一步除以 `VOLUME`（`:356`）。门控只有 `PERTURB_ON_HIGH_RES`（改的是存在哪张网格），`PERTURB_ALGORITHM` 不门控这一档——选 `LINEAR` 时它照旧被算出来写进盒子（§五 第二条）。

论文出处：本对象没有登记的论文节号，代码注释里也没有引用。

## 九、v_2LPT(x) · 二阶 LPT 速度场

它补的是一阶自身引力造成的偏差（§2.2），存进盒子的同样是不含时间因子的那一层：二阶核 $-\tfrac37D^{2}$ 在下游乘上，而且用的是差值形式 $-\tfrac37(D^{2}-D_i^{2})$（`map_mass.c:161-174`）。

`compute_velocity_fields_2LPT`（`InitialConditions.c:366-544`）分两半。先拼源项：三个对角分量各做一次拉普拉斯、变换回实空间后存进借来的 `hires_vi_2LPT` 盒（`:421-447`），三个混合对再逐格累加 $\phi_{ii}\phi_{jj}-\phi_{ij}^{2}$（`:451-482`），整盒除以 $V^{2}N$ 后变换回 k 空间（`:486-502`）。再走一阶那条路：逐方向梯度 → 按需滤波 → 变换回实空间 → 降采样（`:510-543`）。

**三件要记住的事。** 其一，它**会覆盖** `HIRES_box_saved`（`:507`，函数头注释已声明不还原），因此必须排在相对速度与一阶位移之后；其二，体积因子在源项那一步就除完了，最后一步不再除（`:494` 与 `:538`）；其三，只有 `PERTURB_ALGORITHM == 2LPT` 时才被调用（`:751`），另外两档下这三张盒保持为零。

论文出处：二阶修正与三个速度场档位的出处见文末表（Scoccimarro 1998, MNRAS 299, 1097-1118, Appendix D），两条在本地都缺正文。
